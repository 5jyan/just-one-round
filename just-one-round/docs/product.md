# 제품 정의

2026-10-13 로컬 소스 기준. 운영 적용 여부는 [출시 체크리스트](release-checklist.md)에서 별도로 확인한다. 게임별 계약은 [게임 문서 색인](games.md)을 따른다.

## 한 문장

딱한판만은 매일 바뀌는 짧은 미니게임을 플레이하고, 같은 날 참여한 사람들과 순위를 비교하는 모바일 앱이다.

## 사용자 가치

- 긴 시간을 투자하지 않고 바로 시작할 수 있다.
- 하루 한 번이라는 제한 때문에 결과에 긴장감이 생긴다.
- 매일 게임이 바뀌어 다시 방문할 이유가 생긴다.
- 실제 사용자와 전체 일일 순위·내 주변 순위를 비교한다. 주간·월간·그룹별 순위는 현재 일일 랭킹과 구분되는 확장 과제다.

## 핵심 원칙

1. 설명은 짧고 플레이는 게임별 종료 조건과 제한 시간 안에 끝나야 한다. 반응 게임은 수 초, 컵라면은 30초를 목표로 하고, 생존·라운드 게임은 별도 상한을 사용한다.
2. 실력과 즉흥성이 모두 드러나야 한다.
3. 공식 도전은 모든 사용자에게 하루 한 번 무료로 제공하고, 같은 일일 시드의 기록만 공식 순위에 반영한다.
4. 순위는 흥미를 위한 것이며 과도한 경쟁이나 결제를 강요하지 않는다.
5. 새로운 게임을 추가하기 쉬운 공통 구조를 유지한다.
6. 게임 중 전화·홈 이동·잠금·다른 시스템 UI·앱 종료가 발생하면 해당 기회를 소진한다.

## 닉네임과 랭킹

- 닉네임은 사용자가 직접 입력하며 2~12자, 대소문자 구분 없이 중복 불가다.
- 첫 정상 플레이가 끝난 뒤 닉네임 입력을 제안하고, 나중에도 설정에서 변경할 수 있다.
- 랭킹은 실제 사용자별 당일 최고 점수 하나로 비교한다. NPC는 공식 순위와 참여자 수에서 제외하며, 테스트 계정은 다른 유저의 랭킹에서 제외한다. 내 주변 3명과 전체 일일 목록을 제공한다.
- 같은 점수는 제출 시각이 빠른 순, 그다음 사용자 ID 순으로 정렬한다.
- 랭킹창에는 같은 게임의 지난 회차 1등을 표시한다. 성공한 조회 결과는 앱 실행 중 다음 한국 시간 오전 6시까지 재사용한다.
- 하단 버튼으로 실제 플레이를 시작하지 않은 유저를 조회한다. 신원미상·빈 닉네임·본인·테스트 계정·차단 유저는 제외하며, 경험치 내림차순(레벨 높은 순), 동률은 사용자 ID 순으로 정렬한다. 점점점 메뉴에서 기존 찌르기·자랑하기·선물 기능을 사용한다.
- 오전 6시 10분 이후 첫 접속에는 전날 점수, 최종 순위, 상위 비율을 한 번 보여준다.

## 대상 사용자

- 대기·이동·휴식 중 짧게 한 판을 즐기려는 사람
- 긴 모바일 게임의 성장 시스템에 피로한 사람
- 친구 연결 없이도 다른 사용자와 가볍게 경쟁하고 싶은 사람

## 일일 플레이 기회

- 공식 도전은 쿠폰 없이 하루 한 번 무료로 제공한다.
- 오늘의 도전을 끝낸 뒤 보상형 광고로 공식 도전을 딱 한 판 더 할 수 있다.
- 광고 추가 도전 이후에는 같은 `진짜 딱 한판만!` 버튼으로 상점에서 구매한 도전권을 보유량만큼 반복 사용해 도전할 수 있다.
- 연습은 매일 무료 연습권 1장을 제공하며 한 판에 1장을 사용한다.
- 연습권이 0장이 될 때마다, 보상형 광고 1편을 끝까지 보면 연습권 2장을 추가로 받는다.
- 광고로 받은 2장을 모두 사용하면 다시 광고를 보고 2장을 충전할 수 있다. 연습권은 오전 6시 초기화 때 소멸하고 이월되지 않는다.
- 공식 도전은 모든 사용자에게 같은 일일 시드를 사용한다.
- 연습은 공식 도전과 분리된 공용 연습 시드 P1·P2·P3를 사용한다.
- 연습 결과는 랭킹에 반영하지 않는다.
- 코인 상점의 연습권(100코인)과 도전권(250코인)은 날짜가 바뀌어도 이월된다. 매일 무료/광고로 주는 연습권만 오전 6시에 초기화된다.
- 닉네임 변경권은 500코인이며, 첫 닉네임 설정은 무료이고 기존 닉네임을 바꿀 때 1장을 사용한다.
- 상점에서 보상형 광고를 보면 하루 1회 50코인을 받는다.

## 경험치·레벨·닉네임 색상

- 경험치는 누적되며 코인 사용으로 줄어들지 않는다. Lv1은 0XP, 첫 레벨업은 100XP이고 다음 레벨 필요량은 150XP씩 증가한다: `100 → 250 → 400 → 550…`.
- 레벨 L 도달 누적 XP는 `(L−1) × (75 × (L−1) + 25)`이다. Lv5는 1,300XP, Lv10은 6,300XP, Lv30은 63,800XP다.
- 새로 오른 레벨마다 도전권 1장을 서버가 지급한다. 여러 레벨을 오르면 합산 지급하며, 이미 지급한 레벨을 다시 통과해도 중복 지급하지 않는다.
- 150XP 기준 전환으로 오른 기존 계정의 레벨도 차이만큼 지급한다. 기존 XP와 코인은 재설정하지 않는다.
- 축하 화면은 홈에서 다른 팝업·시작 화면이 끝난 뒤 표시한다. 확인은 지급과 별도이며, 확인 전 종료해도 미확인 상태는 다음 접속에 남는다.
- 닉네임 색상은 자동 적용한다: Lv1–4 기본, Lv5–9 노랑, Lv10–14 그린, Lv15–19 블루, Lv20–24 퍼플, Lv25–29 핑크, Lv30 이상 골드.
- 닉네임 색상권은 구매·사용·신규 선물에서 제거한다. 기존 보유분은 서버 마이그레이션에서 장당 300코인을 한 번만 환급한다. 과거 알림·거래 이력은 유지한다.

## 수익 모델

- 핵심: 연습권 2장 충전과 오늘의 도전 후 딱 한 판만 더를 제공하는 선택형 보상 광고
- 코인 소비처: 이월되는 연습권·도전권·닉네임 변경권
- 상점 보상형 광고: 하루 1회, 50코인
- 설정의 `문의하기`는 앱 안에서 내용을 입력받아 사용자 ID·앱 버전·빌드 번호와 함께 운영 DB에 저장한다.
- 초기에는 배너·전면 광고를 최소화한다.
- 보상형 광고를 보지 않아도 무료 연습 1회와 공식 도전 1회로 기본 경험이 완결되어야 한다.
