# 미결정 사항과 확정된 계약

2026-10-13 로컬 소스 기준으로, 이미 구현된 결정을 초기 질문과 구분한다. 게임별 규칙은 [게임 문서 색인](games.md)을 따른다.

구현 전에 전부 결정할 필요는 없다. 해당 기능을 만들기 직전에 확정한다.

## 확정된 구현 계약

- 게임별 규칙·조작·점수 인코딩: 각 게임 `GAME_DESIGN.md`와 순수 규칙 모듈을 따른다.
- 일일 경계: 한국 시간 오전 6시. 이전 날짜의 제출 마감·결과 확정은 오전 6시 10분이다.
- 계정 복원: 카카오 identity를 연결한 계정으로 기기 변경 후 로그인한다. 새 기기의 익명 기록은 기존 계정과 자동 병합하지 않는다.
- 공식 기록: 사용자별 당일 최고 점수를 사용하고, 추가 도전 시도도 별도로 보관한다. 도전권 사용 횟수는 보유 수량까지 허용한다.
- 순위: 실제 사용자 기준이며 NPC를 제외한다. 내 주변 순위와 전체 일일 랭킹을 제공한다.
- 광고: Google AdMob/UMP와 서버 검증 경로를 사용한다.
- 레벨: 첫 100XP 이후 필요량을 150XP씩 증가시키며, 새로 오른 레벨마다 도전권 1장을 지급한다.

## 앞으로 확인할 제품 선택

- 주간·월간 순위에서 서로 다른 게임을 비교할 기준
- 기록 공유·리플레이 등 아직 구현하지 않은 확장 기능의 범위

## 출시·운영 시 확인할 항목

- Google AdMob 광고 단위·동의·서버 검증의 실제 운영 설정
- 개인정보처리방침 및 이용약관
- 부정행위 대응 수준과 제재 정책
- 닉네임 필터링 정책
- `shook.party` 독립 도메인으로 전환 후 기존 도메인 만료 처리
- App Store 및 Google Play 개발자 계정

## 현재 운영 원칙

- 일일 경계는 한국 출시 동안 `Asia/Seoul` 오전 6시로 통일한다.
- 여러 도전 중 최고 점수를 공식 일일 점수로 사용하고 개별 시도는 모두 보관한다.
- 연령과 성별은 수집하지 않고 전체 랭킹만 제공한다.
- 모든 앱 비활성 전환은 해당 시도를 소진하며 유예시간을 두지 않는다.
- 닉네임은 사용자가 직접 정한다. 내 주변 3명과 전체 일일 목록, 이전 회차 1등, 미참여 유저 목록은 서로 다른 조회 기능이다.
