# 도트 UI/UX 방향

## 결론

앱 전체는 Flutter 위에 자체 디자인 시스템을 만들고, 게임 화면만 Flame으로 렌더링한다. 외부의 도트 UI 패키지에 화면 구조를 종속시키지 않는다.

## 시각 원칙

- 도트 감성은 유지하되 작은 본문까지 모두 게임 폰트로 만들지는 않는다.
- 제목, 점수, 버튼에는 픽셀 폰트를 사용한다.
- 긴 설명, 약관, 통계에는 가독성 높은 시스템 한글 폰트를 사용할 수 있다.
- 터치 영역은 시각적 도트 크기와 별개로 모바일 접근성 기준을 지킨다.
- 화면은 8px 간격 체계를 기본으로 한다.
- 모서리, 그림자, 테두리는 정수 단위로 렌더링한다.
- 스프라이트 확대에는 nearest-neighbor 필터를 사용한다.
- CRT 노이즈·글리치 효과는 장식으로만 제한해 피로도를 낮춘다.

### 텍스트 줄바꿈

- 화면에 표시하는 텍스트는 `WordSafeText`를 기본 컴포넌트로 사용한다.
- 공백으로 나뉜 어절은 통째로 다음 줄로 넘기고, 긴 어절도 클립하지 않는다.
- 말줄임표는 사용하지 않는다. 한 줄 고정이 필요한 점수·버튼 값만
  `singleLine: true`를 명시한다.

## 사용할 외부 자산

### Galmuri

- 용도: 한국어 제목, 숫자 점수, 짧은 버튼 문구
- 출처: https://github.com/quiple/galmuri
- 라이선스: SIL Open Font License 1.1
- 방식: 특정 버전의 폰트 파일을 프로젝트에 포함하고 라이선스 고지를 함께 보관

### Pixelarticons

- 용도: 홈, 설정, 음향, 랭킹 등 공통 아이콘
- 출처: https://github.com/halfmage/pixelarticons
- 라이선스: MIT
- 방식: 필요한 SVG만 선택해 프로젝트에 포함한다. 오래된 비공식 Flutter 래퍼에는 의존하지 않는다.

### Kenney UI Pack

- 용도: 초기 프로토타입에서 버튼·패널·슬라이더 형태 참고 또는 임시 애셋
- 출처: https://kenney.nl/assets/ui-pack
- 라이선스: CC0
- 방식: 최종 브랜드 UI를 대신하지 않으며 필요한 부분만 사용한다.

### Pixelorama

- 용도: 스프라이트, 타일, 간단한 애니메이션 편집
- 출처: https://github.com/Orama-Interactive/Pixelorama
- 라이선스: MIT
- 비고: 런타임 의존성이 아닌 제작 도구다.

## 보류한 패키지

### pixel_ui

Flutter용 픽셀 디자인 시스템으로 기능과 방향은 좋지만 2026년 기준 초기 단계이고 사용자 기반이 작다. 구현 참고 자료로 활용하되 앱의 핵심 의존성으로는 추가하지 않는다.

### pixelarticons Flutter wrapper

원본 아이콘은 계속 관리되고 있으나 기존 Flutter 래퍼의 배포가 오래되어 원본 SVG를 직접 포함하는 편이 버전과 품질을 통제하기 쉽다.

## 현재 디자인 토큰 (2026-10-13 소스 기준)

- 배경: 짙은 남색 계열
- 표면: 배경보다 밝은 청회색
- 기본 강조색: 선명한 노랑
- 성공·보상: 민트
- 위험·실패: 코랄 레드
- 테두리: 밝은 크림색 또는 저채도 청색
- 기본 그리드: 8px
- 작은 테두리: 2px
- 강조 테두리와 눌림 오프셋: 4px

색상 값의 기준은 [`AppColors`](../lib/app/theme/app_colors.dart)다.

| 역할 | 값 |
|---|---|
| 배경 / 깊은 배경 | `#101827` / `#09101D` |
| 표면 / 밝은 표면 | `#1D2A3D` / `#2C3C52` |
| 테두리 | `#9CB3C9` |
| 본문 / 보조 텍스트 | `#FFF4D6` / `#A9B8C7` |
| 기본 강조 / 눌림 그림자 | `#FFD23F` / `#B87714` |
| 보상 / 위험 | `#54D6A1` / `#FF6B6B` |

닉네임은 [`NicknameColors`](../lib/features/profile/domain/nickname_color.dart)의 레벨 구간을 따른다. Lv5 노랑 `#FFF15A`, Lv10 그린 `#36F58A`, Lv15 블루 `#5894FF`, Lv20 퍼플 `#B477FF`, Lv25 핑크 `#FF4FA7`, Lv30 이상 골드 `#FFD23F`다. 일반 보상 민트와 닉네임 그린은 서로 다른 토큰이다.

레벨업은 [`LevelUpRewardDialog`](../lib/features/today/presentation/level_up_reward_dialog.dart)의 확대·빛·픽셀 연출과 도전권 합산 표시를 사용한다. 애니메이션은 유한하며 동작 줄이기 설정에서는 정적인 완료 상태로 표시한다. 다른 팝업·시작 화면·게임 플레이와 겹쳐 열지 않는다.

## 라이선스 관리

- 외부 파일마다 출처, 버전 또는 커밋, 라이선스를 `assets/THIRD_PARTY.md`에 기록한다.
- 가능하면 CC0, MIT, SIL OFL 자산만 사용한다.
- 출처나 상업 이용 조건이 불명확한 이미지 검색 결과는 포함하지 않는다.
- 생성형 이미지도 원본 프롬프트와 생성 일자를 기록한다.
