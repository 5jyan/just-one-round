# 스토어 개인정보·데이터 보안 작성 기준

이 문서는 현재 코드 기준의 제출 초안이다. SDK 버전과 콘솔 질문이 바뀔 수
있으므로 제출 당일 App Store Connect, Google Play Console, Google Mobile Ads
문서를 다시 대조한다.

## 앱이 직접 처리하는 데이터

| 데이터 | 용도 | 필수 여부 | 계정과 연결 |
|---|---|---:|---:|
| 익명 사용자 ID | 인증, 계정 구분, 부정 이용 방지 | 필수 | 예 |
| 해시 처리된 기기 설치 ID | 계정 삭제·재설치 후 당일 중복 플레이 방지 | 필수 | 아니요 |
| 닉네임 | 랭킹 표시 | 선택 | 예 |
| 게임 점수·플레이 기록·충돌 정보 | 게임 진행, 기록, 랭킹, 부정행위 확인 | 필수 | 예 |
| 광고 보상 거래·세션 정보 | 보상 검증, 중복 방지 | 광고 이용 시 | 예 |
| 닉네임 신고·차단 정보 | 커뮤니티 안전 | 기능 이용 시 | 예 |

출생연월, 성별, 정확한 위치, 연락처, 사진, 결제정보, 건강정보는 앱이 직접
수집하지 않는다.

## 제3자 SDK

Google Mobile Ads SDK는 광고 제공·측정·보안 목적으로 IP 주소, 기기 또는 광고
식별자, 앱·광고 상호작용, 진단정보를 처리할 수 있다. 콘솔에서는 실제 AdMob
설정(개인 맞춤 광고 여부, 동의 메시지, 지역)과 Google의 최신 데이터 공개
문서를 기준으로 답한다.

Supabase는 익명 인증, 데이터베이스, Edge Function 및 운영 로그를 처리한다.
프로젝트 데이터베이스 리전은 대한민국 서울(`ap-northeast-2`)이다.

## 삭제

앱의 `설정 → 계정 및 데이터 삭제`는 `delete-account` Edge Function을 호출한다.
인증 사용자가 삭제되면 외래키의 `on delete cascade`에 따라 닉네임, 게임 기록,
점수, 광고 보상, 신고·차단 기록이 함께 삭제된다. 원래 기기 식별자는 서버로
전송하지 않고 SHA-256 해시만 저장한다. 계정과 분리된 당일 플레이 여부는
계정 삭제 후에도 다음 일일 초기화까지 유지되며, 이후 요청 시 만료 표식이
삭제된다.

스토어의 계정 삭제 URL에는 공개된
`/account-deletion` 페이지를 입력한다.

## App Store Connect 개인정보 답변 초안

2026-07-26 릴리스 아카이브에 포함된 Google Mobile Ads 및 UMP 개인정보
매니페스트와 Google의 iOS 데이터 공개 문서를 함께 대조했다. SDK가 조건에
따라 수집할 수 있다고 밝힌 항목은 보수적으로 공개한다.

| App Store 데이터 유형 | 수집 | 사용자와 연결 | 추적에 사용 | 주된 목적 |
|---|---:|---:|---:|---|
| 사용자 ID | 예 | 예 | 아니요 | 앱 기능, 사기 방지 |
| 기타 사용자 콘텐츠(닉네임·신고) | 예 | 예 | 아니요 | 앱 기능 |
| 제품 상호작용(플레이·광고 상호작용) | 예 | 예 | 아니요 | 앱 기능, 분석, 광고 |
| 대략적 위치(IP 기반 추정) | 예 | 예 | 아니요 | 제3자 광고, 분석 |
| 기기 ID | 예 | 예 | 예 | 제3자 광고, 분석 |
| 광고 데이터 | 예 | 예 | 아니요 | 제3자 광고, 분석 |
| 충돌 데이터 | 예 | 아니요 | 아니요 | 분석 |
| 성능 데이터 | 예 | 예 | 아니요 | 분석, 광고 |
| 기타 진단 데이터 | 예 | 아니요 | 아니요 | 분석, 광고 |

- `Data Used to Track You`에는 Google Mobile Ads 매니페스트가 추적 가능으로
  선언한 `Device ID`를 포함한다.
- 앱은 현재 `NSUserTrackingUsageDescription`을 선언하거나 자체적으로 ATT
  권한을 요청하지 않는다. 따라서 IDFA 접근을 전제로 한 맞춤형 광고 설정을
  임의로 켜지 않는다.
- UMP 동의 메시지와 AdMob 개인정보 설정은 실제 운영 콘솔 상태를 제출 당일
  확인한다.
- 개인정보처리방침 URL은 `https://legal.shook.work/privacy`, 계정 삭제
  안내 URL은 `https://legal.shook.work/account-deletion`이다.
