# 블랙잭 — 게임 계약 v4

## 목표

- 게임 ID: `beat_the_dealer`
- 규칙 버전: `4`
- 마지막 소스 검증: 2026-10-13
- 플레이어용 이름: `블랙잭` (프레젠테이션 카탈로그의 `블랙잭`)
- 시작 코인 100개로 10라운드를 진행한다.
- 마지막에 보유한 코인을 `raw_score`로 제출하며 높은 점수가 우선이다.
- 안전 제한 시간은 3분이다.

## 플레이어 약속

- 한 문장 약속: 공개된 딜러 카드와 내 패를 읽고 5코인 단위로 베팅한 뒤, `한 장 더`와 `멈추기`를 선택해 10라운드 동안 코인을 지킨다.
- 세션 모델: 10라운드 고정. 정상 완료는 `clear`, 코인이 5 미만이면 `gameOver`, 180초에 도달하면 `timeUp`이다.
- 중단: 앱 이탈·백그라운드·화면 종료는 `interrupted`로 처리하고 점수를 제출하지 않는다.

## 한 라운드

1. 딜러의 공개 카드 한 장을 먼저 보여준다.
2. 플레이어는 공개 카드를 보고 5코인 단위로 5~50코인을 건다. 마지막 10라운드만 최대 100코인이다.
3. 플레이어 카드 두 장과 딜러 비공개 카드 한 장을 배분한다.
   7번째 라운드에는 플레이어의 두 번째 시작 카드가 반드시 A이며, 공개될 때 선물 효과가 나타난다.
4. 플레이어는 `한 장 더` 또는 `멈추기`를 선택한다.
5. 딜러는 비공개 카드를 뒤집고 16 이하면 받고, 모든 17 이상에서 멈춘다.
   숨긴 카드부터 한 장씩 순서대로 공개하며, 매 공개 후 합계를 다시 판정한다.
6. 21 이하에서 높은 합계가 승리하며 같은 합계는 무승부다. 21 초과는 버스트다.
7. 플레이어가 먼저 버스트해도 딜러는 17 이상 또는 딜러 버스트까지 카드를 순서대로 공개한다. 최종적으로 둘 다 버스트여도 플레이어 패배다.

딜러 공개 카드 미리보기는 `0.65초` 동안 재생한다. 각 라운드는 베팅 `8초`와 플레이어 결정 `8초`를 사용하며, 딜러는 숨은 카드와 추가 카드를 `1초` 간격으로 한 장씩 공개한다. 판정 후 `1.2초` 결과 연출을 마치면 다음 라운드로 간다.

## 카드와 배당

- 표준 52장 덱을 사용한다.
- 랭크는 A, 2~10, J, Q, K이며 0은 존재하지 않는다.
- J/Q/K는 10, A는 합계에 가장 유리한 1 또는 11로 자동 계산한다.
- 최초 두 장이 A와 10점 카드면 블랙잭이다.
- 일반 승리 `+배팅액`, 패배 `-배팅액`, 무승부 `0`, 블랙잭 `+배팅액×1.5`.
- 블랙잭 배당은 `((법적 베팅액 × 3 + 9) ~/ 10) * 5`로 계산해 5코인 단위로 반올림한다.
- 스플릿, 더블다운, 보험, 서렌더는 사용하지 않는다.

## 시간과 종료

- 배팅과 플레이어 선택은 각각 8초다.
- 배팅 시간이 끝나면 현재 표시 금액으로 자동 배팅한다.
- 선택 시간이 끝나면 자동으로 멈춘다.
- 10라운드 완료 또는 5코인 미만이 되면 결과를 제출한다.
- 전역 3분 제한에서는 현재 보유 코인으로 종료한다.
- 앱 이탈·백그라운드·화면 종료는 점수를 제출하지 않고 시도만 소진한다.
- 종료 콜백은 정확히 한 번만 호출한다.

## 입력과 상태

- 카운트다운과 딜러 미리보기 중에는 베팅·히트·스탠드 입력을 받지 않는다.
- 베팅 단계에서는 `-5`와 `+5`로 금액을 조절한다. 일반 라운드는 `5~50`, 10번째 라운드는 `5~100` 범위이며 현재 표시 금액을 베팅한다.
- 플레이어 차례에서는 `한 장 더`가 히트, `멈추기`가 스탠드다. 두 버튼은 한 번의 라운드에서 하나의 선택만 확정한다.
- 상태 흐름은 `countdown → dealerPreview → betting → playerTurn → dealerTurn → resolving → nextRound`이며, 10번째 라운드의 결과는 `clear`로 끝난다. 코인 부족·전역 시간 제한·수명주기 중단은 각각 별도 종료 경로다.
- 플레이어가 버스트해도 딜러 공개 연출은 끝까지 재생한 뒤 라운드 결과를 정산한다.

## 공정성과 난수

- 한국 시간 오전 6시 기준 상품 날짜, 규칙 버전, 시도 순번으로 시드를 만든다.
- 각 라운드는 독립된 표준 52장 덱을 시드로 섞는다.
- 7번째 라운드는 셔플된 덱 안의 실제 A를 플레이어의 두 번째 카드와 맞바꿔 중복 없이 선물한다.
- 같은 날짜와 시도 순번에는 같은 덱 순서가 생성된다.
- 10라운드 중 딜러 약한 공개 카드(2~6)가 최소 세 번 나오고 강한 공개 카드(A 또는 10점)는 최대 세 번만 나오도록 세트를 검증한다.
- 플레이어가 받은 추가 카드 수에 따라 딜러가 이후 같은 덱 순서에서 카드를 받는다.

## 점수 계약

- 최소 점수 0, 최대 점수 925.
- 배팅은 5 단위다. 블랙잭 1.5배 보너스는 5코인 단위로 올림해 유효 점수를 5 단위로 유지한다.
- 제출 `raw_score`는 최종 보유 코인 정수 `0~925`이며 항상 5의 배수다. `starsCollected = 0`, `collisions = 0`을 함께 제출한다.
- `20260923000100_blackjack_seventh_round_ace_v4.sql`이 게임 버전 4, 점수 `0~925`, 5 단위, 보조 필드 `0`, 지속시간 `1~180000ms`를 검증한다.

## 화면 계약

- 기준 뷰포트: 360×640, 배경 월드: 360×840, 위치 `(0, -100)`.
- 배팅 중에는 딜러 공개 카드 한 장만 표시한다.
- 배팅 후 플레이어 차례에는 딜러 공개 카드와 카드 뒷면을 표시한다.
- 딜러 차례부터 실제 딜러 패 전체를 표시한다.
- 카드 런타임 크기: 72×100. 좌상단과 우하단에 랭크·무늬를 표시한다.
- 2~10은 실제 핍 배열, A는 중앙 무늬, J/Q/K는 왕족 초상 아틀라스를 사용한다.
- 플레이어 카드가 늘면 겹침 간격을 자동으로 줄여 화면 너비 안에 배치한다.
- 모든 래스터는 nearest-neighbor로 표시한다.
- 상단 HUD는 나가기 버튼·코인·판수를 같은 높이에 둔다. 판수는 `현재/10 판`으로 표시한다.
- 배팅 조절 버튼은 `-5`·`+5`만 표시하고, 중앙 BET 패널은 코인 아이콘과 금액을 하나의 그룹으로 중앙 정렬한다.

## 구현 근거와 검증 경계

- 규칙과 덱 생성은 `domain/beat_the_dealer_rules.dart`, 입력·상태·카드 공개 연출은 `beat_the_dealer_game.dart`, 플레이어용 제목·가이드·시간 표시는 `presentation/beat_the_dealer_presentation.dart`에 있다.
- 7번째 라운드 선물 에이스는 셔플된 실제 덱에서 가져오며, 중복 카드를 만들지 않는다. 약한 딜러 공개 카드와 강한 공개 카드의 라운드 분포도 같은 시드 검증에 포함된다.
- 현재 문서의 카드 분포와 배당은 코드·마이그레이션으로 고정된 계약이다. 실제 승률, 라운드별 코인 잔량과 난이도는 별도 플레이테스트로 확인할 가설이다.
