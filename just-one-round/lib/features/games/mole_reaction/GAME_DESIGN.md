# 친구 두더지 반응속도

## 상태

- 상태: Implemented (픽셀아트 런타임·에셋·가이드·레지스트리·점수 검증 연결 완료, 실기 밸런스 검증 대기)
- 게임 ID: `mole_reaction`
- 규칙 버전: `1`
- 마지막 승인: 2026-09-14
- 승인 범위: 2×2 구멍, 무기록 준비 두더지 1회와 실제 기록 황금 두더지 1회, 총 2회, 등장 전 3~8초 대기, 황금 반응시간 2배 가중, 텃밭과 친구 얼굴 특징을 참고한 두더지
- 첨부 사진의 역할: 일반 두더지는 친구의 눈썹·작은 눈·둥근 볼·분홍 코·다문 미소를 단순화된 픽셀 표정에 참고한다. 황금 두더지는 같은 픽셀 마스터의 실루엣·표정을 유지하고 털 팔레트만 금색으로 바꾼다. 사람 머리카락이나 사진 자체·배경 인물은 런타임 에셋에 넣지 않는다.
- 에셋 산출 상태: 곰처럼 보이던 둥근 귀를 제거하고, 작은 눈·돌출된 분홍 두더지 코·수염·삽 모양 앞발·보이는 상체를 강조한 일반 idle·hurt·thumbs-up 2×2 시트와 동일 실루엣의 황금 시트를 제작했다. `asset-manifest.json`, `pubspec` 자산 등록, Flame 런타임 로딩을 연결했고, 실기 밸런스·터치 지연 계측은 별도 확인이 필요하다.

## 플레이어 약속

- 한 문장 약속: 조용한 텃밭에서 준비 두더지 한 마리로 손을 풀고, 3~8초 뒤 나타나는 진짜 황금 두더지 한 마리를 즉시 눌러 단 한 번의 기록을 만든다.
- 코믹 전제: 친구를 닮은 능청스러운 픽셀 두더지가 먼저 연습 상대가 되어 주고, 잠깐의 정적 뒤 같은 얼굴의 황금 두더지가 진짜 승부를 걸어 온다.
- 핵심 실력: 표적이 나타난 뒤의 시각 반응, 2×2 위치로 손을 옮기는 속도, 긴 대기 동안 집중을 유지하는 능력
- 세션 모델: 준비 1회와 실제 기록 1회로 끝나는 고정 클리어타임형 점수전. 준비판은 기록에서 제외하고, 실제판의 반응시간·실수·놓침만 합산한다.
- 예상 플레이 시간: 약 13~27초. 오류 없이 두 대기와 타격을 거치는 경우 약 27초 이하를 목표로 한다.
- 절대 최대: 세션 wall-clock 180초(카운트다운 포함). 5분보다 짧으며, 제한을 넘긴 시도는 랭킹에 제출하지 않는다.

## 30초 가이드 계약

> 2×2 구멍에서 준비 두더지 한 마리로 손을 풀어요. 다음 황금 두더지 한 마리가 진짜 기록입니다. 황금 반응시간은 2배로 더해져요. 준비판은 점수에 포함되지 않고, 실전 빈 구멍은 +1,000ms, 놓치면 +4,000ms예요. 최종 ms가 낮을수록 좋은 기록입니다.

- 목표: 준비 표적 1개와 실제 기록 표적 1개를 완료한다.
- 조작: 4개 구멍 중 표적이 보이는 구멍을 새 터치로 누른다.
- 점수: 실제 황금 표적이 보인 시점부터 첫 유효 터치까지의 ms를 2배로 합산한다. 준비판 반응시간은 별도로 보여 주되 최종 점수에는 넣지 않는다.
- 실수: 준비판의 빈 구멍·놓침은 연습 피드백만 주고 점수에 넣지 않는다. 실전에서 빈 구멍 또는 현재 표적이 아닌 구멍을 누를 때마다 +1,000ms, 황금 표적을 1,500ms 안에 누르지 못하면 +4,000ms를 더하고 종료한다.
- 실패 조건: 실전의 실수는 즉시 게임오버가 아니다. 180초 안에 실제 표적을 끝내지 못한 타임아웃과 앱 이탈·중단만 랭킹 제출 불가 상태가 된다.
- 예상 읽기 시간: 약 18~20초

## 핵심 루프

- 초기 상태:
  - 에셋과 난수 시드를 준비하고, 2×2의 분리된 4개 구멍을 표시한다.
  - 카운트다운 3.2초 동안은 표적을 생성하지 않고 터치를 받지 않는다.
  - 카운트다운이 끝나면 이벤트 인덱스 0, 누적 가중 시간 0ms, 실수 0회로 시작한다. 첫 이벤트는 준비판이다.
- 반복 행동:
  1. 다음 이벤트의 대기시간(3~8초)을 지난다. 이 시간은 점수에 포함하지 않는다.
  2. 이벤트 1에서는 일반 픽셀 두더지가 준비판으로, 이벤트 2에서는 같은 실루엣의 황금 두더지가 실제 기록판으로 4개 구멍 중 하나에서 판별 가능한 모습으로 올라온다.
  3. 필요한 얼굴·몸 픽셀이 모두 보이는 공개 임계점에 도달하면 반응 측정을 시작한다. 공개 임계점 전에는 표적의 어떤 픽셀·그림자·반짝임도 화면에 그리지 않는다.
  4. 플레이어가 표적 구멍을 새로 누르면 첫 pointer-down 시각을 반응 종료 시각으로 확정한다.
  5. 준비판은 실제 반응시간 `r`을 연습 결과로만 저장한다. 실전 황금은 `2r`을 최종 합계에 더한다. 유효 터치 순간에 해당 반응 측정을 끝내고, 타격 FX·settle 시간은 total에 더하지 않은 채 wall-clock만 계속 흐르게 한 뒤 완료 연출로 넘어간다.
- 표적 반응시간:
  - 측정은 단조 증가(monotonic) 클록으로 한다.
  - 공개 임계점 이전에는 표적의 어떤 픽셀·그림자·골드 광택·흙먼지·소리·햅틱도 예고로 제공하지 않는다. 임계점 이후에만 얼굴과 몸이 보이고 측정을 시작한다.
  - raw delta가 유한하고 단조 증가하며 `0≤delta≤1,500ms`인지 먼저 검증한다. 공개 시각보다 이른 pointer-down, 음수·비정상 timestamp, 1,500ms 밖의 입력을 1ms로 보정하지 않는다. 전자는 무효 입력/사건 순서 오류로 거부하고 후자는 놓침으로 처리한다.
  - 검증을 통과한 delta만 정수 ms로 변환한다. 정상 입력이 동일 monotonic tick에 들어와 0ms가 되는 경우에는 1ms 표시 해상도 floor를 적용하는 것을 가설로 둔다.
  - 렌더러의 frame callback은 실제 디스플레이의 첫 물리적 가시 시점을 보장하지 않는다. 게임은 논리 공개 상태와 monotonic 시각을 일치시키고, 기기 계측·실기에서 오차를 확인할 수 있지만 물리적 첫 광자 시각을 주장하지 않는다.
- 빈 구멍·오답:
  - 준비판 대기·활성 중 빈 구멍을 누르면 연습 피드백만 주고 점수에는 넣지 않는다. 실전 대기 중 빈 구멍을 누르거나, 표적이 활성화된 동안 다른 구멍을 누르면 입력 1회마다 +1,000ms를 더한다.
  - 표적과 타이머는 그대로 유지한다. 오답은 표적을 옮기거나 반응시간을 재시작하지 않는다.
  - 대기·정답 확정 연출 중 손가락을 계속 누르고 있던 입력은 다음 회차의 정답으로 이어지지 않는다. 손가락을 계속 누른 것은 새 pointer-down이 아니며, 정답 뒤에 새로 발생한 pointer-down은 settle 중 빈 구멍 실수로 +1,000ms가 된다.
- 놓침:
  - 표적은 최대 1,500ms 동안 활성화된다.
  - 준비판 시간이 끝나면 연습 놓침으로 표시하고 점수 없이 다음 이벤트로 넘어간다. 실전 황금 시간이 끝나면 +4,000ms를 더하고 최종 결과로 간다.
  - 같은 이벤트를 재등장시키지 않는다.
- 황금 두더지:
  - 반드시 두 번째이자 마지막 이벤트에서만 등장한다. 일반과 같은 구멍 크기·표시 크기·활성 시간·입력 규칙을 사용한다.
  - 외형은 새 캐릭터를 만들지 않고 사용자가 지정한 엄지척 두더지 이미지를 그대로 기준으로 삼으며, 털 영역만 금색으로 변환한다.
  - 일반 시트와 달리 첨부 원본의 픽셀 느낌과 엄지척 포즈를 보존해 한 번뿐인 실전 이벤트라는 인상을 준다.
  - 정답이면 실제 반응시간은 `r`로 별도 보관하고, 제출용 가중 합계에는 `2r`을 넣는다.
  - 금빛 픽셀 파편, 짧은 반짝임, 일반보다 강한 성공 햅틱, `황금! ×2` 표시를 제공한다. pointer-down 즉시 황금 반응 측정을 끝내고, FX는 total에 더하지 않으며 wall-clock deadline은 계속 흐른다. 연출은 0.4초 이내에 끝낸다.
- 완료:
  - 준비 1회와 황금 1회가 모두 해소되면 0.25~0.5초 결과 연출 후 한 번만 `finished(clear)`로 전환한다.
  - 정상 완료가 세션 deadline 안에 이뤄지고 합계가 랭킹 범위 안이면 결과를 제출한다.
- 실패·중단:
  - 이벤트 놓침은 플레이를 끝내지 않는다.
  - 세션 deadline을 넘으면 `finished(timeout)`으로 전환하고 랭킹 결과를 제출하지 않는다.
  - 앱이 백그라운드로 가거나 엔진이 중단되면 `interrupted`로 전환하고 점수를 만들지 않는다.

## 입력 계약

- 제스처: 각 구멍의 비중첩 터치 영역에서 pointer-down 한 번으로 판정한다. 드래그, hover, pointer-up은 판정하지 않는다.
- 유효 터치 영역: 2×2 보드의 4개 구멍 각각이 자신의 직사각형을 소유한다. 보이는 구멍과 터치 영역의 중심을 맞추며, 구멍 사이에 겹치는 확장 hitbox를 두지 않는다. 최종 좌표와 여백은 에셋 작업자 manifest와 런타임 레이아웃이 함께 확정한다.
- 임계값과 데드존: 현재 활성 이벤트가 없거나 선택한 구멍이 표적 구멍이 아니면 무효 터치다. 표적 판정은 그 구멍의 전체 터치 영역에서 허용한다.
- 누름과 재터치: pointer-down 시각만 읽는다. 누르고 있던 손가락이 표적 위로 이동해도 정답이 아니며, 손을 뗀 뒤 새로 누른 입력만 새 터치다. 유효 정답 뒤 새 pointer-down은 다음 회차 정답이 아니고 settle 중 빈 구멍 실수로 처리한다.
- 멀티터치: 같은 monotonic timestamp로 도착한 pointer-down은 상태를 바꾸기 전의 이벤트 snapshot으로 한 배치에 묶어 모든 포인터의 구멍을 판정한다. 표적 구멍과 일치하는 포인터는 최대 하나만 정답으로 인정하고, 같은 배치의 나머지 비표적 포인터는 정답 확정 여부와 관계없이 각각 +1,000ms다. 같은 표적을 중복한 포인터에는 추가 보상을 주지 않는다.
- 시간순 입력: timestamp가 서로 다른 pointer-down은 도착 시점의 현재 상태로 처리한다. 유효 정답 뒤 settle 중에 새로 들어온 구멍 pointer-down도 빈 구멍 실수로 +1,000ms이며, 다음 회차 정답으로 승격되지 않는다. 카운트다운과 terminal 상태의 입력만 무시한다.
- 대기 중 입력: 카운트다운 중에는 완전히 무시한다. 카운트다운 뒤 대기 중 구멍을 누르면 빈 구멍 실수로 +1,000ms를 더하되, 다음 등장 위치나 대기시간을 바꾸지 않는다. 표적 공개 전에 누른 입력을 공개 후의 정답으로 재사용하지 않는다.
- 유효 피드백: 일반 정답은 짧은 눌림·흙먼지·가벼운 햅틱과 `Nms` 표시를 준다. 황금 정답은 금빛 파편과 강한 성공 햅틱을 추가한다.
- 무효 피드백: 오답 구멍을 0.12~0.18초 흔들고 `빈 구멍 +1,000ms` 또는 `다른 구멍 +1,000ms`를 표시한다. 피드백은 다음 표적 위치를 가리지 않는다.
- 놓침 피드백: 표적이 구멍 아래로 내려가고 `놓침 +2,000ms` 또는 `황금 놓침 +4,000ms`를 표시한다. 게임오버 연출은 하지 않는다.

## 상태 머신

```text
loading
  → countdown
  → waiting(event 1..2)
      → active_target(normal/golden)
          ├─ valid tap → resolve_hit → settle → waiting(next)
          └─ 1,500ms expiry → resolve_miss → settle → waiting(next)
      → settle
          └─ new pointer-down → +1,000ms invalid tap → settle
  → finished(clear, eligible result)
  ├─ deadline 180s → finished(timeout, no rank)
  └─ app background/engine stop → interrupted(no rank)
```

- `loading` 실패나 필수 에셋 준비 실패는 결과 없이 `interrupted`로 종료한다.
- 카운트다운과 모든 대기 상태에는 실패 가능한 표적이 없다. 입력은 계약에 따라 무시하거나 실수로만 기록한다.
- `resolve_hit`와 `resolve_miss`는 이벤트 카운트를 정확히 한 번만 증가시킨다. 유효 pointer-down에서 반응 계측은 즉시 끝나며, `settle`의 FX 시간은 `totalMs`에서 제외하고 wall-clock deadline은 계속 적용한다.
- `settle`은 짧은 표정·흙먼지·금빛 FX를 재생하는 상태다. 이 상태의 새 pointer-down은 +1,000ms 무효 입력으로 처리하고, hold·drag에는 새 입력을 만들지 않는다. 카운트다운·terminal 입력만 무시한다.
- 두 번째 이벤트가 해소되면 다음 이벤트를 예약하지 않고 완료 연출로 간다.
- 모든 정상 완료 경로는 원자적 종료 보호를 거쳐 결과 콜백을 최대 한 번만 보낸다.

| 실전 진입 | 이벤트 2 | 준비 뒤 다시 집중을 끌어올리기 | 황금·×2 공개 | 진짜 표적 전 마지막 정적 |
| 숙련 구간 | 실전 1회 | 단 한 번의 반응 품질 유지 | 1,500ms 창 고정 | 오답·놓침이 최종 기록에 반영 |
| 절대 상한 | 세션 deadline 180초 | 미완료 시 랭킹 불가 | 타임아웃 | 진단용 상태만 보존 |

이 게임은 시간이 흐르면서 표적이 작아지거나 빨라지지 않는다. 매 회차가 같은 1,500ms 반응 창을 사용하며, 난도는 긴 대기 뒤의 집중 유지와 4개 위치 탐색에서 생긴다. 정확한 반응속도를 비교하기 위해 후반 자동 가속과 규칙 변경은 두지 않는다.

- 최소 반응시간: 유효 delta만 정수 ms로 변환하고, 정상 동일 tick의 0ms는 1ms 표시 해상도 floor로 기록하는 가설을 둔다. 공개 전·음수·비정상 timestamp는 1ms로 clamp하지 않고 거부한다. 화면에 표시하는 ms는 게임 클록의 정수 표시이며, 기기 주사율·터치·렌더링 지연을 포함한 게임 내 측정값이다. 임상적 반응속도나 실제 인간 반응의 1ms 정확도를 주장하지 않는다.
- 함께 변할 수 있는 변수: 없다. 3~8초 대기, 1,500ms 표적 창, 구멍 크기, 황금 ×2는 매 이벤트와 모든 진행도에서 동일하다.
- 상한의 이유: 세션 deadline은 랜덤 대기와 입력 이상으로 판정이 영원히 지연되는 것을 막으며, 규칙을 바꾸지 않고도 완주·타임아웃을 명확히 한다.
- 목표 기록대(가설, 실전 황금 적중): 초보 가중 합계 700~1,500ms, 중급 350~700ms, 숙련 2~350ms. 실제 분포는 실기 측정 후 벌점·표적 창을 우선 조정한다.

- 수작업 스테이지: 없음.
- 재사용 패턴: 4개 구멍 슬롯, 이벤트 대기·등장·정답·놓침 상태, 일반/황금 색상 변형, 정답 ms 팝업, 흙먼지와 금빛 파편.

## 무작위성과 한 번의 시도 공정성

- 난수 주입: 운영 플레이는 매 실행마다 새 `challengeSeed`를 주입해 직전 판의 표적 위치·대기 순서를 외우지 못하게 한다. 규칙 테스트와 재현 가능한 디버그 실행은 명시적으로 주입한 시드를 사용한다.
- 무작위 요소: 각 이벤트의 3~8초 대기와 구멍 위치. 준비 일반 1회 뒤 황금 실전 1회가 마지막 이벤트로 고정된다.
- 지연 생성 제약: 두 이벤트 모두 3~8초 범위에서 시드로 재현 가능한 대기를 선택한다. 두 이벤트의 대기 길이는 가능한 경우 서로 다르게 만든다.
- 위치 생성 제약: 4개 구멍은 동일한 선택 가중치를 가지며, 준비와 실전은 서로 다른 구멍에서 시작한다. “항상 특정 구멍”이라는 예측 규칙을 만들지 않는다.
- 황금 생성 제약: 황금은 이벤트 2에서 정확히 한 번, 일반과 동일한 위치 후보 규칙으로 생성한다. 등장 전 황금 위치·시각을 알려 주는 효과는 없다.
- 안전 시작: 카운트다운 3.2초 동안 표적과 실패 입력이 없다. 첫 표적은 카운트다운 후 3~8초 대기 뒤에 나타난다.
- 최소 반응·회복 기회: 표적은 1,500ms 동안 안정적으로 보이고, 4개 구멍의 터치 영역은 표적이 올라오는 동안 움직이지 않는다. 정답이나 놓침 뒤 0.25~0.5초 settle 후 다음 대기를 시작한다.
- 피할 수 없는 손실 방지: 표적은 화면 밖이나 겹친 구멍에 만들지 않는다. 대기시간은 기록에 포함되지 않으며, 준비판의 실수는 기록에 넣지 않는다. 실전 오답은 표적을 제거하지 않고 1,500ms 창을 끝까지 유지한다.
- 생성 실패 fallback: 합법 위치 후보가 부족하면 해당 이벤트를 이미 사용하지 않은 구멍 중 하나에 놓는다. 그래도 런타임 레이아웃 검증을 통과하지 못하면 결과 없이 중단하며, 위험한 표적을 강제로 만들지 않는다.
- 필수 진행과 보너스: 모든 두더지는 필수 표적이다. 황금은 보너스 선택지가 아니라 반드시 눌러야 하는 한 회차이며, 황금 적중의 보상은 금빛 피드백과 가중 시간 규칙이다.
- 미래 표적 공개: 2개 이벤트는 시작 전에 시드로 생성해 판정 재현성을 확보하지만, 미래의 위치·대기시간은 HUD와 배경에 표시하지 않는다. 황금 여부는 마지막 이벤트에만 규칙으로 정해져도 등장 전 외형을 예고하지 않는다. 이 게임에서는 준비 뒤 미래를 보지 못한 채 한 번의 실전에 반응하는 것이 핵심이며, 카메라 이동이나 갑작스러운 화면 팝인은 없다.
- 안티 스톨·안티 익스플로잇:
  - 누르고 기다리거나 구멍 위에 손가락을 올려 둔 상태는 정답이 아니다.
  - pointer-down 이전에 입력한 터치는 등장 후 정답으로 승격되지 않는다.
- 실전 대기 중 빈 구멍 탭은 +1,000ms이므로 미리 여러 곳을 누르는 전략이 유리하지 않다. 준비판 대기 중 입력은 기록에서 제외한다.
  - 손가락을 떼지 않은 채 다른 구멍으로 드래그해도 새 입력이 아니다.
  - 앱 백그라운드·일시중지는 시간을 멈춰 기록을 보존하지 않고 중단으로 처리한다.
- 실패 피드백: 오답 구멍, 놓친 두더지, 황금 놓침을 서로 다른 문구·색상·표정으로 표시해 원인을 알 수 있게 한다.

## 점수와 랭킹

- 플레이어 표시값: `최종 494ms`처럼 쉼표가 있는 낮은 시간. `기록 = 실전 황금 가중 반응시간 + 실수·놓침 벌점`이라고 함께 표시한다.
- HUD 값:
  - 상단: `준비 0/1` 또는 `진짜 0/1` 진행도와 실전 `누적 ms` 가중 합계
  - 이벤트 결과: 준비 `연습 218ms`와 실전 `황금 실제 218ms · 가중 436ms`를 구분
  - 황금 이벤트: `황금 실제 218ms · 가중 436ms`를 별도 표시
  - 결과: `실제 반응 합계`, `가중 합계`, `벌점`, `평균 반응`을 분리
- 원시 반응 합계: 실전 황금의 실제 반응시간 `r`만 저장한다. 준비 반응은 별도 연습 값이다.
- 가중 반응 합계: 실전 황금 적중 `2r`만 더한다.
- 벌점 합계: `1,000 × invalidTapCount + 4,000 × goldenMissCount`. 준비판 벌점·놓침은 합계에서 제외한다.
- 표시 이벤트 합계:

  ```text
  totalMs = weightedReactionTotal + penaltyTotal
  ```

- 황금 실제·가중 분리:
  - `goldenActualMs = r`
  - `goldenWeightedMs = 2r`
  - 황금 적중 후 `totalMs`에는 후자만 한 번 더한다. 황금 시간을 실제·가중 두 방식으로 중복 합산하지 않는다.
- 평균 반응:
  - 준비와 실전 모두 적중하면 준비 반응과 실전 실제 반응을 나란히 보여 준다. 평균은 참고용으로만 표시한다.
  - 실전 황금을 놓치면 평균 대신 `실전 놓침`을 보여 주고 최종 기록에는 +4,000ms가 남는다.
  - 평균은 참고용이며 랭킹 정렬은 오직 `totalMs`다.
- 제출 정수: `submittedScore = 1,000,000 - totalMs`.
- 높은 점수 인코딩: 게임 화면과 결과는 낮은 `totalMs`가 좋고, 공통 랭킹에는 높은 `submittedScore`가 먼저 오도록 역변환한다.
- 표시 formatter와 역변환: 제출 전 `totalMs`를 `1,000,000 - totalMs`로 변환하고, 표시할 때는 `1,000,000 - submittedScore`로 되돌린 뒤 `Nms`로 포맷한다.
- 정밀도와 범위: 반응시간과 벌점은 정수 ms다. 준비판은 제외하므로 정상 적중의 이론상 최소 합계는 황금 1회 `×2ms`인 `2ms`다. `totalMs`는 합산 중 64비트 정수로 보존하고 `2 ≤ totalMs < 1,000,000`만 유효 랭킹 범위로 둔다. `totalMs < 2` 또는 `totalMs ≥ 1,000,000`은 점수를 억지로 자르지 않고 malformed/invalid no-rank로 처리한다.
- 동점: 같은 `totalMs`는 같은 제출 정수가 되며 공통 랭킹의 기존 규칙에 따라 먼저 제출한 기록이 앞선다.
- 실수·놓침 완료: 준비 1회와 실전 1회를 deadline 안에 완료하고 합계가 유효 범위면 정상 랭킹 제출한다. 실전 놓침이 있다는 이유만으로 즉시 탈락시키지 않는다.
- 타임아웃: 180초 deadline에 미완료이면 로컬 진단값만 보존하고 랭킹 결과를 제출하지 않는다.
- 중단: 앱 이탈·백그라운드·엔진 중단은 점수와 순위를 제출하지 않는다. 시도 소진 여부는 공통 플레이 수명주기 정책을 따른다.
- 결과 보조 필드: `totalMs`, `rawReactionTotalMs`, `weightedReactionTotalMs`, `penaltyMs`, `caughtCount`, `missCount`, `invalidTapCount`, `goldenActualMs`, `goldenWeightedMs`, `durationMs`, `endType`, `rulesVersion`.
- 측정 한계: 표시 ms는 게임 안의 비교 가능한 기록이며 기기별 입력·프레임 지연의 영향을 받는다. “사람의 순수 신경 반응을 1ms 정밀도로 측정”한다는 문구는 사용하지 않는다.

## 프레젠테이션 의존성

### 2D 비주얼 콘셉트

- 테마와 장소: 햇빛이 약하게 드는 작은 텃밭. 낮은 흙밭 위에 2×2 구멍이 별도의 둥근 흙 테두리로 정렬된다.
- 카메라/뷰: 세로 고정 시점의 2D 보드. 기준 카메라는 논리 `360×800`이며, 구체적인 홀 사각형과 HUD 여백은 에셋 작업자 manifest·런타임 레이아웃이 공동 관리한다.
- 배경 기술 계약: 소스 배경은 약 `180×480` 픽셀이고 2배 최근접으로 런타임 `360×960`에 표시한다. 카메라 중심과 오버스캔을 유지하고, 게임플레이 안전 코어는 논리 `360×640`, 월드 `y=160..800`으로 잡는다. 긴 화면 위아래에 배경이 남아도 구멍 판정은 안전 코어 안에 둔다.
- 분위기: 고요하고 따뜻한 오후의 흙색과 올리브색. 오랜 정적 뒤 얼굴 하나가 갑자기 나타나는 순간이 코믹한 긴장을 만든다.
- 콤팩트한 시각 개그: 친구를 닮은 두더지가 매번 태연한 미소로 올라오며, 잡히는 순간 눈이 커지고 볼이 눌린다. 마지막 황금 두더지는 같은 픽셀 얼굴로 엄지척을 하며 금빛으로 등장한다.
- 아트 방향: 일반·황금 모두 기존 16비트 픽셀아트 감각의 2×2 시트를 사용한다. 일반은 갈색 팔레트, 황금은 같은 프레임을 금색 팔레트로 변환해 마지막 이벤트에서 즉시 구분한다.
- 겉보기 아트 크기: 두더지는 `256×256` 소스 셀을 런타임 `96×96`으로 nearest 표시한다. 일반·황금의 픽셀 클러스터와 표시 배율은 동일하며, 배경은 `180×480 → 360×960`을 유지한다.
- 게임플레이 대비 계층: 현재 표적의 얼굴·실루엣 > 가중 누적시간과 진행도 > 구멍 테두리 > 텃밭 장식. 황금 정답 이펙트는 적중 뒤에만 강하게 나타나며, 등장 전 예고로 반응을 유도하지 않는다.
- 팔레트 분위기: 짙은 흙갈색과 올리브 잎, 크림색 얼굴, 짙은 갈색 눈썹, 일반 두더지의 따뜻한 갈색 털가죽, 황금 두더지의 노랑·황토 금색 털가죽, 성공 FX의 옅은 금빛.

### 플레이어 주체

- 역할: 4개 구멍에서 튀어나오는 표적 두더지. 플레이어의 아바타는 별도로 두지 않는다.
- 실루엣과 비율: 목 없이 이어진 통통한 쐐기형 굴 파기 몸, 얼굴·어깨·앞발·상부 배가 함께 보이는 작은 두더지. 큰 삽 모양 앞발과 낮은 어깨로 96×96 표시에서도 구멍 안에 안정적으로 들어간다.
- 얼굴: 첨부 사진을 사실적으로 복사하지 않고, 두껍고 완만한 눈썹, 작은 눈, 돌출된 분홍 두더지 코, 짧은 주둥이의 수염, 입을 다문 은근한 미소를 단순화된 픽셀 표정 기호로 쓴다. 일반과 황금은 같은 픽셀 얼굴 앵커를 공유한다.
- 어색하고 귀여운 특징: 무슨 일이 있어도 여유로운 표정을 유지하려 하지만, 맞는 순간 눈이 커지고 양 볼이 눌린다.
- 정체성 표식: 둥근 털가죽, 작은 눈, 긴 분홍 코, 짧은 수염, 두꺼운 눈썹, 삽처럼 넓은 앞발과 다문 미소의 조합. 일반과 황금 두더지가 이 얼굴·몸 앵커를 공유해 같은 친구 두더지 계열로 읽힌다.
- 사람 머리카락은 사용하지 않는다. 인간형 헤어스타일·앞머리·가르마·검은 머리카락을 금지하고, 머리 전체를 털가죽이 이어지는 둥근 두더지 실루엣으로 표현한다.
- 일반 두더지: 현재는 하나의 따뜻한 갈색 마스터를 사용한다. 밝은 주둥이·배 패치와 짙은 눈썹, 분홍 코, 수염, 크림색 발톱은 공통으로 유지한다.
- 황금 두더지: 일반 픽셀 마스터의 얼굴·몸·포즈·프레임을 유지하고 털 영역만 금색으로 변환한다. 금빛 파편과 ×2 피드백은 적중 후에만 붙이며, 크기와 터치 판정은 일반과 같다.
- 필요한 동작:
  - 등장/대기: 구멍 테두리 뒤에서 몸이 올라오고, 판별 가능한 얼굴로 1프레임 이상 안정된다.
  - 적중: 눈이 커지고 양 볼이 눌리는 2~3프레임 피격 표정.
  - 놓침: 아쉬운 듯 한쪽 입꼬리를 유지한 채 구멍 아래로 내려가는 2프레임.
- 황금 적중: 픽셀 엄지척 포즈를 유지한 채 금빛 파편과 ×2 표식을 보여 준다. 일반과 같은 원본 실루엣이라도 금색과 엄지척으로 보상 표적임을 구분한다.
- 연출 포즈: 오프닝은 비어 있는 구멍과 조용한 배경, 압박은 정적 뒤 단일 얼굴, 성공은 `Nms`와 흙먼지, 황금 성공은 금빛 파편·반짝임, 실패는 표적이 내려가며 원인을 설명하는 문구다.

### 시각적 역할

- 목표물: 준비 일반 두더지 1회와 실전 황금 두더지 1회. 둘 다 “보이면 누르는 것”이며 준비는 기록에서 제외하고 황금만 가중 시간이 다르다.
- 위험물: 물리적 장애물과 누르지 말아야 하는 캐릭터는 없다. 비어 있는 구멍과 다른 구멍은 잘못 누르면 시간 벌점을 주는 입력 대상이다.
- 픽업: 없음. 황금은 별도 선택지가 아니라 필수 표적의 가중 변형이다.
- 안전 영역: 4개 구멍의 비중첩 터치 영역과 그 주위의 정지된 텃밭 보드. 배경 장식은 터치 영역을 침범하지 않는다.
- 경고 언어: 시작 카드에는 `최대한 빠르게 두더지를 잡으세요!`를 표시한다. 각 표적을 기다리는 동안 보드 위에 `첫 두더지는 연습이에요!` 또는 `이번엔 진짜에요!`를 CLEAR 타이틀과 같은 큰 픽셀 타이포그래피로 표시한다. 위치를 미리 알려 주는 화살표·글로우·소리는 사용하지 않는다.
- 적중·근접 피드백: 적중한 구멍의 흙 테두리가 0.18초 눌리고, 얼굴이 찌그러지며 `218ms`가 떠오른다. 1,500ms 안에 누르지 못한 경우 표적이 사라지는 순간 `놓침`을 보여 준다.
- 성공 피드백: 일반은 작은 흙먼지와 가벼운 햅틱, 황금은 픽셀 엄지척 포즈 위에 금빛 파편·짧은 스파클·강한 성공 햅틱과 `황금! ×2`를 붙인다. 화면 전체 플래시나 큰 흔들림은 사용하지 않는다.
- 배경 동작: 대기·표적·settle 중에는 하단의 안전한 흙길에서 작은 개미가 4프레임으로 왕복하고, 상단의 안전한 흙길에서는 지렁이가 느리게 기어간다. 둘 다 분위기용 비대상 장식이며 두더지가 등장해도 계속 보인다. 구멍 위치·표적 예고·터치 판정에는 영향을 주지 않는다.
- HUD 관계: 상단 안전 영역에 `준비 0/1` 또는 `진짜 0/1`, 가중 `누적 ms`, 마지막 이벤트 결과를 둔다. 얼굴과 구멍을 가리지 않도록 이벤트 문구는 표적 아래 또는 상단 결과 띠에 배치한다.
- 가이드 비주얼: 3페이지를 권장한다. 1페이지는 2×2 보드와 준비 표적 터치, 2페이지는 실전 황금 두더지와 `황금 실제 218ms → 가중 436ms`, 3페이지는 실전 대기 중 미리 누르면 +1,000ms와 놓침 +4,000ms를 보여 준다. 가이드의 긴 대기는 제작상 축약하며 실제 3~8초 타이밍을 시연한다고 주장하지 않는다.
- 가이드 장면 비율·랜드마크: 세로 9:16 계열. 4개 구멍, 상단 진행도, 하나의 얼굴, 하단 ms 문구가 한 장면에서 모두 보여야 한다. 일반과 황금 모두 실제 런타임 픽셀 시트를 재사용한다.
- 홈 미리보기: 2×2 보드 중앙 또는 약간 아래쪽의 한 구멍에서 일반 두더지와 금색 파편이 올라오는 정적 장면. 크롭 앵커는 보드 중앙이며, 상단 제목과 4개 구멍이 잘리지 않아야 한다. 골드 이펙트는 적중 후 장면임을 명시하는 작은 `×2` 배지로만 쓴다.

### 런타임 기하 계약

| 역할 | 소스/불투명 bounds | 렌더 크기 | 터치·판정 기하 | 회전/경로 반경 | 가장자리 여유 |
|---|---|---:|---|---|---|
| 일반 두더지 | 소스 셀 `256×256`, 얼굴·몸 불투명 영역 중심 | `96×96` | 해당 구멍의 비중첩 터치 직사각형 전체. 구멍을 떠나지 않는 고정 표적 | 없음 | manifest가 정한 홀 간격만 사용 |
| 황금 두더지 | 픽셀 마스터 기반 `256×256` 소스 셀·불투명 앵커 | `96×96` | 일반과 정확히 같은 구멍 터치 직사각형·활성 창 | 없음 | 일반과 동일 |

구멍 간격, 상단 HUD와 보드 사이의 실제 좌표, 소스 파일의 atlas 열·행 순서는 에셋 작업자 manifest를 단일 기준으로 삼는다. 이 문서에서 새로운 좌표를 임의로 만들어 에셋과 판정이 갈라지지 않게 한다.

- 재사용 가능 에셋: 픽셀 일반 시트의 공통 얼굴 앵커·등장/놓침 프레임, 동일 실루엣 황금 시트, 구멍·흙 테두리, HUD, 가이드와 홈 미리보기. 황금은 같은 프레임을 금색 팔레트로 읽어 게임 규칙과 연결한다.
- `build-game-assets`로 정확히 정할 항목: 셀 내부 불투명 bounds, 명암 단계, 골드 팔레트, 파편 수, 최종 표정 프레임 수, 가이드 crop과 파일명.
- 사운드·햅틱: 표적 등장 전에는 소리·햅틱을 주지 않는다. 일반 적중은 짧은 tap haptic, 황금 적중은 한 단계 강한 success haptic과 짧은 금속성 음, 오답은 약한 reject haptic을 사용한다. 사운드 재생 지연은 시간 측정에 포함하지 않는다.

## 기술 적합성

- 런타임 접근: Flame의 고정 2D 보드와 기존 게임 수명주기. 4개 홀 슬롯, 하나의 활성 표적, monotonic reaction clock, 원자적 결과 방출만 필요하다.
- 재사용 프로젝트 구성요소: 공통 카운트다운·게임 종료 전환·세로 HUD·배경/구멍/FX nearest 렌더링·캐릭터별 필터·햅틱·결과/랭킹 제출 흐름.
- 순수 규칙 모듈: `MoleReactionRules`에 시드 생성, 준비 1회·실전 1회 이벤트 로스터, 지연·위치 제약, 실전 반응·벌점 합산, `1,000,000-totalMs` 역변환을 둔다.
- 중앙 튜닝 위치: `lib/features/games/mole_reaction/domain/mole_reaction_rules.dart`에 규칙 값을 모으고, 프레젠테이션은 해당 상수와 결과 모델만 읽는다.
- 백엔드·레지스트리 영향: `mole_reaction`을 게임 레지스트리와 daily rule version `1`에 연결했고, 서버는 `totalMs` 역변환 점수·180초 timeout·`8 ≤ totalMs < 1,000,000` 범위를 검증한다. 정상 완료만 점수를 제출하고 timeout·중단은 no-rank로 처리한다.
- 주요 구현 위험:
  - 표적 공개 프레임과 pointer-down timestamp가 같은 monotonic 시간 기준을 쓰지 않으면 표시 ms가 흔들릴 수 있다.
  - 구멍 touch rect가 시각 구멍과 겹치거나 좁으면 위치 이동 능력보다 좌표 오판이 점수를 좌우한다.
  - 3~8초 대기가 너무 길게 느껴지면 반응 테스트보다 지루한 대기 게임이 될 수 있다.
  - 황금 ×2와 황금 놓침 ×2가 전체 기록을 과도하게 좌우하는지 별도 검증해야 한다.
  - 360×800 카메라와 360×960 배경 오버스캔이 기기별 safe area에서 홀·HUD를 밀지 않는지 확인해야 한다.

## 인수 테스트

- 20초 안에 목표·조작·황금 ×2·빈 구멍 벌점·최종 기록 방향을 이해할 수 있다.
- 친구 얼굴 특징을 참고한 일반 픽셀 표정과 동일 실루엣 황금 표정이 작은 화면에서 읽히며, 표적 구분을 해치지 않는다.
- 2×2 4개 구멍과 배경의 2× 스케일이 360 논리 폭에서 일치한다.
- 3.2초 카운트다운 중 표적·실패 가능 입력이 없다.
- 정확히 준비 일반 1회와 황금 실전 1회, 총 2회가 생성된다. 황금은 항상 이벤트 2(마지막)에만 나온다.
- 각 대기시간이 3~8초 범위이고 테스트 시드에서 균형 규칙과 셔플 결과가 재현된다.
- 실행 시 새 시드가 사용되고, 테스트에서는 주입 시드로 같은 로스터를 다시 만든다.
- 공개 임계점 전에는 표적의 어떤 픽셀·그림자·반짝임·사운드·햅틱도 없고, 필요한 얼굴·몸 픽셀이 모두 보인 논리 공개 상태부터 1,500ms를 측정한다. frame callback이 실제 물리적 가시 시점을 보장하지 않는다는 한계를 기록하고 실기 계측으로 오차를 확인한다.
- 공개 전 pointer-down, 음수·비정상 timestamp, 1,500ms 밖의 입력이 1ms로 clamp되지 않으며, 정상 동일 tick만 1ms floor 가설을 적용한다.
- 유효 pointer-down 즉시 반응 계측이 끝나고, 이후 FX·settle 시간은 total에서 빠지며 wall-clock deadline은 계속 흐른다.
- 4개 터치 영역이 서로 겹치지 않고, 시각적 구멍과 표적 판정 구멍이 같다.
- pointer-down만 정답이며, hold·drag·pointer-up·미리 누른 입력이 다음 표적을 맞히지 않는다.
- 같은 timestamp 배치는 이벤트 시작 snapshot으로 모든 포인터를 판정하고, 정답은 최대 한 개, 나머지 비표적 포인터는 각각 +1,000ms다. 서로 다른 timestamp의 settle 중 새 pointer-down도 +1,000ms이며, countdown·terminal만 입력을 무시한다.
- 빈 구멍·오답 입력마다 +1,000ms가 정확히 한 번 더해지고, 오답이 표적·반응 계측·이벤트 순서를 바꾸지 않는다.
- 일반 적중은 `r`, 황금 적중은 실제 `r`과 가중 `2r`을 분리 저장하고 total에는 `2r`만 들어간다.
- 일반 놓침은 +2,000ms, 황금 놓침은 +4,000ms 가설값을 사용하며, 표적이 재등장하지 않는다.
- 2회 완료·timeout·interrupted 각각이 종료 결과를 최대 한 번만 방출한다.
- 완료 시 `totalMs = weightedReactionTotal + penaltyTotal`이 정확하고, 낮은 total이 높은 제출 점수로 왕복 변환된다.
- 이론상 최소 `totalMs`는 실전 황금 1×2ms = `2ms`이며, `2 ≤ totalMs < 1,000,000`만 랭킹 제출된다. 그 밖의 값은 overflow 없이 malformed/no-rank 처리된다.
- timeout과 interruption에는 랭킹 제출이 없고, 정상 완료의 동점은 공통 선제 제출 규칙을 따른다.
- 황금 적중에만 금빛 파편·×2 문구·강한 성공 피드백이 붙고 등장 전 예고 효과는 없다.
- 배경 장식·FX·HUD가 표적을 가리거나 터치 영역을 움직이지 않는다.
- 카운트다운·대기·적중·놓침·완료·중단이 지원 휴대폰 viewport에서 같은 보드 기하를 유지한다.
- 앱 백그라운드와 복귀가 시간을 멈춰 점수를 유리하게 보존하지 않고 interrupted로 처리된다.
- 가이드와 홈 미리보기가 실제 런타임 배경·일반 픽셀·황금 표정과 nearest 필터를 재사용하며, 가이드의 축약 타이밍을 production timing으로 오해하게 만들지 않는다.

## 밸런스 가설

- 가설: 3~8초 대기 2개와 하단 개미의 왕복 움직임이 준비·실전 모두에서 “미리 다음을 예측”하는 이점을 줄이고 평균 세션을 약 13~27초 안에 유지한다.
  - 필요한 증거: 초보·숙련 각 20회 이상의 실제 플레이에서 준비판 이탈률, 실전 전 집중 유지, 체감 지루함.
  - 조정 변수: 대기 분포와 settle 시간. 반응 창과 황금 ×2는 별도 결정 없이 바꾸지 않는다.
- 가설: 일반 준비와 황금 실전 모두의 1,500ms 표적 창은 대부분의 플레이어에게 본판 진입 기회를 주면서도 실전 놓침 +4,000ms가 의미 있는 손해가 된다.
  - 필요한 증거: 실전 진입률, 실전 반응시간, 1,500ms 경계 근처의 놓침 비율.
  - 조정 변수: 표적 활성 시간, 일반 놓침 대체값.
- 가설: 빈 구멍 +1,000ms가 손가락을 미리 깔아 두는 전략을 억제하고, 반복 오답을 기록상 명확히 손해로 만든다.
  - 필요한 증거: 기다리는 플레이와 선입력·연타 플레이의 평균 오답 수와 total 분포.
  - 조정 변수: invalid tap 벌점. 벌점을 0으로 낮추지 않는다.
- 가설: 황금 실제 반응시간 ×2와 황금 놓침 +4,000ms가 한 번의 특별 이벤트로 충분히 기억되지만 전체 기록을 운으로 바꾸지 않는다.
  - 필요한 증거: 황금 적중·놓침 비율, 일반 대비 황금 이벤트의 total 기여도, 점수 분산.
  - 조정 변수: 황금 놓침 대체값과 금빛 연출 길이. 사용자 승인 규칙인 황금 ×2 자체는 유지한다.
- 가설: 구멍별 최대 2회와 인접 반복 허용이 위치 운을 줄이면서도 “항상 다음 구멍은 다르다”는 메타 예측을 막는다.
  - 필요한 증거: 4개 위치별 표준화한 이동 거리, 위치별 평균 반응, 0회 등장 홀 비율.
  - 조정 변수: 위치 선택 가중과 반복 상한.
- 가설: 실행마다 새 시드를 사용해도 대기시간을 점수에서 제외하므로 랭킹은 반응·손 이동 실력 중심으로 유지된다.
  - 필요한 증거: 여러 시드의 위치 이동 거리와 total 상관, 동일 플레이어의 시드 간 편차.
  - 조정 변수: 위치 균형 제약. 시드를 고정해 외우는 방식으로 되돌리지 않는다.
- 가설: 정상 입력이 동일 monotonic tick에 들어온 0ms를 1ms로 표시하는 floor가 플랫폼별 정수 ms 양자화에서 일관된 최저 기록을 제공한다.
  - 필요한 증거: 주입 시계의 0·0.4·0.9·1.0ms 입력과 실제 기기 timestamp를 비교한 규칙 테스트·실기 계측.
  - 조정 변수: 정상 delta의 정수 변환 방식. 공개 전·음수·비정상 timestamp를 이 floor에 포함하지 않는다.

## 열린 질문

- 없음. 황금 놓침 +4,000ms, 대기·위치 분포, 1,500ms 창, 벌점 크기, 예상 기록대는 구현 전 실기 검증이 필요한 가설이며 승인된 핵심 루프를 다시 여는 질문이 아니다.
