# 엄마, 어디가

## 상태

- 상태: Implemented
- 게임 ID: `mama_duck_trail`
- 규칙 버전: 1
- 마지막 승인일: 2026-09-08

## 플레이어 약속

- 한 문장 약속: 비에 지워지는 엄마 오리의 발자국을 기억해 새끼 오리를 안전하게 인도한다.
- 코믹 전제: 엄마 오리는 습지를 너무 빨리 건너가고, 뒤늦게 따라가는 새끼 오리가 길을 틀리면 갈대밭에 숨은 늑대가 한입에 삼킨다.
- 핵심 실력: 짧은 시간 동안 경로의 순서와 방향을 기억하고 정확하게 재현하는 능력
- 세션 모델: 120초 고정 점수전, 목숨 3개 소진 시 조기 종료
- 예상 플레이 시간: 초보자 30~70초, 숙련자 최대 120초
- 절대 최대 시간: 120초

## 20초 가이드 계약

> 엄마 오리의 발자국을 기억하세요.  
> 비에 지워지면 출발점부터 같은 길을 드래그하세요.  
> 길을 틀리면 늑대가 오리를 잡아먹어요. 오리 세 마리를 지키며 최대한 많은 길을 완성하세요!

- 목표: 제한시간 동안 엄마 오리의 경로를 최대한 많이 완성한다.
- 조작: 출발 타일부터 손을 떼지 않고 상하좌우로 이어진 타일을 드래그한다.
- 점수 획득: 경로 전체를 정확히 재현하면 경로 길이와 연속 성공 수에 따라 점수를 얻는다.
- 주요 실패 조건: 잘못된 타일에 진입하면 현재 오리를 잃고, 오리 세 마리를 모두 잃으면 즉시 종료된다.
- 예상 읽기 시간: 약 15초

## 핵심 루프

- 초기 상태: 세로형 5×7 습지 타일 보드만 화면 대부분을 채우고 첫 실전 경로는 7칸으로 시작한다.
- 경로 제시: 엄마 오리가 합법적인 경로를 이동하며 밝은 발자국을 남긴다.
- 기억 구간: 엄마가 마지막 칸에 도착하면 발자국이 남아 있어도 출발점부터 바로 드래그할 수 있고, 입력이 없으면 비가 내려 순서대로 지운다.
- 반복 플레이 행동: 플레이어가 출발점에서 경로를 기억해 연속 드래그한다.
- 입력 반응: 확정된 올바른 타일에는 밝은 발자국을, 잘못된 타일에는 붉은 오답 발자국을 표시한다.
- 성공: 전체 경로를 정확히 재현하면 경로의 마지막 칸에는 엄마, 나머지 모든 칸에는 새끼 오리가 한 마리씩 들어온다. 선두는 엄마 바로 전 타일에서 멈추고 뒤따른 오리들은 차례로 기뻐한다. 다음 경로는 한 칸 길어진다.
- 실패: 첫 오답 타일이 확정되는 즉시 입력을 종료하고, 그때만 나타난 늑대가 입을 벌려 삼키는 동작으로 실패를 전달한다.
- 시간 초과: 120초가 되는 순간 진행 중인 미완성 경로는 점수 없이 종료하고 누적 점수를 제출한다.
- 완료: 120초 경과 또는 목숨 3개 소진 중 먼저 발생한 조건으로 정상 종료한다.

## 입력 계약

- 제스처: 한 손가락 연속 드래그
- 유효 시작 영역: 현재 경로의 출발 타일
- 유효 이동: 현재 타일과 상하좌우로 맞닿은 다음 타일
- 대각선 이동: 허용하지 않음
- 같은 타일 재방문: 허용하지 않음
- 손가락 판정: 셀 경계의 작은 흔들림은 무시하고, 다음 셀 내부로 충분히 진입했을 때만 이동을 확정한다.
- 임시 판정 가설: 셀 안쪽 40% 진입 시 확정, 경계 데드존 6 논리 픽셀
- 손 떼기: 목표까지 도달하기 전에 손을 떼면 해당 라운드를 실패 처리한다.
- 재터치: 한 라운드 중 재터치는 허용하지 않는다.
- 멀티터치: 최초 한 손가락만 사용하고 나머지 입력은 무시한다.
- 카운트다운 및 엄마 이동 중 입력: 게임 판정에 반영하지 않는다.
- 엄마 도착 후 입력: 발자국 유지·소멸 중에도 출발 타일을 누르면 즉시 회상 단계로 전환하고 같은 드래그의 첫 칸으로 확정한다.
- 유효 입력 피드백: 크림색 발자국과 짧은 흙 튀김
- 무효 시작 피드백: 보드를 짧게 흔들고 출발 타일을 강조하되 생명은 차감하지 않는다.
- 오답 피드백: 첫 오답 타일을 붉은 주황색으로 표시하고 늑대 실패 연출로 전환한다.

## 상태 머신

```text
loading
  → countdown
  → round_preview
  → round_recall (엄마 도착 후 유효한 출발 입력 또는 자동 전환)
      ├─→ round_success → round_preview
      ├─→ round_failure → life_remaining? → round_preview
      │                              └─→ finished_lives
      └─→ finished_timeout

loading/countdown/playing → interrupted
```

- 별도 연습 라운드는 없으며 첫 7칸 경로부터 실패 시 오리를 잃는다.
- `round_success`는 완성 점수를 한 번만 반영한다.
- `round_failure`는 오리 한 마리를 한 번만 차감한다.
- `finished_lives`와 `finished_timeout`은 누적 점수를 제출하는 정상 종료다.
- `interrupted`는 홈 이동, 앱 백그라운드 전환, 잠금, 전화, 시스템 UI 또는 앱 종료로 발생하며 시도를 소진하되 점수를 제출하지 않는다.

## 세션 및 난이도 계약

### 타임라인

| 구간 | 시간 | 플레이어 학습 | 주 변화 | 보조 변화 |
|---|---:|---|---|---|
| 첫 실전 | 성공 0회 | 기본 조작을 익힌다. | 경로 7칸 | 실패 시 즉시 오리 차감 |
| 진행 | 성공 1~2회 | 더 긴 방향 전환을 기억한다. | 경로 8~9칸 | 실패해도 길이 유지 |
| 중급 | 성공 3~4회 | 긴 경로를 안정적으로 재현한다. | 경로 10~11칸 | 시간에 따라 표시 시간 감소 |
| 숙련 | 성공 5회 이상 | 성공할수록 한 칸 더 긴 경로를 처리한다. | 성공마다 +1칸 | 표시 시간 최소 1.1초 |

- 자동 전환 대기: 유효한 출발 입력이 없으면 기존 발자국 유지와 0.35초 소멸 구간을 끝낸 뒤 회상 단계로 자동 전환한다.
- 함께 바꿀 수 있는 변수: 경로 길이는 성공 횟수만으로 정하고, 표시 시간은 세션 경과 시간만으로 조정한다.
- 상한의 일관성: 후반에도 새로운 타일 종류나 예외 규칙을 추가하지 않고 길이와 표시 시간만 바뀐다.

## 콘텐츠 확장성과 Codex 적합성

- 수작업 맵 필요: 고정형 단일 습지 보드 맵 1장
- 수작업 스테이지 필요: 없음
- 재사용 패턴: 고정 지형 맵은 그대로 재사용하고, 생성 실패용 검증된 35칸 폴백 경로를 반전·역순 변형
- 버전 1 에셋 가족:
  - 캐릭터 3종: 새끼 오리, 엄마 오리, 늑대
  - 환경 1종: 비 오는 습지 보드와 갈대 가장자리
  - 고정 지형 1종: 이어진 진흙길, 여러 칸을 가로지르는 물웅덩이, 갈대·풀숲 군락
  - 발자국 1종: 엄마 발자국, 플레이어 발자국, 오답 발자국
  - 효과 1종: 비, 성공 점수, 피버 반짝임과 금빛 가장자리
  - UI 모티프 1종: 상단 오리 얼굴 목숨, 점수, 하단 중앙 콤보
- 변화 생성 요소: 날짜 시드, 출발·도착 위치, 경로 길이, 방향 전환 위치
- 고정 요소: 습지 지형의 물길·진흙길·갈대 위치는 매 실행 동일하며 게임 규칙과 무관한 장식 레이어다.
- 수치 난이도 제어: 경로 길이, 표시 시간, 제시 속도, 회상 판정 허용치
- 지속적인 수작업 콘텐츠가 필요하지 않은 이유: 제약 기반 경로 생성만으로 매 판 다른 기억 문제를 만들 수 있다.
- 구현 복잡도: 중간. 보드 규칙은 단순하지만 입력 경계 허용치와 애니메이션-판정 동기화가 중요하다.
- 자동 테스트 전략:
  - 시드별 경로 재현
  - 경계 밖·대각선·재방문 경로 거부
  - 모든 생성 경로의 완주 가능성 검증
  - 성공 점수와 콤보 상한 검증
  - 실패당 정확히 한 생명 차감
  - 정상 종료당 정확히 한 결과 방출
  - 3·5·7콤보 피버 경계와 실패 시 해제 검증
  - 구조 오리 5마리 표시 상한과 초과 수 집계 검증

## 무작위성과 한 번의 시도 공정성

- 시드: 오늘의 게임 날짜와 규칙 버전으로 생성한 서버 또는 시도 제공 시드
- 무작위 요소: 맨 아래 행의 출발 열, 도착점, 합법 경로의 모양
- 합법 생성 조건:
  - 출발점은 맨 아래 행의 5칸 중 무작위 선택
  - 상하좌우 인접 이동만 사용
  - 각 단계는 이동 가능한 방향을 무작위 순서로 탐색하며 상단·회전 방향 우선 편향을 두지 않음
  - 같은 타일 재방문 금지
  - 자기 교차 금지
  - 보드 밖 이동 금지
  - 출발점과 도착점이 서로 다름
  - 같은 방향 이동은 최대 2칸 연속까지만 허용
  - 요구 길이와 표시 시간을 모든 플레이어에게 동일하게 적용
- 안전 시작: 3초 카운트다운 동안 입력을 막고 첫 경로 전체를 보여주지만 별도 무손실 연습은 제공하지 않는다.
- 회복 기회: 정상 실패 후 다음 라운드 시작 전에 오답 위치와 정답 경로를 함께 짧게 표시한다.
- 피할 수 없는 실패 방지: 입력 전에 전체 경로를 항상 완전하게 보여주며 모든 생성 경로는 규칙 검사에 통과해야 한다.
- 생성 실패 폴백: 35칸까지 검증된 전체 보드 경로를 시드에 따라 상하·좌우 반전하거나 역순으로 사용한다.
- 반복 입력 악용 방지: 경로 전체를 완성해야 점수를 주고, 부분 경로에는 점수를 주지 않는다.
- 대기 악용 방지: 회상 단계에서도 세션 타이머가 계속 흐른다.
- 화면 밖 악용 방지: 보드 밖 드래그는 진행을 멈추며 복귀해도 새 타일로 확정되지 않는다.
- 실패 원인 표시: 최초 오답 타일, 플레이어 경로, 정답 경로를 서로 다른 색으로 동시에 표시한다.
- 구조 오리와 피버 공정성: 성공 장면의 새끼 오리는 입력이 끝난 뒤에만 경로를 채운다. 두 연출은 입력 판정, 생명, 점수 공식에 영향을 주지 않는다.

## 점수와 랭킹

- 플레이어 표시 단위: 점수
- HUD: 남은 시간, 누적 점수, 남은 오리 3마리, 현재 연속 성공
- 라운드 기본 점수: 완성한 경로 길이 × 100
- 콤보 보너스: `min(연속 성공 횟수, 10) × 25`
- 제출 정수: 모든 성공 라운드의 기본 점수와 콤보 보너스 합
- 순위 방향: 높은 점수가 더 높은 순위
- 표시 포맷: 천 단위 구분 정수와 `점`
- 정밀도와 범위: 최소 0점, 이론적 상한은 120초 내 가능한 라운드 수로 계산해 서버 검증 상한을 둔다.
- 동점 의미: 같은 수의 비슷한 길이 경로를 같은 연속 성공 수준으로 완성한 기록이다.
- 오리 3마리 소진: 그때까지 누적한 점수를 제출한다.
- 120초 시간 초과: 진행 중 라운드는 0점으로 닫고 누적 점수를 제출한다.
- 중단: 시도만 소진하고 점수를 제출하지 않는다.
- 결과 보조 필드: 실제 플레이 지속시간, 성공 라운드 수, 최고 콤보, 잃은 오리 수
- 피버 점수 정책: 3·5·7콤보의 피버 단계는 기존 콤보 보너스를 시각적으로 강조할 뿐 별도 배수나 숨은 보너스를 추가하지 않는다.

## 프레젠테이션 의존성

### 2D 비주얼 콘셉트

- 테마와 장소: 비가 내리는 얕은 습지와 진흙 길, 가장자리를 둘러싼 높은 갈대
- 카메라: 세로형 5×7 보드를 중심으로 내려다보는 고정 탑다운 2D 시점
- 보드 점유율: 360×640 게임 좌표에서 보드는 `x=0`, `y=68`, `360×504`를 사용해 가로폭 전체와 세로 대부분을 차지한다.
- 캐릭터 가시성: 엄마는 경로 제시 후 마지막 칸에서 계속 기다리고, 새끼는 정답 드래그 완료 후에만 경로를 따라가며, 늑대는 오답 연출 중에만 표시한다.
- 분위기: 축축하고 약간 쓸쓸하지만, 새끼 오리의 과장된 행동과 늑대의 어설픈 위장으로 코믹하게 유지
- 핵심 비주얼 개그: 늑대가 새끼 오리를 한입에 삼킨 뒤 배 안에서 `꽥!` 소리가 나고 이빨 사이에 노란 깃털 한 가닥이 남는다.
- 픽셀아트 방향: 낮은 원본 해상도에서 만든 굵고 계단진 픽셀 덩어리, 명확한 실루엣, 낮은 배경 대비, 2~3단계로 제한한 내부 명암
- 겉보기 아트 픽셀 크기: 360 논리 픽셀 폭 화면에서 약 2×2 논리 픽셀
- 플레이 대비 우선순위: 발광하는 엄마 발자국 > 플레이어 발자국 > 새끼 오리와 늑대 > 보드 장식 > 배경
- 팔레트 분위기: 차가운 청록·갈색 습지 위에 노란 오리와 밝은 레몬 크림색 발자국을 강조하고, 오답은 붉은 주황으로 분리
- 세로 화면 대응: 카메라는 360 논리 픽셀 폭을 고정하고 긴 화면에서는 640px 안전 코어의 위아래로 습지 배경을 더 보여주며, 5×7 보드와 HUD는 잘리지 않는다.

### 새끼 오리

- 역할: 플레이어가 안전하게 인도해야 하는 현재 생명
- 비주얼 비율: 귀여움 80%, 바보같이 사랑스러운 dopey-cute 20%. 첫인상은 정상적으로 아주 귀엽고 보호해주고 싶은 새끼여야 한다.
- 실루엣과 비율: 통통한 볼이 붙은 둥근 큰 머리, 작고 말랑한 배 모양 몸통, 머리보다 작지만 눈에 띄는 큰 물갈퀴, 안정적인 좌우 대칭
- 표정: 엄마를 무조건 믿는 크고 맑은 눈과 살짝 벌어진 작은 부리. 무슨 일이 일어나는지 한 박자 늦게 이해하는 순진하고 해맑은 표정
- 바보같이 귀여운 특징: 떡진 머리털 세 가닥, 생각 없이 가만히 벌린 부리, 가슴을 내밀고 엉뚱한 방향을 잠깐 보는 대기 동작, 걸을 때의 작은 좌우 흔들림
- 피할 표현: 비뚤어진 부리, 얼굴·눈의 비대칭, 신체 결함처럼 읽히는 특징, 지나치게 비쩍 마른 몸, 초점 없는 동공, 일그러진 얼굴, 불쾌하거나 기괴한 인상
- 사랑스러운 정체성 단서: 넘어질 듯하면서도 엄마를 향해 계속 달리는 성실함과 통통한 볼
- 필수 동작: 대기, 뒤뚱 걷기, 무리 이동, 엄마 직전 정지와 기쁨, 놀람, 삼켜지기 직전
- 시각 비트:
  - 시작: 보드 아래에서 엄마를 올려다봄
  - 압박: 긴 경로를 앞두고 식은땀
  - 성공: 노란 몸색의 기본·꼬질·빨간 스카프 새끼가 경로의 모든 칸을 채우고 엄마 직전부터 차례로 기뻐함
  - 실패: 늑대를 뒤늦게 보고 한 박자 늦게 놀람

### 엄마 오리

- 역할: 안전한 경로를 직접 보여주고 목표 지점에서 새끼를 기다리는 안내자
- 비주얼 방향: ugly-cute를 적용하지 않는다.
- 실루엣과 비율: 실제 오리의 특징을 단순화한 균형 잡힌 비율과 부드럽고 깨끗한 외곽선
- 표정: 따뜻하고 침착하며 새끼를 걱정하는 표정
- 성격: 서두르지만 무책임하거나 우스꽝스럽게 보이지 않는다.
- 정체성 단서: 비를 맞은 새끼를 품어주는 넓은 날개
- 필수 동작: 경로 걷기, 뒤돌아보기, 기다리기, 6프레임 기쁨, 새끼를 잃었을 때 놀람과 슬픔
- 시각 비트:
  - 시작: 새끼를 돌아보며 출발
  - 경로 제시: 또렷한 발자국을 남기며 이동
  - 성공: 마지막 타일에서 기다리다가 새끼 무리가 직전 타일에 도착하면 눈웃음과 날갯짓으로 함께 기뻐함
  - 실패: 늑대가 튀어나온 방향을 보고 경악함

### 늑대

- 역할: 오답을 즉시 전달하는 실패 연출이자 남은 생명을 차감하는 위협
- 실루엣과 비율: 비쩍 마른 몸, 작은 다리, 지나치게 긴 주둥이와 큰 입
- 표정: 영리하다고 믿지만 갈대 몇 가닥만 머리에 꽂고 완벽히 숨었다고 착각하는 표정
- 어색한 특징: 몸은 말랐지만 오리를 삼킨 직후 배만 완벽한 공처럼 부푼다.
- 사랑스러운 정체성 단서: 무서운 척하지만 항상 깃털 한 가닥을 제대로 숨기지 못함
- 필수 동작: 갈대 속 대기, 눈 번쩍임, 튀어나오기, 입 벌리기, 삼키기, 배 부풀기, 트림
- 실패 표현: 피나 신체 훼손 없이 늑대가 처음부터 입을 빠르게 벌려 오리를 통째로 삼킨다. 별도 펑 연기 레이어 없이 늑대의 6프레임 몸체 동작만으로 결과를 전달한다.

### 시각적 역할

- 목표: 마지막 경로 칸에 직접 서서 기다리는 엄마 오리
- 위험: 보드 가장자리 갈대 속 늑대의 눈과 붉은 오답 발자국
- 픽업: 없음
- 안전 영역: 출발 타일과 도착 칸에 서 있는 엄마 오리
- 경고 언어: 실패 직전 갈대가 흔들리고 늑대 눈이 번쩍임
- 성공 피드백: 엄마 직전 타일에 멈춘 새끼 무리의 기쁨, 엄마의 6프레임 환영 날갯짓, 점수 상승
- 실패 피드백: 붉은 오답 타일, 늑대가 처음부터 입을 빠르게 벌리는 6프레임 한입 삼킴, 남은 오리 UI 감소. 별도 펑 연기 효과는 사용하지 않는다.
- 누적 성공 피드백: 보드 아래 안전 구역에 구조한 새끼를 최대 5마리까지 `48×48`로 표시하고, 초과분은 `+N`으로 집계한다.
- 성공 이동 피드백: 성공 순간 하단 행렬을 숨기고 경로 길이보다 한 마리 적은 새끼를 `72×72` 셀 안의 `50px` 몸체로 같은 경로에 투입한다. 이동 시간은 `0.58초`이며, 선두는 엄마 직전 타일 중앙에 멈추고 후속 새끼는 정확히 `1타일` 간격으로 뒤를 따라 각 칸에 한 마리만 배치된다. 마지막 두 새끼는 뒤늦게 합류해 빠르게 발을 움직인다.
- 재회 기쁨 피드백: 도착 뒤 엄마와 새끼는 각각 6프레임을 `125ms/프레임`으로 반복하며 `1.5초` 동안 함께 기뻐한다. 새끼는 앞에서 뒤로 시간차를 두고 만세한다. 엄마는 마지막 타일, 선두 새끼는 직전 타일을 유지한다.
- 피버 피드백: 3콤보부터 플레이어 발자국과 성공 문구를 황금색으로 바꾸고, 5콤보부터 픽셀 반짝임, 7콤보부터 비 약화와 얇은 금빛 가장자리를 추가한다.
- 발자국 가독성: 각 자국은 세 갈래 발가락과 작은 뒤꿈치가 보이는 단순한 물갈퀴 실루엣이며, 어두운 외곽선과 밝은 중심색으로 진흙·물웅덩이 위에서 즉시 읽혀야 한다.
- 배경 행동: 비와 물결은 계속 움직이되 발자국보다 대비가 낮아야 한다.
- HUD 관계: 상단의 `SURVIVE`와 `TIME` 사이, `LIVES` 바로 아래에 `48×48` 새끼 오리 얼굴 3개를 배치한다. 얼굴 중심 간격은 `24px`, 전체 묶음은 `96×48`이며 `LIVES`를 기준으로 중앙 정렬한다. 소진된 목숨은 같은 얼굴을 `18%` 불투명도로 표시하고, 콤보는 보드 아래 정중앙에 둔다.
- 가이드 비주얼: 경로 보기, 비에 지워짐, 같은 길 드래그, 오답 시 늑대의 네 장면
- 홈 미리보기: 엄마 발자국이 사라지는 가운데 새끼 오리가 첫 타일 앞에서 망설이고, 갈대 속 늑대 눈이 보이는 순간

### 제한된 에셋 목록

아래 값은 현재 런타임과 `hd_v7`~`hd_v9` 제작 계약에 반영된 최종 규격이다.

| 가족 | 대상 | 동작·변형 | 예상 원본 셀 | 예상 표시 크기 |
|---|---|---|---:|---:|
| 플레이어 | 노란 기본·꼬질·빨간 스카프 새끼 오리 | 대기, 걷기, 무리 이동, 기쁨, 놀람 | 72px | 72px 셀 / 50px 몸체 |
| 안내자 | 엄마 오리 | 걷기, 대기, 6프레임 기쁨, 경악 | 72px | 72px |
| 위험 | 늑대 | 대기 눈, 도약, 삼킴, 배 부풀기, 트림 | 32~48px | 64~96px |
| 경로 | 오리 발자국 | 엄마, 플레이어, 오답, 소멸 단계 | 16~24px | 32~48px |
| 효과 | 비, 성공 점수, 피버 반짝임·금빛 가장자리 | 루프 및 일회성 효과 | 코드 기반 2px 격자 | 2~6px 강조 |
| 환경 | 이어진 습지 보드, 물길, 진흙길, 갈대·풀숲 | 고정형 단일 보드 맵 | 2 논리 픽셀 | 360×504 표시 |
| UI | 오리 얼굴 생명, 점수, 콤보 | 정상, 손실, 상승 | 얼굴 24px | 얼굴 48px |

- 이 에셋 세트로 충분한 이유: 플레이 변화는 절차 생성 경로와 수치 난이도에서 나오며 캐릭터·환경 변형을 계속 추가할 필요가 없다.
- 구조 행렬과 피버 재사용 계약: 기존 새끼 오리 걷기 시트와 발자국 아틀라스를 원본 픽셀 크기로 재사용하며, 피버 반짝임과 가장자리 광원은 정수 픽셀 도형으로 렌더링한다.
- 엄마 기쁨 에셋 계약: 현재 두건·체형·팔레트를 고정한 `2×3`, `216×144`, 6프레임 시트를 발 기준으로 재생하며 기존 단일 포옹 이미지는 런타임에서 사용하지 않고 보존한다.
- 새끼 크기 계약: 걷기와 기쁨 시트는 `2×3`, `216×144`, 프레임당 `72×72`를 유지하되 실제 몸체 높이는 전 프레임 `50px`, 발 기준선은 `y=68`로 고정한다. 엄마 몸체는 동작에 따라 `56~60px`로 유지해 성체가 더 크게 읽혀야 한다.
- 새끼 종류 계약: 세 종류 모두 기존 노란 몸색과 6프레임 걷기·기쁨, 같은 셀·발 기준선을 유지한다. 꼬질 오리는 볼·날개 진흙 자국, 멋낸 오리는 작은 빨간 목 스카프로 구별하며 성공 경로와 하단 행렬에서 고정 순서로 반복한다.
- LIVES 배치 계약: `duckling_life_face.png`는 `24×24` 원본을 nearest-neighbor로 `48×48` 표시하며, 세 얼굴의 중심을 `24px` 간격으로 겹쳐 전체 `96×48` 묶음으로 중앙 정렬한다.
- 최종 제작 계약: `hd_v7`은 단체 재회와 엄마 기쁨, `hd_v8`은 새끼 몸체 축소, `hd_v9`은 LIVES 얼굴 간격을 기록한다.
- 재사용 가능 후보: 기존 프로젝트의 픽셀 크기, nearest-neighbor 렌더링, 공통 HUD 구조와 결과 전환
- `build-game-assets`로 미루는 결정: 현재 버전의 핵심 에셋 규격은 확정되었다. 이후 새 동작·캐릭터·환경 변형을 추가할 때만 별도 제작 계약을 승인한다.
- 사운드와 햅틱:
  - 발자국 확정마다 부드러운 진흙 소리와 약한 햅틱
  - 성공 시 짧은 오리 울음과 상승 햅틱
  - 오답 시 갈대 흔들림 경고 후 강한 단발 햅틱
  - 삼킴은 코믹한 `꿀꺽`, 배 안에서는 작은 `꽥`

  - 경로 제시 애니메이션과 실제 판정 순서가 어긋날 수 있음
  - 늑대 연출이 길면 실패가 남은 플레이시간을 과도하게 소모할 수 있음
  - 동일 날짜 시드가 클라이언트와 서버에서 일관되게 전달되어야 함

## 승인 테스트

- 전체 가이드를 약 20초 안에 이해할 수 있다.
- 엄마의 발자국이 비에 지워지고 플레이어가 이를 재현한다는 설정과 규칙이 자연스럽게 연결된다.
- 엄마 오리는 따뜻하고 정상적으로 귀여우며 ugly-cute를 적용하지 않는다.
- 새끼 오리와 늑대에는 프로젝트의 어색하고 멍청한 ugly-cute 정체성이 명확하다.
- 2D 픽셀아트가 360 논리 픽셀 폭 화면에서 일관된 픽셀 크기로 보인다.
- 3초 카운트다운 뒤 첫 7칸 경로부터 실패 시 오리를 정확히 한 마리 잃는다.
- 경로 전체가 입력 전에 완전하게 표시된다.
- 엄마가 이동 중일 때 출발점을 눌러도 무시되고, 도착 후 발자국 유지·소멸 중 출발 입력은 같은 드래그의 첫 칸으로 즉시 시작된다.
- 유효 시작, 경계 흔들림, 대각선, 재방문, 조기 손 떼기, 보드 밖 입력이 계약대로 처리된다.
- 한 성공 라운드가 점수를 정확히 한 번만 추가한다.
- 한 실패 라운드가 오리를 정확히 한 마리만 차감한다.
- 세 번째 목숨 소진과 120초 시간 초과가 각각 정확히 한 번 결과를 방출한다.
- 중단은 점수를 조작하거나 제출하지 않고 시도를 소진한다.
- 동일 시드는 동일한 경로 순서를 만든다.
- 모든 생성 경로는 보드 안에서 완주 가능하다.
- 성공마다 경로가 정확히 한 칸 증가하고 5×7 보드의 물리적 한계인 35칸에서 멈추며, 실패 시 현재 길이를 유지한다.
- 여러 시드에서 출발점이 맨 아래 5칸에 분포하고 이후 경로에는 상하좌우 네 방향이 모두 생성된다.
- 습지 보드는 `marsh_board_map.png` 한 장으로 고정 표시되며, 물웅덩이와 갈대 위치는 시드나 경로 생성에 영향을 받지 않는다.
- 짧은 화면, 기준 화면, 긴 화면에서 보드·HUD·엄마·새끼 오리가 잘리지 않는다.
- 늑대의 삼킴은 분명하지만 피나 신체 훼손 없이 코믹하게 표현된다.
- 성공 수만큼 구조 행렬이 누적되고 5마리 이후 초과 수가 정확히 집계된다.
- 피버가 3·5·7콤보에서 상승하며 실패 직후 즉시 해제된다.
- 구조 행렬과 피버가 점수 공식, 경로 판정, 목숨 또는 보드 입력 영역을 바꾸지 않는다.
- 성공 선두는 경로 마지막 칸의 엄마와 겹치지 않고 정확히 직전 타일에 멈춘다.
- 성공 장면에는 `경로 길이 - 1`마리의 새끼가 합류하여 엄마가 선 마지막 칸을 제외한 모든 경로 칸을 채운다. 각 경로 타일에는 정확히 한 마리만 있고 성공 중 하단 행렬과 중복 표시되지 않는다.
- 새끼 도착 뒤 엄마와 새끼가 동시에 기쁨 모션을 재생한다.
- 새끼 오리 걷기·기쁨 프레임의 몸체 높이는 모두 50px이고 발 기준선은 `y=68`이며, 엄마 오리보다 작게 읽힌다.
- LIVES 얼굴은 각각 `48×48`, 중심 간격 `24px`, 전체 폭 `96px`로 `LIVES` 정중앙에 놓이고 소진 상태는 `18%` 불투명도를 사용한다.
