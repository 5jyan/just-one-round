## 핵심 루프

- 초기 상태: `rowCount=15`, `columnCount=9` 주방 타일 보드의 머리 `(row 7, column 4)`에서 오른쪽을 향한 길이 4의 닥스훈트로 시작한다.
- 안전 학습: 첫 소시지는 진행 방향 앞의 `(row 7, column 6)`에 고정하고 초기 이동 간격을 0.60초로 유지한다.
- 반복 플레이 행동: 플레이어가 다음 진행 방향을 스와이프로 예약한다.
- 이동 반응: 고정 이동 틱마다 머리가 한 칸 전진하고 각 몸마디는 바로 앞 마디의 이전 칸을 따른다.
- 진행: 소시지를 먹으면 점수와 몸길이가 각각 1 증가하고 다음 소시지를 합법적인 빈칸에 생성한다.
- 실패: 다음 머리 위치가 벽 밖 또는 꼬리가 빠져나가기 전에 점유 중인 자기 몸이면 충돌 원인을 표시하고 종료한다.
- 시간 초과: 150초가 되는 순간 현재 이동을 더 진행하지 않고 누적 소시지 개수를 제출한다.
- 보드 완료: 소시지를 생성할 합법적인 빈칸이 없으면 주방 정복 완료로 종료하고 누적 점수를 제출한다.
- 완료: 벽 충돌, 자기 몸 충돌, 150초 시간 초과 또는 보드 완료 중 먼저 발생한 조건으로 정상 종료한다.

## 입력 계약

- 제스처: 상하좌우 한 손가락 스와이프
- 유효 터치 영역: HUD를 제외한 전체 게임 보드
- 방향 판정: 수평·수직 이동량 중 절댓값이 큰 축을 사용하고 부호로 방향을 결정한다.
- 스와이프 임계값: 보존된 v1 소스에서 18 논리 픽셀 이상을 사용한다.
- 대각선 입력: 우세한 한 축으로만 판정한다.
- 정반대 방향 입력: 현재 진행 방향의 즉시 반전은 무시한다.
- 입력 버퍼: 이동 틱 사이에 최초 유효 방향 전환 하나만 예약하며 추가 입력은 다음 틱까지 무시한다.
- 손 떼기와 재터치: 손을 뗄 때 스와이프를 확정하며 매 이동 틱 이후 새 스와이프를 받을 수 있다.
- 멀티터치: 최초 한 손가락만 사용하고 나머지 입력은 무시한다.
- 카운트다운 입력: 게임 판정과 입력 버퍼에 반영하지 않는다.
- 유효 입력 피드백: 다음 방향을 가리키는 짧은 머리 기울임과 보드 가장자리 화살표 점멸
- 너무 짧은 입력 피드백: 방향을 바꾸지 않고 약한 무반응 햅틱만 제공한다.
- 반대 방향 입력 피드백: 머리가 잠깐 뒤를 보지만 방향은 바뀌지 않는다.

## 상태 머신

```text
loading
  → countdown
  → playing
      ├─→ finished_wall_collision
      ├─→ finished_self_collision
      ├─→ finished_timeout
      └─→ finished_board_complete

loading/countdown/playing → interrupted
```

- 카운트다운은 기본 3초이며 이 구간에는 이동과 입력을 판정하지 않는다. 별도의 `safe_opening` 런타임 단계는 없다.
- 플레이 시작 후 첫 이동 간격은 `0.60초/칸`이며, 별도의 무적 시간이나 입력 안전 보조 없이 플레이 중 충돌을 판정한다.
- `finished_wall_collision`과 `finished_self_collision`은 누적 소시지 개수를 정상 제출한다.
- `finished_timeout`과 `finished_board_complete`도 누적 소시지 개수를 정상 제출한다.
- 모든 정상 종료 상태는 결과를 정확히 한 번만 방출한다.
- `interrupted`는 홈 이동, 앱 백그라운드 전환, 잠금, 전화, 시스템 UI 또는 앱 종료로 발생하며 시도를 소진하되 점수를 제출하지 않는다.

## 무작위성과 한 번의 시도 공정성

- 시드: 레거시 게임을 레지스트리 밖에서 직접 생성할 때 규칙이 제공하는 한국 시간 날짜 기반 `dailySeed`; 현재 활성 레지스트리는 이 게임에 시드를 주입하지 않는다.
- 무작위 요소: 첫 고정 소시지 이후의 소시지 위치
- 합법 생성 조건:
  - 현재 머리와 몸통이 점유하지 않은 칸
  - 현재 머리에서 빈칸 그래프를 통해 도달 가능한 칸
  - 몸과 벽으로 완전히 봉쇄된 주머니가 아닌 칸
  - 직전 소시지 위치와 다른 칸
  - 가능한 경우 머리에서 맨해튼 거리 3 이상인 칸
- 결정론적 선택: 시드로 후보 목록의 시작 인덱스를 정하고 현재 합법 후보 중 하나를 선택한다.
- 안전 시작: 첫 소시지는 `(row 7, column 6)`에 고정하며 카운트다운 3초 동안에는 이동·입력을 판정하지 않는다.
- 최소 회복 기회: 소시지를 먹은 틱에는 새 몸마디만 예약하고 다음 이동 틱 전까지 새 소시지 위치를 명확히 표시한다.
- 피할 수 없는 실패 방지: 소시지는 현재 도달 가능한 영역에만 생성하고, 생성 때문에 즉시 방향 전환을 강제하지 않는다.
- 생성 실패 폴백: 도달 가능한 빈칸을 행 우선으로 순회해 첫 안전 칸을 사용하고, 안전 칸이 없으면 보드 완료 처리한다.
- 대기 악용 방지: 닥스훈트는 항상 이동하며 생존 시간 자체에는 점수를 주지 않는다.
- 입력 연타 악용 방지: 한 이동 틱당 최초 유효 방향 하나만 처리한다.
- 화면 밖·수명주기 악용 방지: 화면 밖 입력은 추가 점수를 만들지 않으며 앱 중단은 시도만 소진하고 결과를 제출하지 않는다.
- 실패 피드백: 충돌한 머리 칸과 벽 또는 몸마디를 붉은 주황색으로 동시에 점멸하고 충돌 원인별 전용 연출을 사용한다.

## 점수와 랭킹

- 플레이어 표시 단위: 먹은 소시지 개수
- HUD: 남은 시간과 `소시지 N개`
- 제출 정수: 먹은 소시지 개수 `N`
- 순위 방향: 높은 정수가 더 높은 순위
- 표시 포맷: `N개`
- 역변환: 표시 정수와 제출 정수가 동일하므로 변환 없음
- 정밀도와 범위: 최소 0점, 9×15 보드와 초기 길이 4를 기준으로 이론적 최대 131점
- 동점 의미: 같은 수의 소시지를 먹고 서로 다른 위치 또는 시간에 실패한 동등 기록
- 충돌 종료: 충돌 직전까지 확정된 누적 개수를 제출한다.
- 150초 시간 초과: 마지막 완료 이동 틱까지 확정된 누적 개수를 제출한다.
- 보드 완료: 마지막 소시지까지 포함한 누적 개수를 제출한다.
- 중단: 시도만 소진하고 점수를 제출하지 않는다.
- 결과 필드: 보존된 런타임 `GameResult`는 `score=N`, `starsCollected=0`, `collisions`(벽·자기 몸 충돌 1, 시간 초과·보드 완료 0), 실제 `duration`, `endType`을 기록한다. 최종 몸길이·머리 위치는 제출 필드가 아니다.

## 프레젠테이션 의존성

### 2D 비주얼 콘셉트

- 테마와 장소: 가족이 잠든 늦은 밤, 냉장고 문이 살짝 열린 작은 주방
- 카메라: 9×15 보드를 고정해서 내려다보는 탑다운 2D 시점
- 분위기: 어두운 청록색 주방 속에서 몰래 야식을 훔치는 조용한 긴장과 어리숙한 코미디
- 핵심 비주얼 개그: 소시지를 먹을 때마다 닥스훈트의 허리가 실제로 한 마디씩 늘어나지만 머리는 끝까지 그 사실을 모른다.
- 픽셀아트 방향: 굵고 계단진 픽셀 덩어리, 단순한 타일 실루엣, 2~3단계 내부 명암, 낮은 배경 대비
- 겉보기 아트 픽셀 크기: 360 논리 픽셀 폭 화면에서 약 2×2 논리 픽셀
- 플레이 대비 우선순위: 닥스훈트 머리 > 붉은 소시지 > 몸통과 꼬리 > 충돌 칸 > 주방 장식
- 팔레트 분위기: 차가운 청록·남색 타일 위에 따뜻한 밤색 닥스훈트를 두고, 소시지는 더 채도 높은 붉은 갈색, 검은 그릴 자국과 밝은 김 픽셀로 분리
- 승인된 콘셉트 참고: `assets/source/imagegen/sausage_dachshund/concept/gameplay-concept-v4.png`
- 콘셉트 사용 범위: 닥스훈트 정체성, 밤의 주방 분위기, 색 대비와 화면 구성을 잠그는 참고 이미지이며 런타임 스프라이트나 정확한 판정 기하로 직접 사용하지 않는다.

### 플레이어 캐릭터

- 역할: 항상 움직이며 소시지를 먹을수록 길어지는 플레이어의 전신
- 품종 정체성: 매끈한 털의 닥스훈트로 읽혀야 하며, 긴 주둥이, 낮게 붙어 아래로 늘어진 둥근 귀, 큰 검은 코, 낮은 가슴, 긴 몸통과 짧은 다리를 유지한다.
- 실루엣과 비율: 머리부터 어깨·가슴·허리·엉덩이·가늘어지는 꼬리까지 하나의 유기적인 개 몸으로 이어지고, 게임 규칙 때문에 허리 구간만 비정상적으로 길어진다.
- 몸의 경로 형태: 전체 몸길이의 80% 이상은 격자 중앙을 따르는 곧은 수평·수직 구간으로 표현하고, 방향 전환은 해당 모서리 셀 안의 짧고 작은 90도 굴곡만 허용한다.
- 금지 곡선: 여러 셀에 걸친 큰 원호, S자 곡선, 뱀처럼 감기는 곡선, 대각선 연결과 장기처럼 보이는 자유곡선을 사용하지 않는다.
- 표정: 소시지만 바라보는 멍하고 지나치게 진지한 표정
- 어색한 특징: 실제 닥스훈트처럼 앞다리 두 개와 뒷다리 두 개만 있으며, 길어진 몸 때문에 앞다리와 뒷다리가 서로 한참 떨어진 채 따로 허둥댄다.
- 사랑스러운 정체성 단서: 한쪽만 안쪽이 보이게 뒤집힌 긴 귀, 지나치게 큰 검은 코와 앞뒤로 멀리 떨어진 네 개의 짧은 다리
- 털과 의상 규칙: 의상과 목걸이는 사용하지 않는다. 전신은 매끈한 따뜻한 밤색 털이며 등은 한 단계 어둡게, 머리와 몸의 큰 면에는 작은 따뜻한 하이라이트만 사용한다.
- 금지 형태: 반복되는 소시지 마디, 원통형 절단면, 몸마디마다 붙은 다리, 지네나 붉은 벌레로 읽히는 실루엣, 짧은 주둥이, 뾰족하게 선 귀, 스웨터·목걸이·리본 등 모든 의상과 액세서리
- 필수 동작: 대기성 전진, 4방향 걷기, 방향 전환, 소시지 삼키기, 몸마디 생성, 벽 충돌, 자기 꼬리 물기, 시간 완료
- 시작 비트: 냉장고 불빛 속 첫 소시지를 발견하고 침을 한 방울 흘린다.
- 압박 비트: 몸이 길어질수록 머리에 식은땀이 맺히고 멀리 떨어진 네 다리가 서로 박자가 어긋난 채 더 빠르게 움직인다.
- 성공 비트: 주인이 긴 몸을 빨랫줄처럼 둘둘 감아 안고 주방 밖으로 데려간다.
- 실패 비트: 벽에서는 코가 납작해지고, 자기 충돌에서는 꼬리를 소시지로 착각해 문 뒤 늦게 놀란다.

### 시각적 역할

- 목표: 밝은 붉은 주황색 소시지와 짧은 향기 픽셀
- 위험: 어두운 외곽선의 주방 벽과 현재 점유 중인 길쭉한 닥스훈트 몸통
- 픽업: 소시지 1종
- 안전 영역: 현재 머리에서 도달 가능한 빈 타일
- 경고 언어: 머리가 벽 또는 몸통 한 칸 앞에 접근하면 눈이 커지고 귀가 뒤로 젖혀진다.
- 근접 피드백: 위험 칸을 아슬아슬하게 통과하면 귀가 펄럭이고 앞발이 잠깐 미끄러진다.
- 획득 피드백: 한입 삼킴, 부스러기, `+1`, 허리가 고무처럼 한 칸 늘어나며 엉덩이와 꼬리가 뒤로 밀리는 연쇄 동작
- 실패 피드백: 충돌 칸 붉은 점멸, 머리 압착 또는 꼬리 물기, 뒤따르는 몸마디의 연쇄 압축
- 배경 행동: 냉장고 불빛과 시계 초침만 낮은 대비로 움직이고 보드 타일은 고정한다.
- HUD 관계: 상단에 남은 시간과 소시지 개수를 두고 9×15 보드 영역과 겹치지 않는다.
- 가이드 비주얼: 스와이프 회전, 소시지 획득과 몸 증가, 벽 충돌, 자기 몸 충돌의 네 장면
- 홈 미리보기: 긴 몸이 주방을 한 바퀴 감싼 가운데 머리가 바로 앞 소시지만 멍하게 바라보는 순간

- 이동 표현 계약: 규칙 상태와 충돌은 기존 격자 틱을 유지하고 화면 위치만 틱 직후 최대 0.18초 동안 ease-out 보간한다.
- 몸통 연결 계약: 몸통과 목·엉덩이 연결부는 동일한 2픽셀 공통 단면으로 공유 경계까지 닿는다. 이동 보간 중에는 스프라이트 아래 연결 보강선을 렌더링해 마디가 벌어지지 않게 한다. 귀·주둥이·발·꼬리 등 비연결 요소는 자기 셀 안에 머문다.
- 모듈 외형 계약: 직선 모듈은 길고 곧은 외곽선을 유지하고 모서리 모듈의 둥근 반경은 한 셀 내부에서만 끝난다. 여러 셀을 한꺼번에 휘는 곡선 모듈은 만들지 않는다.
- 다리 배치 계약: 앞다리 두 개는 머리 바로 뒤 어깨 모듈에만, 뒷다리 두 개는 꼬리 바로 앞 엉덩이 모듈에만 포함한다. 중간 몸통 모듈에는 다리·발·돌출부가 없다.
- 에셋 제작 필수 검증: 직선·모서리 모듈을 혼합한 실제 보드 합성에서 갈색 털이 원통형 소시지나 지네 마디로 보이지 않고, 앞다리와 뒷다리가 각각 머리·꼬리 구간에만 나타나며 모든 불투명 픽셀이 자기 셀 안에 머무는지 확인한다.
- 사운드와 햅틱:
  - 이동: 작은 발톱 네 번이 섞인 짧은 타일 소리
  - 소시지 획득: 둔한 `꿀꺽`과 가벼운 성공 햅틱
  - 벽 충돌: 고무 코가 눌리는 둔탁한 소리와 강한 단발 햅틱
  - 자기 충돌: 짧은 낑 소리와 두 번의 경고 햅틱
  - 완료: 주인 발소리와 안도하는 긴 한숨

## 보존 구현 인수 테스트

- 가이드 문구를 약 20초 이내에 이해할 수 있다.
- 소시지 섭취와 닥스훈트 몸 증가가 규칙과 코믹 전제를 동시에 설명한다.
- 제한된 에셋 목록만으로 일관된 2D 픽셀아트 화면을 구성할 수 있다.
- 한쪽 귀, 큰 검은 코와 네 개의 짧은 다리로 만든 ugly-cute 정체성이 판정 가독성을 해치지 않는다.
- 머리·몸·꼬리가 긴 주둥이와 늘어진 귀를 가진 하나의 닥스훈트로 읽히며 다리는 정확히 네 개만 표현된다.
- 의상 없는 밤색 몸이 반복 소시지 마디, 지네 또는 붉은 벌레처럼 보이지 않는다.
- 소시지는 포장지나 사탕 매듭 없이 굽힌 고기 몸체, 뭉툭한 양 끝, 그릴 자국과 김으로 읽힌다.
- 모든 닥스훈트 모듈의 불투명 픽셀이 자기 32×32 격자 셀을 벗어나지 않는다.

- 너무 짧은 스와이프와 멀티터치가 상태를 손상하지 않는다.
- 소시지 하나당 점수와 몸길이가 정확히 1 증가한다.
- 꼬리가 빠지는 칸으로 이동할 때 잘못된 자기 충돌이 발생하지 않는다.
- 벽과 자기 몸 충돌 원인이 서로 다르게 표시된다.
- 벽 충돌, 자기 충돌, 시간 종료, 보드 완료가 각각 정상 종료된다.

- 중단 상태는 시도를 소진하지만 점수를 제출하지 않는다.
- 같은 시드와 입력에서 소시지 위치가 재현된다.
- 모든 생성 소시지가 생성 시점의 머리 영역에서 도달 가능하다.
- 생성 후보가 없을 때 무한 반복 없이 보드 완료로 종료된다.
- 각 시간 마일스톤에서 이동 간격이 정확히 한 번 변경된다.
- 초보자·중급자·숙련자 실패 시간 분포가 목표 구간과 대체로 일치한다.
- 제출 점수는 0~131 범위를 벗어나지 않고 `N개`로 표시된다.
- 150초에 반드시 정상 종료된다.
- 지원하는 모든 휴대전화 화면 비율에서 HUD와 보드가 겹치거나 잘리지 않는다.
