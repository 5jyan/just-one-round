# 야식털이 뱀

## 상태

- 상태: 구현 완료, 장기 구간 밸런스 검증 필요
- 게임 ID: `midnight_snake`
- 규칙 버전: `2`
- 마지막 동기화: 2026-09-10
- 런타임: Flame, 360×764 논리 해상도. 승인 시안의 주방·보드·조작부가 한 장의 배경으로 이어진다.

## 플레이어 약속

- 한 문장 약속: 네 방향 버튼과 최대 3개의 예약 입력으로 긴 뱀을 몰아, 5분 안에 야식과 반복 등장하는 특별 먹이를 훔쳐 먹는다.
- 코믹 전제: 밤에 집을 빠져나온 애완뱀이 냉장고와 방 안의 야식을 몰래 턴다.
- 핵심 실력: 다음 이동을 예측하는 경로 계획, 연속 코너 선입력, 길어진 몸의 공간 관리
- 세션 모델: 충돌 시 즉시 끝나는 최대 5분 생존 점수전
- 예상 플레이 시간: 초보 30~50초, 중급 50~90초, 숙련 90~150초, 극한 150~300초
- 절대 최대 시간: 300초

## 20초 설명 계약

- 목표: 야식을 먹어 점수를 올리고 몸과 벽을 피하세요.
- 조작: 아래 오락실 방향키를 누르세요. 위에 ↑, 아래에 ← ↓ → 배열입니다.
- 예약 입력: 다음 방향을 순서대로 최대 3개까지 미리 저장할 수 있어요.
- 점수: 일반 야식은 1점, 황금 소시지는 3점, 움직이는 쥐는 2점이며 모두 몸이 한 칸 길어져요.
- 종료: 벽이나 자기 몸에 닿으면 즉시 끝나며, 5분을 버티면 현재 점수가 제출돼요.
- 이탈 경고: 플레이 중 앱을 나가면 점수 없이 오늘 기회가 소진돼요.
- 예상 읽기 시간: 약 18~20초

## 핵심 루프

- 초기 상태:
  - 9열×15행 보드 중앙 행에서 몸 길이 4칸으로 시작한다.
  - 머리는 `(7, 4)`, 몸은 왼쪽으로 이어지며 진행 방향은 오른쪽이다.
  - 첫 음식은 `(7, 6)`에 고정해 첫 성장 규칙을 빠르게 가르친다.
- 반복 행동: 플레이어가 방향키를 누르면 뱀은 현재 이동 간격에 맞춰 한 칸씩 진행한다.
- 입력 반응: 유효한 방향은 최대 3개까지 FIFO 큐에 저장되며 이동 틱마다 하나씩 적용된다.
- 성장: 일반 음식은 +1점, 황금 소시지는 +3점, 쥐는 +2점이며 어느 것을 먹어도 몸은 한 칸 길어진다.
- 황금 소시지:
  - 첫 이벤트는 활성 플레이 30~60초 사이에 도달 가능한 빈 모서리에서 출현한다.
  - 먹거나 10초 안에 먹지 못해 사라지면 30초 쿨다운 뒤 다음 쥐 이벤트를 시작한다.
- 쥐:
  - 황금 소시지 이벤트가 끝난 뒤 30초 쿨다운 후 출현한다.
  - 일반 음식·황금 소시지·뱀과 겹치지 않는 칸에서 시작하고, 약 1초마다 합법적인 인접 칸으로 천천히 움직인다.
  - 잡거나 15초 안에 잡지 못해 사라지면 30초 쿨다운 뒤 다음 황금 소시지 이벤트를 시작한다.
- 이벤트는 5분 종료까지 황금 소시지와 쥐가 번갈아 계속 반복된다.
- 이벤트 순서: 같은 프레임에는 뱀 이동과 충돌·획득을 먼저 확정하고 그 뒤 쥐를 이동시킨다.
- 실패: 다음 머리 칸이 보드 밖이거나 현재 몸과 겹치면 즉시 종료한다.
- 시간 종료: 300초에 현재 점수를 정상 제출한다.
- 보드 완료: 도달 가능한 빈칸이 없어지면 클리어로 종료하고 현재 점수를 제출한다.

## 입력 계약

- 제스처: 하단 방향 버튼의 pointer down에서 한 번 입력한다. 드래그 조향 없음.
- 조작부: `(0, 590, 360, 174)`. 키캡은 앵커 `(180, 590)` 기준 1.4875배로 표시하고, 하단 배경은 원본의 x 좌표와 외벽을 유지한 채 세로로 확장해 상단 ↑와 아래 ← ↓ → 역T 배열을 수납장 중앙에 표시한다.
- 게임판: `(48, 108, 264, 468)`, 9열×15행. 기존 보드 렌더링 전체를 같은 좌표 변환으로 확대해 뱀·음식·충돌 격자가 일치한다.
- 아트: 승인 시안에서 HUD·뱀·음식을 제거한 `kitchen_playfield.png` 360×764를 전체 배경으로 표시한다. 기존 아파트의 9×15 바닥 타일과 하단 조작부를 같은 원본에서 재사용해 규칙 격자를 보존한다. 확대된 키캡은 약 62×61 논리 px다.
- 터치: 확대되어 보이는 각 키 영역을 hit target으로 사용하며, 네 영역은 서로 겹치지 않는다.
- 눌림: 같은 버튼 아트를 호박색으로 착색하고 2px 내려 0.18초 표시한다.
- 재터치: 별개 입력이며 손을 놓았다고 중복 입력하지 않는다.
- 예약 수: 최대 3개
- 반대 방향:
  - 현재 진행 방향의 정반대는 거부한다.
  - 예약이 있으면 마지막 예약 방향의 정반대를 거부한다.
- 같은 방향 반복: 현재 또는 마지막 예약 방향과 같으면 거부한다.
- 멀티터치: 도착한 버튼 탭을 순서대로 기존 예약 큐에서 판정한다.
- 카운트다운: 입력을 받지 않는다.
- 유효 입력 피드백: 선택 햅틱
- 무효 입력 피드백: 별도 햅틱이나 화면 효과 없이 무시

## 상태 머신

```text
loading
  → countdown
  → playing
      ├─ wall collision ─────→ finished(gameOver, score submit)
      ├─ self collision ─────→ finished(gameOver, score submit)
      ├─ 300s timeout ───────→ finished(timeUp, score submit)
      ├─ board complete ─────→ finished(clear, score submit)
      └─ app exit/background → interrupted(no score submit)
```

- 기본 카운트다운은 3초다.
- 에셋 준비와 카운트다운이 모두 끝난 뒤에만 이동을 시작한다.
- 벽·몸 충돌은 0.5초, 시간·보드 완료는 0.25초의 결과 연출 뒤 종료 콜백을 보낸다.
- 모든 정상 종료는 하나의 보호된 경로를 사용하며 결과는 최대 한 번만 방출한다.
- 중단은 엔진과 입력을 멈추지만 점수를 만들지 않는다.

- 추가 수작업 콘텐츠가 없어도 플레이 경로와 음식 위치 조합으로 매 판 상태가 달라진다.

## 난수와 한 번의 시도 공정성

- 기본 시드: 한국 시간 오전 6시 경계를 적용한 날짜와 `rulesVersion`
- 랜덤 요소: 다음 음식 위치와 6종 음식 타입, 첫 황금 소시지의 출현 시각·보너스 위치, 쥐의 합법 이동
- 고정 요소: 시작 몸, 시작 방향, 첫 음식
- 생성 제약:
  - 현재 몸이 차지한 칸은 제외한다.
  - 현재 머리에서 BFS로 도달 가능한 빈칸만 후보로 사용한다.
  - 가능하면 머리와 맨해튼 거리 3 이상인 칸을 우선한다.
  - 첫 황금 소시지는 도달 가능한 빈 모서리에만 놓고 60초까지 자리가 없으면 해당 이벤트를 건너뛴다. 반복 이벤트는 쿨다운 뒤 합법적인 자리가 생길 때까지 재시도한다.
  - 쥐는 뱀·일반 음식·황금 소시지를 밟지 않으며 합법 이동이 없으면 그 칸에 머문다.
  - 황금 소시지와 쥐는 동시에 화면에 존재하지 않는다.
- 생성 실패: 도달 가능한 빈칸이 없으면 보드 완료로 정상 종료한다.
- 피할 수 없는 상태 방지: 새 음식은 생성 순간 현재 머리에서 도달 가능한 경로가 있는 칸에만 놓인다.
- 입력 스팸 방지: 큐는 3개로 제한하고 같은 방향·즉시 반대 방향·네 번째 입력을 거부한다.
- 대기 악용 방지: 뱀은 자동 전진하므로 멈춰서 점수를 보존할 수 없다.
- 오프스크린 악용 방지: 보드 밖 탭은 방향 입력으로 처리하지 않는다.
- 실패 피드백:
  - 벽·몸 충돌 시 뱀의 사망 모션과 충돌 햅틱
  - 시간·보드 완료 시 보드 전체에 청록 오버레이

## 점수와 랭킹

- 플레이어 표시값: 먹이로 획득한 총점
- HUD: `MIDNIGHT SNACKS`, 정수 점수, 남은 초, 현재 몸 길이
- 점수 증가: 일반 음식 +1, 황금 소시지 +3, 쥐 +2
- 제출 정수: `0~145`
- 상한 근거: 5분 안에 가능한 최대 5회 황금 소시지(+2씩)와 4회 쥐(+1씩)를 일반 음식 상한 131점에 더한 값
- 정렬: 높은 점수 우선
- 포맷: `<점수>개`
- 동점: 공통 랭킹의 선제 제출 우선 규칙을 따른다.
- 벽·몸 충돌:
  - 현재 점수를 제출한다.
  - `collisions = 1`, `endType = gameOver`
- 300초 시간 종료:
  - 현재 점수를 제출한다.
  - `collisions = 0`, `endType = timeUp`
- 보드 완료:
  - 현재 점수를 제출한다.
  - `collisions = 0`, `endType = clear`
- 앱 이탈·백그라운드:
  - 점수를 제출하지 않는다.
  - 공통 화면 정책에 따라 시도만 소진한다.
- 보조 결과:
  - `starsCollected = 0`
  - `duration = 1~300000ms` 범위의 실제 활성 플레이 시간
- 서버 검증:
  - 버전 3, 점수 `0~145`, 별 `0`, 충돌 `0 또는 1`
  - 플레이 시간은 예약된 게임 시간 이하여야 한다.
  - `20260913000100_midnight_snake_repeating_bonus_events.sql`이 게임 버전·설명·점수 범위를 갱신한다.

## 프레젠테이션 계약

### 2D 비주얼 콘셉트

- 배경: 밤의 원룸 주방과 열린 냉장고
- 카메라: 세로형 탑다운 고정 시점
- 보드: 청록색 주방 바닥 타일 자체가 실제 9×15 플레이 격자다.
- 분위기: 어둡고 조용한 밤, 냉장고의 따뜻한 빛, 몰래 먹는 코믹한 긴장감
- 시각적 농담: 작고 능청스러운 애완뱀이 사람의 야식을 훔쳐 먹을수록 지나치게 길어진다.
- 픽셀 아트: 굵고 약간 투박하며 어글리 큐트한 실루엣, 최근접 보간, 안티앨리어싱 없음
- 화면 대비:
  1. 황금색 뱀과 밝은 음식
  2. 청록색 플레이 보드
  3. 어두운 주변 가구와 벽
- 몸통:
  - 18 논리 px 황금색 단일 직교 경로
  - 32×32 투명 비늘 타일 반복
  - 실제 방향 전환점만 남겨 불필요한 관절을 만들지 않는다.
  - 이동 틱 전체를 선형 보간해 칸 단위 순간이동처럼 보이지 않게 한다.
- 꼬리: 별도 스프라이트가 아니라 단일 몸통 경로의 둥근 끝
- 머리: 32×32 열린 목 구조의 방향별 래스터 캡

### 플레이어 캐릭터

- 역할: 테라리움에서 탈출한 야식 도둑 애완뱀
- 실루엣: 낮고 긴 몸, 몸보다 조금 넓은 머리, 팔다리와 의상 없음
- 표정: 약간 어긋난 눈과 태연한 얼굴
- 어색하고 귀여운 특징: 진지하게 몰래 움직이지만 몸은 계속 길어져 숨기 어려워진다.

  - 4방향 이동, 방향별 4프레임

### 설명서 4페이지

| 페이지 | 제목 | 가르치는 내용 | 시각 형태 |
|---|---|---|---|
| 1 | 오락실 버튼으로 방향 전환 | ↑ 위, ← ↓ → 아래 역T 배열, 반대 방향 거부 | 승인 조작판 아트와 실제 배경·머리·몸통 |

- 좌우 스와이프, 이전·다음, 페이지 점, 마지막 `설명 끝`, 닫기 버튼을 제공한다.
- 첫 페이지의 `이전`은 비활성화한다.
- 짧은 화면에서는 페이지 본문을 세로 스크롤한다.
- 시각 자료는 별도 영상 파일이 아니라 실제 런타임 배경·아틀라스·몸통 셰이더를 재사용한 경량 스프라이트 애니메이션이다.

### 메인 미리보기

- 세로 비율: `0.78`
- 길이: 16초 반복
- 실제 게임과 같은 배경, 머리, 음식, 몸통 경로와 승인 조작판을 사용한다.
- 점수, 남은 시간, 성장, 여러 코너, 예약 입력 가능 문구를 함께 보여준다.
- 루프 종료 시 어두운 페이드 뒤 점수·시간·몸 상태가 첫 프레임과 함께 초기화된다.
- 첫 프레임만 보이더라도 플레이 장면과 핵심 조작을 이해할 수 있어야 한다.

## 기술 적합성

- 런타임: `FlameGame` + `FixedResolutionViewport(360×764)`
- 순수 규칙: `domain/midnight_snake_rules.dart`
- 경로 보간: `presentation/midnight_snake_path.dart`
- 렌더링·입력·수명주기: `midnight_snake_game.dart`
- 화면 등록: `GameRegistry`, `GamePresentationRegistry`
- 중앙 조정값: 보드 크기, 이동 간격, 예약 수, 임계값, 점수 상한은 `MidnightSnakeRules`
- 렌더링 핵심:
  - 몸 좌표를 한 개의 직교 `Path`로 단순화한다.
  - 현재 몸과 이전 몸을 이동 간격 전체에 걸쳐 선형 보간한다.
  - 황금색 바탕과 같은 경로의 비늘 셰이더를 겹쳐 틈을 막는다.
  - 머리는 경로 첫 점을 32×32 아틀라스로 덮는다.
  - 하단 배경은 원본 `(0, 590, 360, 114)`를 `(0, 590, 360, 174)`로 nearest-neighbor 세로 확장해 외벽·상단 림의 x 좌표를 보존한다.
  - 키 없는 캐비닛 면 `(43, 596, 68, 84)`을 x=`43~317`에 반복해 원본 키캡을 덮고, 원본 키캡 네 조각을 현재 표시 좌표에 개별 재합성한다.
- 프레임 지연 복구: 한 업데이트에서 최대 12개의 누적 이동 틱을 처리한다.
- 백엔드: `public.games.duration_seconds = 300`, 점수 제출 검증은 게임 버전 1의 범위를 사용한다.
- 주요 위험:
  - 120~300초 구간의 선형 가속이 장기 플레이 압력을 적절히 높이는지 미검증
  - 몸이 매우 길어진 상태에서 0.22초 입력이 물리 기기에서도 안정적인지 미검증
  - 첫 무입력 벽 충돌이 활성 플레이 3초 부근이라 안전 오프닝 기준이 경계값임

## 인수 테스트

- 설명서 4페이지에서 조작·예약·성장·충돌·5분 제한·이탈을 20초 안에 이해할 수 있다.
- 보드 밖 탭은 입력을 받지 않는다.
- 상단 ↑, 하단 ← ↓ → 버튼이 키보드 역T 배열로 표시되고 약 62×61 논리 px로 충분히 크게 보인다.
- 같은 방향과 즉시 반대 방향은 거부한다.
- 유효한 방향 3개를 순서대로 저장하고 네 번째 입력을 거부한다.
- 카운트다운과 종료 뒤에는 입력을 받지 않는다.
- 시작 몸, 첫 음식, 이동 방향이 계약과 일치한다.
- 음식은 빈칸이면서 현재 머리에서 도달 가능한 위치에만 생성된다.
- 음식 획득은 점수와 몸을 정확히 1씩 증가시킨다.
- 벽·자기 몸·시간·보드 완료가 올바른 종료 유형을 만든다.
- 정상 종료 결과는 정확히 한 번만 제출한다.
- 중단은 가짜 점수를 제출하지 않는다.
- 점수는 `0~131`, 플레이 시간은 `1~300000ms` 범위다.
- 이동 간격은 0.60→0.46→0.42→0.35→0.29초로 변한 뒤 120~300초에 0.25→0.22초로 선형 가속한다.
- 같은 날짜와 규칙 버전은 같은 난수 시드를 만든다.
- 몸통은 직선과 실제 코너만 남기며 이동·성장 중 끊기지 않는다.
- 활성 에셋의 크기와 투명도 계약이 유지된다.
- 메인 애니메이션은 16초 루프를 두 번 이상 자연스럽게 반복한다.
- 예약 입력 설명은 화살표가 실제 회전 순서에 맞춰 체크로 바뀐다.
- 설명서가 짧고 긴 지원 화면에서 잘리거나 넘치지 않는다.
- 실제 게임은 300초에서 시작하고 299초로 정상 감소한다.
