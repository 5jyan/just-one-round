## 핵심 루프와 입력

- 최초 활성 손님은 흑곰=남탕, 흰토끼=여탕 두 종뿐이다.
- 15·30·45초에 새 남탕·여탕 동물을 한 종씩 동시에 해금한다.
- 해금 시 플레이 타이머와 입력을 멈추지 않고 각 입구 아래의 새 얼굴표를 0.8초 동안 금색으로 강조한다.

- 화면 하단의 파란 남탕 또는 빨간 여탕 영역을 탭하면 현재 손님을 즉시 해당 탕으로 보낸다.
- 입력은 화면 하단의 좌우 탭만 사용하며 드래그 판정은 제공하지 않는다.
- 논리 판정 영역은 `x=0..360`, `y=543..617`이며 `x=180`을 기준으로 남탕·여탕을 나눈다.
- 왼쪽은 남탕, 오른쪽은 여탕이다. 판정은 동물 종과 고유 털색 조합만 사용한다.

- 오답이면 같은 손님이 튕겨 돌아오고 콤보가 0이 되며 남은 예약 입력을 비운 뒤 250ms 동안 입력이 잠긴다.
- 콤보 카운터와 최고 콤보는 50에서 고정되며, 27콤보 이상 정답은 계속 360점을 준다.
- 현재까지 해금된 동물의 큰 얼굴 아이콘을 각 탕 입구 아래에 한 줄씩 세로로 표시한다.

## 무작위성과 공정성

- `GameRegistry`가 제공한 `challengeSeed`로 `Random`을 주입해 손님과 해금 후 삽입 순서를 재현한다. 게임을 레지스트리 밖에서 직접 만들면 기본 `Random()`을 사용하므로 일일 시드 자체를 규칙 파일이 생성하지는 않는다.
- 같은 탕은 최대 4명까지만 연속 등장한다.
- 줄에 현재 포함 총 7명의 순서를 미리 보여 운보다 사전 판독이 중요하게 한다.
- 각 동물 종은 한쪽 탕에만 속한다. 유카타 형태는 같고 남탕은 남색, 여탕은 빨간색을 사용한다.
- 해금된 새 두 종은 기존 줄을 바꾸지 않고 다음 무작위 생성부터 후보에 들어간다.
- 대기는 점수를 늘리지 못하며, 탭 한 번에 한 번만 판정하되 보이는 줄을 읽은 연타는 순서대로 예약된다.

## 2D 비주얼 계약

- 세로 고정 카메라에서 왼쪽 정면 남탕 입구, 깊은 중앙 복도, 오른쪽 정면 여탕 입구의 3칸 구조를 사용한다. 손님은 두 입구 사이 중앙 복도 안쪽부터 원근감 있게 줄선다.
- 현재 손님은 화면 아래쪽 전면에 크게, 뒤의 여섯 명은 점차 작게 그리되 종별 얼굴·귀·털색은 읽을 수 있어야 한다.
- 남탕 캐릭터는 흑곰·에스프레소색 강아지·차콜 회갈색 너구리·차가운 차콜색 늑대, 여탕 캐릭터는 흰토끼·연한 밀키 핑크 돼지·크림색 양·흰치즈 고양이다.
- 머리띠, 가슴 표식 같은 문자 표시는 캐릭터에서 제거한다.
- 남탕 동물은 먹빛 남색, 여탕 동물은 짙은 빨간색의 동일한 료칸 유카타를 입어 빠른 색상 판독을 돕는다.
- 손님 셀은 `112×224`를 유지한다. 4×2 아틀라스는 남탕 4종 한 행, 여탕 4종 한 행의 총 8종으로 구성한다.
- 입구 아래 얼굴표는 아틀라스 상단 얼굴 영역을 `52×52`로 잘라 화면 가장자리에서 5px 이상 안쪽에 둔다. 머리와 귀를 자르지 않으며, 어두운 외곽선과 남탕 하늘색·여탕 분홍색의 얇은 이중 테두리로 배경과 분리한다.
- 종별 기본 체형은 유지한다. 남탕 손님은 눈썹과 어깨선을 조금 더 곧고 넓게, 여탕 손님은 곡선 눈썹·아주 작은 속눈썹·높은 허리끈과 살짝 퍼지는 옷자락으로만 구분감을 보조한다.
- 큰 얼굴, 짧은 팔다리, 볼터치와 느슨한 료칸 유카타로 조금 바보 같지만 사랑스러운 인상을 유지한다. 여덟 얼굴은 동일 눈 템플릿을 공유하지 않는다. 남탕은 무뚝뚝한 곰·순진한 강아지·곁눈질하는 너구리·가장 사나운 늑대로 강도를 나누고, 여탕은 타원 눈 토끼·구슬 눈 돼지·초승달 눈 양·호박색 고양이 눈에 짧은 속눈썹과 부드러운 눈썹을 사용한다.
- 정답은 입구 방향 이동, 노렌 젖힘 3프레임, 줄 전진, 가벼운 햅틱과 입력별 독립 성공 버스트로 표현한다. 버스트는 복도 상단 노렌 높이에 표시하고 콤보마다 연속적으로 커지며, 10·20·27콤보에서 링·광선 수·문구 강도가 추가 상승한다.
- 하단 `男·女` 입력은 화면 폭을 거의 반씩 차지하는 `164×82px` 불투명 남색·적색 버튼, 금색 외곽선, 흰색 대형 한자로 표시한다. 버튼 아래 기준선은 고정하고 위쪽으로 터치 영역을 함께 확장한다.
- 오답은 반대 방향 튕김, 붉은 플래시, 강한 햅틱으로 표현한다.
- 배경은 `180×360` 원화를 2배 정수 확대하고, `男·女` 노렌은 `80×80` 셀 3열×2행 아틀라스를 `128×128`로 표시한다.

## 기술 및 검증 계약

- 순수 규칙은 `domain/bathhouse_sort_rules.dart`, Flame 입력·렌더링은 `bathhouse_sort_game.dart`에 둔다.
- 검증 항목: 0·15·30·45초 활성 명단, 3→2→1 카운트다운, 무중단 해금, 기존 줄 불변, 큰 얼굴 목록 강조, 좌우 탭 경계, 드래그 입력 부재, 32개 FIFO 예약, 입력별 성공 버스트, 콤보별 이펙트 배율, 50콤보 상한, 20ms 판정 간격, 800ms 만료, 오답 시 예약 제거, 7명 큐 유지, 70ms 전진, 250ms 오답 잠금, 시드 재현, 점수 경계, 60초 단일 결과, 중단 무결과, 짧고 긴 화면의 배경 채움.
