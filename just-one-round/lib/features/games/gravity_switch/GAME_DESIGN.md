# 중력 스위치

## 상태

- 상태: Implemented (안전 시작 밸런스 검증 필요)
- 게임 ID: `gravity_switch`
- 규칙 버전: 1
- 마지막 소스 확인일: 2026-10-13
- 300초 강제 종료가 런타임·레지스트리·가이드·서버 검증에 적용되어 있다.

## 플레이어 약속

- 한 문장 약속: 자석 진드기의 중력을 탭으로 뒤집어 우주 고철 통로의 바닥과 천장을 번갈아 달린다.
- 코믹 전제: 작은 자석 생물이 거대한 우주 폐기장에 붙어 이동하다가, 앞을 막는 고철을 볼 때마다 몸 전체의 극성을 뒤집는다.
- 핵심 실력: 다음 통로 판독, 탭 타이밍, 연속 착지 계획
- 세션 모델: 충돌 즉시 종료되는 생존전
- 목표 실패 구간: 초보 30~35초, 중급 35~75초, 숙련 75~150초
- 승인 절대 최대: 300초

## 20초 가이드 계약

> 캐릭터는 왼쪽에 있고 고철 통로가 다가옵니다.  
> 화면을 탭하면 중력이 뒤집혀 바닥과 천장 사이를 이동해요.  
> 벽에 한 번 닿으면 끝입니다. 다음 빈 통로를 미리 보고 최대 5분 동안 오래 살아남으세요!

- 조작: 화면 어디든 단일 탭
- 점수: 실제 생존 시간
- 실패: 고철 벽과 충돌
- 예상 읽기 시간: 약 13초

## 핵심 루프와 입력

- 시작: 3초 카운트다운과 안전한 초기 통로
- 반복: 다음 기둥의 빈 쪽 확인 → 탭 → 반대 표면으로 가속 → 착지 → 다음 통로 확인
- 캐릭터 x: 92 고정, 맵만 오른쪽에서 왼쪽으로 이동
- 중력 가속도: 5200
- 최대 수직 속도: 1400
- 표면 스냅 허용치: 10
- 탭: 플레이 중이고 스위치 게이트가 열려 있을 때 중력 방향을 반전
- 연타: 반전 후 착지할 때까지 같은 이동 중인 재반전은 무시한다. 착지하면 다음 반전을 받을 수 있다.
- 충돌: 고철 윗면·아랫면에는 중력 방향에 맞춰 착지하고, 옆면에 부딪히면 종료
- 중단: 결과를 제출하지 않고 시도만 소진

## 상태 머신

```text
loading → countdown → playing
                         ├─ collision → finished_game_over
                         ├─ 300s → finished_time_up
                         └─ interrupted
```

- 정상 종료 결과는 생존 밀리초로 한 번만 방출한다.

## 난이도와 패턴 계약

### 시간 구간

| 구간 | 시간 | 사용 패턴 | 스크롤 속도 | 플레이 요구 |
|---|---:|---|---:|---|
| 안전 시작 | 0~3초 초과 | 초기 평면 12열 | 160~164.5 | 조작 확인 |
| 초급 | 3~35초 | easy 6종 | 164.5~212.5 | 여유 있는 반전 |
| 중급 | 35~75초 | medium 8종 | 212.5~272.5 | 연속 통로 계획 |
| 숙련 | 75~110초 | hard 4종 | 272.5~325 | 짧은 반응과 정확한 착지 |
| 극한 | 110~300초 | hard 7종 반복 | 325~360 | 실수 없는 연속 처리 |

- 스크롤 속도: `min(360, 160 + 1.5 × 경과초)`
- 패턴은 같은 ID를 바로 연속 선택하지 않도록 한다.
- 현재 맵 JSON에는 플레이용 패턴 21개가 있으며, `testOnly`로 제외된 패턴은 없다.
- 맵은 세로 최대 12줄(48px 간격)을 사용한다. 부족한 줄은 위아래 벽으로 채워 기존 8줄 맵의 충돌 좌표를 유지한다.
- hard 패턴은 깊은 상하 관문과 섬 벽·엇박자 관문을 포함한다. 4개가 75초부터, 나머지 3개가 110초부터 후보에 들어온다.
- 첫 고철 충돌 가능 시점이 활성 플레이 3초를 초과하는지 자동 테스트한다. 부족하면 초기 안전 열 수를 늘린다.

## 콘텐츠 확장성과 Codex 적합성

- 수작업 맵: 플레이용 21개
- 등급: easy 6, medium 8, hard 7
- 새 패턴: 연속 반전, 섬 마감 관문, 엇박자 연속 관문
- 변화: 패턴 순서, 고철 모듈 외형 배치, 스크롤 속도
- 수치 제어: 속도, 등급 해금 시점, 초기 안전 열, 중력 가속도
- 구현 복잡도: 중간
- 주의: 새 패턴은 플레이 가능성과 난이도별 반응 시간을 확인한 뒤 추가한다.
- 자동 테스트:
  - 모든 map 파싱과 내부 벽 구간 인식
  - 각 열에 열린 통로 존재
  - 등급별 시간 해금
  - 같은 시드의 패턴 순서
  - 첫 충돌 가능 시점
  - 중력 운동과 착지 스냅
  - 300초 종료와 결과 1회 방출

## 무작위성과 공정성

- 난수 주입: 가능
- 무작위 요소: 현재 시간 등급 안의 다음 패턴과 고철 모듈 외형
- 합법성: 패턴 파일 파서가 화면을 완전히 막는 열을 거부하고, 통로 안의 벽을 충돌 장애물로 읽는다.
- 연속 중복: 후보가 둘 이상이면 직전 패턴과 같은 ID를 피한다.
- 안전 시작: 초기 12개 열은 첫 패턴의 안전 프로필로 고정한다.
- 피할 수 없는 실패 방지:
  - 모든 통로는 캐릭터 크기와 착지 운동으로 통과 가능해야 한다.
  - 패턴 경계의 연속 전환도 실제 운동 시뮬레이션으로 검증해야 한다.
- 현재 런타임은 후보가 없을 때 별도 easy 폴백을 두지 않고 후보 목록에서 선택한다. 맵 데이터가 진행 구간마다 후보를 제공해야 한다.
- 대기·연타 악용: 맵은 항상 흐르고 탭 자체는 점수를 만들지 않는다.
- 실패 피드백: 캐릭터 KO, 충돌 지점 고철 강조, 즉시 게임오버

## 점수와 랭킹

- HUD: 0.01초 생존 시간
- 제출 정수: 생존 밀리초
- 표시: `N.NN초`
- 순위: 높은 값 우선
- 충돌: 충돌 직전까지의 시간 제출
- 300초 종료: 300000ms, 충돌 0, `timeUp` 제출
- 중단: 제출 없음

## 2D 비주얼 콘셉트

- 장소: 남색 우주 공간을 가로지르는 보라색·녹색 고철 압축 통로
- 카메라: 고정 측면 2D, 360×640 코어와 세로 오버스캔
- 플레이어: 48px 자석 진드기. 작은 몸, 큰 자석성 발, 진지하지만 얼빠진 표정
- 어색한 특징: 중력이 바뀔 때 몸보다 발이 먼저 천장 쪽으로 끌려가며 빙글 돈다.
- 사랑스러운 단서: 한쪽 눈이 착지보다 반 박자 늦게 따라온다.
- 위험: 녹슨 기계, 파이프, 배터리, 나사로 구성된 굵은 고철 벽
- 픽셀 방향: 낮은 원본을 2배 표시, 굵고 계단진 덩어리, 제한된 명암
- 대비 우선순위: 열린 통로 > 플레이어 > 충돌 면 > 장식 모듈 > 우주 배경
- 성공 비트: 착지 시 작은 자력 불꽃
- 실패 비트: 자석 발이 고철에 붙고 몸이 납작해진 KO

## 기술 위험·인수 테스트

- 런타임: Flame 횡스크롤 + 순수 중력 운동 + JSON 패턴
- 중앙 조정: `GravitySwitchRules`, `GravityMapLayout`
- 현재 미사용 규칙 값 `safeColumnCount`, `hazardHeight`, `alternatingPatternChance`는 런타임 계약에 포함하지 말고 정리 여부를 별도로 결정한다.
- 주요 위험: 패턴 경계 통과 가능성, 3초 안전 시작, 모듈 장식과 실제 충돌면 혼동
- 모든 패턴과 경계를 입력 시뮬레이션으로 통과 가능성 검사
- 첫 실패 가능 시점 3초 초과
- 초보·중급·숙련 목표 실패 분포
- 300초 강제 종료
- 결과 정확히 1회
- 지원 화면에서 보이는 고철과 판정 면 일치
