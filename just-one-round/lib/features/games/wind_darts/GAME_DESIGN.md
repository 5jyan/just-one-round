# 바람 다트

## 상태

- 상태: v3 무제한 조준 런타임·가이드·발별 온라인 기록 구현. 로컬 PostgreSQL 검증과 6발 플레이·저장 확인 완료. 스토어 배포·일일 편성·실사용 밸런스 검증은 남음
- 게임 ID: `wind_darts`
- 규칙 버전: 3
- 마지막 승인: 2026-10-05
- 범위: 어두운 서부시대 펍에서 손과 기계 장식 없이 표준 다트판만 겨누며 상대 기록과 겨루는 2D 화면. 상대 초상은 사용하지 않는다.

## 플레이어 약속

- 한 문장 약속: 바람을 읽고 흔들리는 조준점을 원하는 순간 놓아 고정된 표준 다트판의 고득점 구역을 맞힌다.
- 핵심 실력: 12방향 바람 보정, 거리별 조준 타이밍, 카메라가 가까워지는 착탄 확인
- 세션 모델: 총 6발 고정 점수전
- 투구 거리: 1m → 1.5m → 2m → 2.5m → 3m → 3.5m
- 제한 시간: 없음. 조준 시간 게이지는 6초에서 가득 차지만 계속 누르고 조준할 수 있으며, 정상 완료는 여섯 발 투척으로 끝난다.

## 20초 가이드 계약

> 바람 화살표와 풍속을 읽으세요. 화면을 누르고 있는 동안 조준점이 좌우·상하로 흔들리고 하단의 조준 시간 게이지가 천천히 찹니다. 손가락을 끌어 조준점을 보정하고, 원하는 위치와 타이밍에 손을 놓아 발사하세요. 착탄점은 놓는 순간의 조준점과 바람으로 정해집니다. 매 발 거리가 늘어나며, 표준 다트판 점수를 합산해 6발 기록을 만듭니다.

- 목표: 여섯 발의 표준 다트 점수 합을 높인다.
- 조작: 포인터를 누르면 조준·게이지가 시작되고, 누른 채 드래그하면 조준점을 보정하며, 놓으면 한 발을 발사한다.
- 점수: 숫자 영역은 싱글/더블/트리플 배수, 중앙 불의 안쪽·바깥쪽 모두 50점이다.
- 실패: 빗나간 발은 0점이며 즉시 게임오버는 없다. 앱 이탈은 기존 공통 중단 정책을 따른다.

## 핵심 루프와 상태

- 시작: 로딩·카운트다운 뒤 1m 투구를 준비하고, 화면 기준 바람 화살표와 `m/s`를 표시한다.
- 매 발: 풍향·풍속 미리보기 → 포인터다운 → 흔들리는 조준점과 조준 시간 게이지 확인 → 드래그로 조준점 보정 → 포인터업 발사 → 카메라가 비행 다트를 따라 판까지 가까워짐 → 다트가 꽂히면 판과 다트를 함께 멈추고 착탄 위치 및 발별/누적 점수를 2초간 표시.
- 바람은 해당 발의 미리보기부터 착탄까지 고정한다. 판은 고정된 방향으로 표시한다.
- 착탄 판정은 발사 순간의 조준점·바람·발사 거리와 다트 위치를 사용한다. 표준 숫자 배치는 판에 붙어 있다.
- 발이 끝나면 다음 거리로 진행한다. 2초 착탄 표시 뒤 화면은 0.7초 동안 뒤로 물러나 다음 거리의 판 크기로 복귀하며 HUD 크기는 유지한다.
- 성공: 여섯 발의 착탄 연출이 끝나면 합계를 한 번 제출한다.
- 오발·판 밖: 해당 발 0점, 남은 발은 계속 진행한다.
- 종료: `finished`는 6발 완료 후 합계와 발별 배열을 한 번 제출한다. `interrupted`는 기존 공통 정책대로 시도만 소진하고 점수를 만들지 않는다. 앱 이탈·일일 마감 처리는 기존 공통 서버 정책을 따른다.

표준판 숫자 순서는 20부터 시계 방향으로 `20, 1, 18, 4, 13, 6, 10, 15, 2, 17, 3, 19, 7, 16, 8, 11, 14, 9, 12, 5`다.

## 입력 계약

- 포인터다운 즉시 조준점을 판 정중앙에 놓고 조준/시간 루프를 시작한다.
- 누르는 동안 조준점은 좌우와 상하 성분을 가진 예측 가능한 경로로 흔들린다. 포인터 이동량만큼 조준점을 보정하며 보정 거리는 판 반지름의 75%로 제한한다.
- 누르는 동안 조준 시간 게이지는 차오른다. 게이지는 누른 시간을 보여 주며 착탄점은 포인터업 순간의 조준 위치와 해당 발의 바람으로 정해진다.
- 포인터업 뒤에는 입력을 한 발로 확정하고 다음 발 준비 전까지 중복 발사를 막는다.
- 화면 어디서든 한 포인터로 한 발을 조준한다. 추가 포인터는 무시하고, 취소 이벤트는 발사하지 않고 조준을 초기화한다.
- 조준점은 좌우 `0.36R`, 상하 `0.30R` 진폭으로 서로 다른 주기의 사인파를 따른다.
- 조준 시간 게이지는 0초부터 6초까지 선형으로 차며, 6초 이후에도 게이지는 가득 찬 상태로 유지된다. 발사는 포인터업에서만 일어나며, 놓는 순간의 조준 위치를 사용한다.
- 카운트다운 중 입력은 무시하고 시각 피드백만 표시한다. 한 발 확정 뒤 중복 발사는 막는다.

## 상태 머신

```text
loading → countdown → playing(shotPreview → aiming → flight → impact)
                                      ├──────────────→ nextShot
                                      ├──────────────→ finished(6발 제출)
                                      └──────────────→ interrupted(무제출)
```

- 결과는 6발 정상 완료 또는 기존 공통 중단 정책의 한 경로에서만 정확히 한 번 방출한다.
- 비행·착탄 연출 중 앱 백그라운드, 홈 이동, 잠금은 중단 처리한다.

| 3발 | 2m | 카메라 접근 중 착탄 위치 확인 | 거리 2m | 판 축소·비행 증가 |
| 4발 | 2.5m | 바람·조준 타이밍 동시 판단 | 거리 2.5m | 판 축소·비행 증가 |

| 변수 | 구현된 규칙 | 검증할 부분 |
|---|---|---|
| 투구 수 | 정확히 6발 | 없음 |
| 거리 | 1, 1.5, 2, 2.5, 3, 3.5m 순서 | 화면 원근의 체감 |
| 판 방향 | 시작각 0, 여섯 발 내내 고정 | 없음 |
| 거리 원근 | 고정 월드를 카메라로 후퇴하며 표시 반지름 `142 → 129 → 116 → 106 → 95 → 87px`로 변화 | 거리별 가독성 |

| 조준 흔들림 | 좌우 `sin(2.25t)×0.36R`, 상하 `sin(1.73t)×0.30R` | 사용자 테스트 후 진폭 조정 |

| 비행 | 기본 0.72초, 발마다 0.05초 증가 | 실제 모바일 체감 확인 |
| 상한 | 플레이어 상한 없음. 75초는 서버 세션 메타데이터와 발급 시도 복구 윈도우 계산에만 사용 | 프로덕션 플레이테스트 |

조준점은 누른 시간에 따라 흔들리고, 포인터업 순간의 조준 위치에 바람 편향을 거리 보정과 함께 더해 착탄점을 정한다. 조준 시간 게이지 자체는 착탄 위치에 별도 편차를 더하지 않는다. 난이도 밸런스는 실제 플레이테스트가 남아 있다.

## 콘텐츠 확장성과 공정성

- 수작업 맵·스테이지는 없다. 표준판 1개, 재사용 투구 공간 1개, 수치화한 바람·조준·카메라 규칙만 사용한다.
- 변화는 일일 시드의 발별 바람 조건과 검증된 조준 위상, 거리별 카메라·비행 변화에서 나온다. 시드 외 무작위는 허용하지 않는다.
- 동일한 일일 시드는 모든 플레이어에게 같은 바람 조건을 제공한다. 날짜와 규칙 버전을 기존 시도 시드에 포함한다.
- 동일한 바람·거리 조건은 결정적이지만, 조준 가능 구간의 공정성은 플레이테스트로 확인해야 한다.
- 판 중심·넓은 영역의 안전한 명중 기회와 고득점 영역을 구분해, 운만으로 피할 수 없는 상태가 생기지 않게 한다.
- 입력을 오래 눌러도 자동 발사하지 않는다. 한 발씩 눌렀다 놓는 입력만 점수에 반영하며, 게이지는 6초 이후에도 조준 시간을 표시하는 가득 찬 상태를 유지한다.
- 순수 Dart 투사·점수·시드 규칙과 Flame 2D 렌더링을 분리해 테스트한다.

## 점수·랭킹

- 숫자 영역: 싱글 `N`, 더블 `2N`, 트리플 `3N`; 중앙 불 전체 `50`; 판 밖 `0`.
- 한 발 최고점은 트리플 20의 60점, 여섯 발 제출 범위는 `0..360` 정수다.
- 보너스 콤보나 캐릭터 점수는 없다. 표준 영역 배수만 사용한다.
- HUD에는 현재 발, 거리, 누적 점수, 바람 방향, 풍속 `m/s`, 조준점, 조준 시간 게이지를 표시한다.
- 동점 처리는 기존 랭킹 정책을 따른다.
- 정상 완료는 6발 합과 발별 점수 배열을 함께 제출한다. 중단은 제출하지 않는다.

## 현재 구현과 남은 연결

- 런타임: `WindDartsGame`이 6발 입력·바람·조준 시간·투사·고정판 착탄·합계/발별 점수 제출을 수행한다. 규칙과 화면 코드는 각각 `domain/wind_darts_rules.dart`, `wind_darts_game.dart`에 둔다.
- 프리뷰/가이드: 정적인 구성 검수 이미지는 `assets/source/imagegen/wind_darts/qc/`에 있고, 앱 홈에는 고정판·거리별 카메라·조준점 미리보기를 사용한다.
- 온라인 발별 기록과 상대 배정은 v1 `20261004000100_wind_darts.sql`, v2 `20261005000100_wind_darts_v2.sql`, v3 무제한 조준 마이그레이션으로 제공한다. 기존 v1/v2 5·6발 시도·기록·재전송은 보존하고, 새 v3 시도는 6발·최대 360점으로 검증한다. v1/v2 상대는 같은 규칙 버전의 최고 기록을 기준으로 삼고, v3 도전자의 기존 v1/v2/v3 최고 기록보다 높은 v3 후보만 배정한다. 75초 카탈로그 값은 공용 세션 스키마 호환용 메타데이터이며 플레이 제한으로 사용하지 않는다. 카탈로그 활성 여부와 기존 일일 편성은 보존한다.

## 상대 기록 대결

- 초상 없이 랭킹 상대의 닉네임과 점수만 표시한다.
- 내 6발 각각의 점수를 합계와 별도로 저장한다. 매 착탄 직후 같은 순번의 상대 발 점수를 보여 주고, 결과 화면에서 여섯 발 각각을 비교한다.
- 상대는 같은 규칙 버전에서 전체 기간의 내 최고 합계보다 높은 유저 최고 기록 중 무작위로 고른다. 해당 기록이 없으면 360점 봇을 상대한다. 360점은 규칙상 최고점이므로 개인 최고가 360점이면 더 높은 상대가 존재할 수 없다.

## 서부 펍 비주얼 계약

- 화면은 어두운 앤티크 서부시대 펍 배경 위에 고해상도 픽셀 텍스처 표준 다트판만 플레이 오브젝트로 보여 준다. 손과 캐비닛은 런타임에 렌더링하지 않으며, 기존 원본은 보존된 아카이브로 둔다. 상대 초상은 두지 않고 상대 이름/점수만 UI에 둔다.
- 360×640 논리 뷰포트에서 `pub_interior.png`를 cover로 채운 뒤 담갈색 어둠막과 가장자리 비네팅을 얹는다. 다트판은 화면 중앙 `(180, 235)`에 고정하고, 첫 발은 scoring radius 142px에 해당하는 크기로 크게 보여 준다.
- `board_face.png`는 중심 `(288, 288)`의 576×576 RGBA 텍스처다. scoring radius는 228px이며, 숫자 전용 어두운 목재 띠를 포함한 외곽 시각 반지름은 280px 이하로 둔다. 숫자는 board face에 굽지 않는다.
- `board_numbers.png`는 320×256 RGBA, 64×64 셀 5×4 atlas다. 값 1~20을 row-major로 배치하고 각 glyph 중심은 셀 `(32, 32)`에 둔다. 런타임은 source number orbit radius 260px의 별도 외곽 띠에 표준 숫자 순서를 배치한다.
- `dart_atlas.png`는 192×128 RGBA, 96×128 셀 2개 atlas다. 왼쪽은 비행 다트, 오른쪽은 임팩트 다트이며 두 셀 모두 tip anchor `(48, 12)`를 사용한다. nearest-neighbor와 anti-alias off로 true impact tip에서 그린다.
- 게임과 홈/가이드 프리뷰는 `presentation/wind_darts_art.dart`의 같은 board/number/dart renderer를 사용한다. renderer의 고정 `+9°` 정렬과 scorer의 `-9°` 호환 각도를 합쳐 20번 중심을 정확히 12시에 둔다. 더블·트리플 링은 각각 기존보다 두 배 넓은 판정 영역을 사용한다.
- 각 거리 단계에서는 월드 판 반지름을 `142×0.45=63.9px`로 고정하고 화면 표시 배율을 `표시 board scale÷0.45`로 바꾼다. 펍 배경·판·비행 다트는 `(180, 235)` 피벗의 하나의 camera transform을 함께 적용하고, HUD는 카메라 바깥 화면 좌표에 고정한다. 발사 시 조준·거리·착탄점을 월드 좌표로 고정하고, 비행 중 현재 거리 배율에서 full-board 배율 `1.0`까지 0.72~0.97초 동안 부드럽게 접근한다. 비행·착탄 다트는 true tip anchor를 기준으로 월드 판 크기에 맞춰 그리며, 착탄점에는 짧은 접촉 그림자와 따뜻한 링을 덧댄다. 착탄 2초 정지 뒤 0.7초 동안 부드럽게 뒤로 물러나며, 그 동안 `shotPreview`를 유지하되 입력을 막고 `뒤로 이동 중`을 표시한다. 하단 게이지는 320px 길이로 6초 동안 왼쪽에서 오른쪽으로 선형 충전한다.
- 첫 착탄 뒤 왼쪽 아래 `(10, 414)`에 `score_parchment.png`를 120×160으로 표시하고, 여섯 줄에 라운드·내 점수·상대 점수를 유지한다. `aim_gauge_frame.png`는 `(20, 580)`에 320×36으로, `aim_gauge_fill.png`는 내부 `(28, 592)`의 304×12 영역에 nearest crop으로 채운다. 둥근 외곽 카드 대신 생성된 프레임·양피지와 평면 HUD 텍스트를 사용한다.
- 표시 우선순위는 `풍향·풍속·조준 시간·조준점 > 점수 영역·거리 > 착탄 피드백 > 펍 장식`이다. 바람은 12방향 화살표와 숫자 `m/s`를 함께 보여 준다.
- 재질은 생성된 낡은 목재·시잘·벽돌색·병녹색·무광 브론즈/강철의 weathered pixel cluster 스타일을 사용한다. 마스코트, 손, 캐비닛, 상대 초상은 넣지 않는다.

## 기술 적합성·검증

- 런타임: Flame 고정 2D 화면 + 순수 Dart 다트판/바람/투사 규칙.
- 튜닝 값은 `WindDartsRules`와 게임 런타임 상수에 있다.
- 자동 테스트: 표준 숫자 순서와 배수, 넓어진 더블·트리플 경계, 불 경계, 고정판·같은 시드 바람, 6초 선형 조준 시간 게이지와 이후 연속 흔들림, release-time 조준+바람 착탄, 발사 배율 고정과 비행 중 full-board 접근, 1~3.5m 판 크기, 2초 착탄 대기, 6발 완료·실제 경과시간·합계, 배경 로딩·가이드 렌더.
- 시뮬레이터 확인: 6발 진행, 중앙 불 50점, D-BULL 확대 이펙트, 양피지·게이지 가독성, 카메라 후퇴, 서버 저장. 실사용 점수 분포와 난이도 밸런스는 추가 플레이테스트 대상이다.
- lifecycle 테스트: 카운트다운 입력 무시, 한 발당 한 번 발사, 정상 결과 정확히 한 번, 중단 시 제출하지 않음.
- 포인터 이동 중에도 조준을 유지하며, 6초 이후에도 조준점은 계속 흔들린다. 발사는 포인터업에서만 일어난다.

## 밸런스 가설과 미확정 결정

- 가설: 플레이어가 여섯 발을 원하는 속도로 완료하고, 거리 증가만으로도 후반 정밀도가 충분히 상승한다.
- 필요한 증거: 실제 첫 시도 점수 분포, 거리별 명중률, 풍속·방향별 난이도, 조준 시간 창 도달률.
- 조정 우선순위: 카메라 접근 속도, 풍속 범위, 조준 진폭/주기, 조준 시간 게이지, 거리별 비행 시간.
- 밸런스 검증: 실제 점수 분포, 거리별 명중률, 풍속·방향별 난이도, 조준 시간 창 도달률.
