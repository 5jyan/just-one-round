# 빙글개굴

## 상태

- 상태: 구현 및 집중 검증 완료, 실사용 밸런스 검증 대기
- 게임 ID: `lily_frog`
- 규칙 버전: 5
- 마지막 승인일: 2026-09-23
- 런타임: Flame, 360×640 기준·최대 360×800 가시 논리 해상도

## 플레이어 약속

- 한 문장 약속: 회전하는 연잎 가장자리에서 타이밍을 재다가 탭 한 번으로 접선 방향에 뛰어, 다음 연잎에 아슬아슬하게 착지한다.
- 코믹 전제: 길을 전혀 모르는 자신만만한 개구리가 연못 건너편에 맛있는 파리가 많다는 소문만 믿고 연잎을 갈아탄다.
- 핵심 실력: 현재 회전 방향과 각도, 목표 연잎의 크기와 거리를 함께 읽어 발사 순간을 결정하는 능력
- 세션 모델: 실패 시 조기 종료되는 150초 고정시간 점수전
- 예상 플레이 시간: 초보는 30~50초에 첫 실패, 중급은 50~90초, 숙련자는 90~150초 또는 시간 종료
- 절대 최대 시간: 150초

## 20초 가이드 계약

> 개구리는 연잎 가장자리를 자동으로 돌아요.  
> 원하는 방향을 향했을 때 탭하면 접선 방향으로 점프해요.  
> 연잎을 연속으로 밟고, 먼 연잎과 파리로 보너스를 받으세요.  
> 물에 빠지면 끝!

- 목표: 새로운 연잎에 연속 착지하며 150초 안에 최대한 높은 점수를 얻는다.
- 조작: 개구리가 연잎을 도는 동안 화면을 한 번 탭한다.
- 점수: 새 연잎 착지, 황금·위험 연잎, 공중의 파리 획득으로 얻는다.
- 주요 실패 조건: 점프 궤적이 어떤 연잎의 착지 영역에도 닿지 않아 물에 빠지면 즉시 종료한다.
- 예상 읽기 시간: 약 15초

## 핵심 루프

- 초기 상태:
  - 잔잔한 연못 중앙 하단의 큰 시작 연잎에서 시작한다.
  - 개구리는 시작 연잎의 가장자리를 반시계 방향으로 천천히 돈다.
  - 첫 목표는 화면 중앙 위쪽에 충분히 큰 연잎으로 고정한다.
  - 카운트다운 중에도 개구리는 회전하는 시작 연잎 가장자리를 함께 공전하되, 그림 자체는 화면 위쪽을 향한다.
  - 시작 전에 현재 연잎과 안전한 전방 연잎 두 개를 모두 생성해 다음 경로가 미리 보이게 한다.
  - 활성 플레이 첫 3초 동안은 실패할 점프를 실행하지 않는 안전 보조가 적용된다.
- 반복 행동: 플레이어는 목표 연잎과 개구리의 접선 방향이 겹치는 순간 화면을 탭한다.
- 콤보 행동: 새 연잎에 착지한 뒤 한 바퀴를 채우기 전에 다음 새 연잎으로 점프해 성공하면 콤보가 1씩 오른다.
- 입력 반응:
  - 탭 순간의 중심각 `theta`와 회전 방향 `d`를 고정한다.
  - 화면 평면의 발사 단위벡터는 반시계 방향일 때 `(-sin(theta), cos(theta))`, 시계 방향일 때 그 반대다.
  - 개구리의 평면상 접지점은 이 방향으로 직선 이동하고, 별도의 시각적 높이 곡선으로 점프 동작을 표현한다.
  - 공중에서는 방향을 바꾸거나 추가 점프를 할 수 없다.
  - 연잎 그림은 판정 각속도와 같은 방향·속도로 실제 회전하고, 개구리 그림은 공전·비행 중에도 화면 위쪽을 향한 자세를 유지한다.
  - 처음 세 번의 점프까지 공전 중 실제 접선 벡터가 처음 교차하는 연잎이 있으면 개구리부터 첫 충돌점까지 점선 궤적과 원형 착지 마커를 실시간으로 표시한다.
- 착지:
  - 출발 연잎을 완전히 벗어난 뒤 처음 교차한 합법 연잎의 원형 착지 영역에 내려앉는다.
  - 착지한 접촉각에서 새 연잎의 회전 방향으로 즉시 공전 상태를 시작한다.
  - 새 연잎을 처음 밟았다면 점수를 올리고 진행 기준점을 갱신한다.
  - 착지 순간 연잎 압축, 물결, 점수 팝업을 동시에 재생하며 공전은 멈추지 않는다.
- 진행:
  - 현재 연잎이 화면 아래쪽에 오도록 카메라가 정수 논리 픽셀 단위로 부드럽게 이동한다.
  - 현재 연잎을 기준으로 안전한 다음 연잎 두 개와 선택적인 위험 연잎을 항상 화면 안에서 먼저 보여준다.
  - 플레이어 경로를 따라 결정론적으로 새 연잎 묶음을 생성한다.
  - 안전 연잎은 도달 가능성과 간격 조건을 만족하는 후보 중 가로로 60px 이상 이동하는 배치를 우선해 좌우 이동감을 만든다.
- 회복:
  - 이미 밟은 연잎에 착지해도 실패하지 않지만 점수를 주지 않는다.
- 실패: 최대 비행시간 안에 합법 연잎에 착지하지 못하면 물에 빠지고, 그때까지 확정된 점수를 제출한다.
- 시간 종료: 활성 플레이 150초에 현재 점수를 정상 제출한다.
- 완료: 물 빠짐 또는 150초 시간 종료 중 먼저 발생한 조건으로 끝난다.

## 입력 계약

- 제스처: 화면 어디든 한 손가락 탭
- 유효 터치 영역: 시스템 제스처 안전영역과 HUD 버튼을 제외한 전체 게임 화면
- 유효 상태: `orbiting` 상태에서만 새 점프를 시작한다.
- 탭 판정: 유효 영역에서 포인터가 내려간 순간 즉시 한 번 발사한다. 누르고 있기나 손 떼기에는 추가 반응하지 않는다.
- 착지 프레임 입력: 착지 순간 또는 착지 직후의 탭을 바로 다음 발사로 처리한다. 카메라 이동 연출은 입력을 막지 않는다.
- 공중 입력: 게임 판정에는 반영하지 않고 약한 무반응 햅틱도 발생시키지 않는다.
- 손 떼기와 재터치: 한 번의 유효 탭은 정확히 한 번의 발사를 만든다.
- 멀티터치: 가장 먼저 내려온 포인터 하나만 추적하고 나머지는 무시한다.
- 카운트다운 입력: 점프나 입력 버퍼에 반영하지 않는다.
- 안전 오프닝 입력:
  - 활성 플레이 0~3초에는 착지 연잎과 교차하는 탭만 실행한다.
  - 실패할 방향의 탭은 발사하지 않고 목표 쪽 물결 안내만 한 번 점멸한다.
  - 3초가 지난 뒤에는 같은 입력이 정상적인 실패 가능 점프로 실행된다.
- 유효 입력 피드백: 선택 햅틱, 연잎 눌림, 짧은 도약음
- 안전 보조로 거부된 입력 피드백: 목표 방향 물결 점멸과 작은 개구리 고개 돌림

## 상태 머신

```text
loading
  -> countdown
  -> safe_opening(0~3s)
  -> orbiting
       -> airborne
            |- legal lily hit -> landing -> orbiting
            `- flight timeout -> finished_water(score submit)
       |- 150s timeout -> finished_time(score submit)
       `- app exit/background -> interrupted(no score submit)
```

- `safe_opening`도 활성 플레이 시간에 포함하지만 실패 가능한 발사는 실행하지 않는다.
- `landing`은 짧은 연출 상태이며 착지 점수는 진입 순간 정확히 한 번 확정한다.
- `finished_water`와 `finished_time`은 결과를 정상 제출한다.
- `interrupted`는 홈 이동, 앱 백그라운드, 잠금, 전화, 시스템 UI 또는 앱 종료로 발생하며 시도를 소진하되 점수를 제출하지 않는다.
- 모든 정상 종료는 하나의 보호된 경로를 사용하며 결과 콜백을 최대 한 번만 방출한다.

- 최소 반응 시간: 극한 구간의 유효 접선 정렬 창을 최소 240ms 이상으로 생성한다.

- 한 바퀴 시간과 콤보 만료: 각속도 `ω`에 대해 `2π/ω`초이며 시작 약 `4.65초`, 최고 속도 약 `2.24초`다. 콤보 게이지도 같은 누적 회전 각도를 따른다.
- 함께 바뀔 수 있는 변수: 각속도와 회전 방향 혼합, 또는 착지 영역과 위험 연잎 등장률만 한 구간에서 함께 바꿀 수 있다.
- 상한의 일관성: 끝까지 회전 방향, 접선 발사, 원형 착지라는 같은 규칙만 사용하며 움직이는 연잎이나 새로운 입력을 추가하지 않는다.
- 점수대 가설:
  - 초보: `600~1,800점`
  - 중급: `1,800~4,000점`
  - 숙련: `4,000~7,000점`
  - 극한: `7,000점 이상`

## 콘텐츠 확장성과 Codex 구현 적합성

- 수작업 맵: 없음
- 수작업 스테이지: 없음
- 재사용 패턴: 안전한 단일 후보, 안전·위험 갈림길, 좌우 분기, 이전 연잎 회복 경로의 4개 배치 관계
- 버전 1 에셋 계열:
  - 개구리 1종
  - 일반 연잎 3종과 위험 표시 변형
  - 파리 1종
  - 연못 배경 1종
  - 물결·착지·입수·점수 효과
  - 연잎 방향과 접선 안내 UI
- 변화의 원천:
  - 날짜와 규칙 버전 기반 시드
  - 연잎 중심, 크기, 회전 방향과 각속도
  - 안전 경로와 위험 경로 선택
  - 파리 위치
  - 플레이어의 착지 접촉각과 경로
- 수치 난이도 제어: 각속도, 연잎 지름, 중심 간격, 목표 후보 수, 위험 후보 비율, 파리 배치율
- 추가 수작업 콘텐츠가 필요하지 않은 이유: 소수의 검증된 배치 관계를 크기·거리·방향·순서·시드로 조합하면 매 판 다른 접선 타이밍 문제가 생긴다.
- 구현 복잡도: 중간. 화면 물리는 단순하지만 접선 벡터, 연속 충돌, 절차 생성의 도달 가능성, 카메라와 판정 좌표 분리가 정확해야 한다.
- 자동 테스트:
  - 접선 벡터와 회전 방향
  - 직선 비행과 첫 교차 연잎 선택
  - 출발 연잎 재충돌 방지
  - 착지 접촉각에서의 공전 재개
  - 동일 시드와 입력에서 같은 연잎 필드 재현
  - 모든 생성 묶음의 안전 후보와 최소 타이밍 창
  - 기본 착지·판정·위험·황금·파리 점수
  - 중단과 모든 종료 상태의 결과 방출

## 무작위성과 한 번의 시도 공정성

- 시드: 한국 시간 오전 6시 경계의 오늘 날짜, `gameId`, `rulesVersion`, 서버가 발급한 도전 시드를 조합한다.
- 무작위 요소: 연잎 중심과 크기, 허용 범위 안의 각속도, 위험 후보와 파리 위치. 회전 방향은 예상 착지점과 다음 목표를 바탕으로 생성 시 결정한다.
- 고정 요소: 시작 연잎, 첫 목표 연잎, 초기 회전 방향, 첫 3초 안전 보조
- 합법 생성 조건:
  - 현재 연잎에서 접선 직선으로 도달 가능한 일반 연잎을 최소 하나 제공한다.
  - 일반 후보의 유효 접선 정렬 창은 현재 난이도 구간의 최소 240ms를 만족한다.
  - 목표 연잎 전체와 착지 영역은 HUD를 제외한 화면 안에서 발사 전에 보여야 한다.
  - 목표끼리 겹쳐 첫 교차 판정이 시각적으로 모호해지는 배치를 금지한다.
  - 위험 연잎은 선택 사항이며 유일한 전진 경로가 될 수 없다.
  - 파리는 합법 착지 궤적 부근에만 놓되 획득을 위해 불가능한 착지를 요구하지 않는다.
- 안전 시작: 0~3초에는 실패할 발사를 거부하고 첫 목표를 크고 고정된 연잎으로 제공한다.
- 생성 시 최적화: 선행 생성 단계에서 예상 착지점에서 다음 안전 연잎의 접선 발사 창까지 걸리는 시간을 시계·반시계 양쪽으로 계산해 더 짧은 방향을 미리 정한다. 점프·착지 순간에는 연잎 방향을 바꾸지 않는다.
- 선행 가시성: 매 첫 착지 직후 안전 경로를 보충해 현재 진행 지점보다 앞선 안전 연잎이 항상 최소 두 개 존재하게 한다.
- 피할 수 없는 실패 방지: 연잎은 사라지지 않으며 플레이어는 현재 연잎을 계속 돌아 다음 정렬 기회를 기다릴 수 있다.
- 생성 실패 폴백: 현재 진행 방향의 다음 반회전 안에서 320ms 이상의 정렬 창을 만드는 큰 일반 연잎을 결정론적으로 배치한다.
- 대기 악용 방지: 생존 시간에는 점수를 주지 않고 150초가 계속 흐르므로 기다릴수록 득점 기회가 줄어든다.
- 반복 파밍 방지: 한 번 방문한 연잎은 다시 점수를 주지 않는다.
- 입력 연타 방지: 공중 입력은 버리고, 유효 탭 하나당 발사를 한 번만 만든다. 착지 상태에서의 탭은 새 발사 하나로 소비한다.
- 화면 밖 악용 방지: 화면 밖에 있거나 HUD에 가려진 연잎은 합법 목표가 될 수 없다.
- 실패 피드백: 마지막 비행 궤적을 잠깐 남기고 가장 가까이 빗나간 연잎 테두리를 점멸한 뒤 개구리가 배로 물에 떨어진다.

## 점수와 랭킹

- 플레이어 표시값: 누적 정수 점수
- HUD: `SCORE`, 현재 점수, 남은 초
- 일반 새 연잎 착지 점수: `300 + 현재 콤보×10점` (첫 착지는 `310점`)
- 일반 위험 연잎: 현재 생성되지 않으며, 안전 경로를 대체하지 않는다.
- 황금 연잎 착지: `1000 + 현재 콤보×10점` (기본 `300점`에 황금 보너스 `700점`)
- 파리 획득: 마리당 `+100점`, 황금 선택이 없는 일반 경로의 `50%`에 2~3마리
- 방문 연잎 재착지: 0점
- 콤보: 새 연잎 착지에서 1로 시작한다. 착지 후 한 바퀴 돌기 전에 점프해 다음 새 연잎에 착지할 때마다 상한 없이 1씩 증가하며, 위 착지 점수에 `콤보×10점`으로 반영한다. 한 바퀴를 넘기거나 방문 연잎에 재착지하면 0으로 끊기며, 다음 새 연잎 착지는 다시 1로 시작한다.
- HUD의 `COMBO` 아래 콤보 단계와 같은 색의 게이지는 착지 직후 가득 차고 한 바퀴 공전하는 동안 줄어든다. 마지막 15%에서 깜빡이며 점프 순간 멈추고, 다음 새 연잎 착지에 성공하면 다시 찬다. 콤보가 끊기면 사라진다.
- 2콤보부터 화면 위쪽에 배경 상자 없는 큰 숫자 배너와 착지 충격파·빛살, 짧은 화면 플래시·흔들림, 강한 진동을 재생한다. 1–10 하늘색(연출 약하게), 11–20 노랑, 21–40 주황, 41–70 분홍, 71 이상 보라로 색과 충격파·빛살·광량을 단계적으로 높인다. 연출 중에도 다음 점프 입력을 받는다.
- 제출 정수: `0~200,000`으로 검증하고 10의 배수가 아니거나 파리 수×100보다 작으면 제출을 거부한다.
- 순위 방향: 높은 정수가 높은 순위
- 표시 포맷: 천 단위 구분이 있는 `<점수>점`
- 역변환: 표시 구분자를 제거한 정수와 제출값이 동일하다.
- 상한 근거: 최소 발사 간격과 최대 착지·위험·파리 점수를 조합한 150초 이론상 획득량보다 여유 있게 둔 서버 검증 상한이다.
- 동점: 공통 랭킹의 선제 제출 우선 규칙을 따른다.
- 물 빠짐: 실패 직전까지 확정된 점수를 제출하고 `endType = gameOver`로 기록한다.
- 150초 시간 종료: 마지막 완료 착지까지 확정된 점수를 제출하고 `endType = timeUp`으로 기록한다.
- 중단: 시도만 소진하며 점수나 정상 결과를 제출하지 않는다.
- 보조 결과 필드: 실제 활성 플레이 시간, 새 연잎 착지 수, 위험 연잎 착지 수, 파리 수, 재착지 수, 종료 원인

## 프레젠테이션 의존성

### 2D 비주얼 콘셉트

- 테마와 장소: 저녁빛이 남은 조용한 시골 연못
- 카메라: 세로 화면의 고정 탑다운 2D 시점, 현재 연잎을 화면 중앙 아래에 두는 진행형 카메라
- 분위기: 평화로운 연못과 지나치게 진지한 개구리의 대비
- 시각적 농담: 개구리는 매번 완벽한 계산을 마친 표정으로 뛰지만 다리가 뒤늦게 길게 펴지고, 실패 직전까지도 성공을 확신한다.
- 픽셀 아트 방향: 조금 못생기고 어색하지만 또렷한 실루엣의 chunky pixel art
- 겉보기 아트 픽셀: 화면의 약 `2×2` 논리 px
- 대비 우선순위: 개구리와 목표 연잎 > 위험 테두리와 파리 > 물결 효과 > 배경 생물과 수초
- 팔레트 분위기: 낮은 대비의 청록·남색 물, 밝고 옅은 황연두 연잎, 짙은 에메랄드 개구리와 크림색 배, 위험 후보의 코랄 테두리, 황금 후보와 파리의 노란 강조

### 플레이어 캐릭터

- 역할: 연못을 무작정 횡단하는 작은 개구리
- 실루엣과 비율: 납작한 몸, 몸보다 지나치게 긴 뒷다리, 작은 앞발, 좌우로 튀어나온 눈
- 표정: 입은 일자로 굳어 있고 두 눈이 미세하게 다른 방향을 본다.
- 어색한 특징: 연잎과 이동 방향이 바뀌어도 몸은 화면 위쪽을 향한 채 뻣뻣한 표정을 유지한다.
- 애착 포인트: 한쪽 볼에만 있는 작은 분홍 점
- 필수 동작: 공전, 발사 준비, 점프, 착지 압축, 짧은 기쁨, 물 빠짐
- 장면별 포즈:
  - 시작: 가슴을 내밀고 첫 목표와 조금 다른 곳을 본다.
  - 압박: 눈동자만 빠르게 목표를 따라간다.
  - 성공: 착지 충격으로 납작해졌다가 아무 일 없듯 복원된다.
  - 실패: 허공에서 다리를 한 번 헛젓고 배부터 물에 닿는다.

### 시각적 역할

- 일반 목표: 개구리보다 확실히 밝고 옅은 황연두 원형 연잎과 낮은 대비의 흰 가장자리
- 위험 목표: 일반 연잎과 같은 형태에 코랄색 갈라진 테두리와 작은 금빛 파문을 추가한다.
- 황금 목표: 진행 연잎 5개마다 원본 점유 지름 `128px`의 별도 24K 금색 에셋을 런타임 지름 `104px`로 축소해 일반 안전 경로와 함께 표시한다. 일반 연잎 색 필터나 테두리를 사용하지 않는다.
- 픽업: 노란 몸과 어두운 날개를 가진 파리 한 종류
- 픽업 피드백: 닿는 즉시 5프레임 금빛 POP 이펙트, `파리 +100` 팝업, 중간 강도 진동을 동시에 재생한다.
- 필드 선생성: 현재 안전 경로의 4세대와 황금·일반 선택 양쪽의 직후 후속 연잎을 출발 전에 월드에 추가한다. 스크롤 중 새 연잎이 갑자기 나타나지 않는다.
- 안전 영역: 실제 착지 원을 시각적 연잎의 전체 외곽까지 사용하며, 정확히 끝을 스치는 접선도 착지로 인정한다.
- 회전 안내: 연잎 자체가 판정과 같은 방향·각속도로 돌아 잎맥과 홈의 움직임이 회전 방향을 보여준다.
- 접선 안내: 안전 오프닝과 가이드에서만 개구리 앞쪽에 짧은 점선 궤적을 표시한다.
- 경고: 위험 연잎은 점멸 대신 일정한 코랄 테두리로 표시해 타이밍 신호와 혼동하지 않는다.
- 착지 피드백: 연잎 압축, 원형 물결, 작은 물방울, 점수 팝업, 가벼운 햅틱
- 아슬아슬 착지: 가장자리 착지 때 개구리가 한쪽 다리로 버티고 큰 물방울이 바깥쪽으로 튄다.
- 실패 피드백: 최근 궤적 잔상, 빗나간 연잎 테두리, 배치기 물보라, 충돌 햅틱
- 배경: 수초·작은 물고기·잠자리는 낮은 대비로 천천히 움직이며 게임 판정에는 관여하지 않는다.
- HUD: 상단 안전영역에 점수와 남은 시간을 두고 플레이 공간과 겹치지 않는다.
- 가이드 시각물: 중심에서 개구리까지의 반지름과 직각인 접선 화살표, 성공 연잎 하나를 함께 보여준다.
- 홈 미리보기: 개구리가 큰 연잎을 한 바퀴 돈 뒤 안전한 목표로 점프하고 납작하게 착지하는 짧은 반복 장면

- 재사용 가능 자산: 공통 픽셀 HUD 패널, 숫자 폰트, 점수 팝업 구조, 결과 전환 효과
- `build-game-assets`로 미룰 결정: 실제 소스 크기, 프레임 수, 팔레트 값, 앵커, 충돌 원과 보이는 잎의 정확한 비율, 최종 파일 경로
- 사운드와 햅틱:
  - 발사: 짧은 탄성음과 선택 햅틱
  - 착지: 연잎 크기에 따른 낮은 `퐁` 소리와 가벼운 햅틱
  - 파리: 짧은 삼킴음
  - 아슬아슬 착지: 물방울 강조음
  - 실패: 배치기 물보라와 충돌 햅틱

  - 보이는 연잎과 실제 착지 원의 불일치
  - 카메라 이동 중 월드 좌표와 입력·판정 좌표 혼동
  - 절차 생성이 수학적으로 도달 가능하지만 사람에게 지나치게 좁은 타이밍 창을 만드는 문제
  - 첫 교차 연잎이 시각적으로 예상한 착지 대상과 달라지는 중첩 배치

## 승인 테스트

- 가이드만 읽고 20초 안에 목표, 탭, 접선 점프, 점수와 물 빠짐을 설명할 수 있다.
- 개구리, 회전 연잎과 접선 점프가 하나의 자연스러운 시각·조작 전제를 이룬다.
- 360 논리 px 너비에서 개구리, 일반·위험 연잎, 파리가 즉시 구분된다.
- 첫 3초 동안 어떤 탭 순서로도 물 빠짐 상태에 도달하지 않는다.
- 시계·반시계 공전에서 발사 벡터가 각각 올바른 접선 방향이다.
- 공중 탭, 멀티터치, 카운트다운 탭은 추가 발사를 만들지 않으며, 착지 프레임 탭은 지연 없이 다음 발사로 이어진다.
- 연속 충돌은 큰 프레임 간격에서도 첫 번째 합법 연잎을 놓치지 않는다.
- 출발 연잎은 이탈 전 재착지 대상으로 판정되지 않는다.
- 고정 착지 점수, 위험·황금 보너스, 파리 점수와 재착지 무득점이 정확하다.
- 물 빠짐과 150초 종료는 점수를 정확히 한 번 제출한다.
- 앱 중단은 시도를 소진하지만 점수를 만들거나 제출하지 않는다.
- 모든 생성 묶음에는 화면 안에 보이는 일반 도달 후보가 최소 하나 있다.
- 모든 일반 후보는 해당 구간의 최소 240ms 유효 정렬 창을 만족한다.
- 같은 도전 시드와 같은 입력 기록은 동일한 연잎, 파리, 점수와 종료 결과를 만든다.
- 위험 후보나 파리 때문에 안전 후보가 사라지지 않는다.
- 초보·중급·숙련 점수대가 플레이테스트 목표 분포와 대체로 일치한다.
- 150초를 넘겨 엔진이나 점수가 진행되지 않는다.
- 지원하는 좁고 긴 휴대폰 화면에서도 HUD가 연잎이나 개구리를 가리지 않는다.
- 홈 미리보기와 가이드가 실제 런타임의 회전·접선 방향을 거짓 없이 보여준다.

## 밸런스 가설

| 가설 | 필요한 증거 | 우선 조정값 |
|---|---|---|
| `1.35 rad/s`가 첫 접선 타이밍을 읽기에 충분히 느리고 140초의 `2.80 rad/s`가 과도하지 않다. | 신규 사용자 10회 이상의 첫 점프 성공률과 140초 이후 생존률 | 초기 각속도와 20초 이정표 |
| 최소 240ms 정렬 창이면 한 번뿐인 시도에서도 억울하지 않다. | 초보·숙련자의 구간별 성공률과 체감 설문 | 연잎 지름과 중심 간격 |

| 착지 원을 보이는 잎보다 약간 작게 해도 판정이 정직하게 느껴진다. | 가장자리 착지 리플레이와 오판정 신고 | 충돌 원 비율 |

## 미결정 사항

- 구현 계약상 미결정 사항은 없다.
- 런타임 에셋, 4장 가이드, 홈 애니메이션 미리보기, 클라이언트 레지스트리와 비활성 서버 카탈로그까지 구현했다.
- 위 밸런스 수치는 실제 사용자 플레이테스트로 검증하되, 승인된 핵심 조작·점수 구조·세션 모델은 별도 승인 없이 변경하지 않는다.
