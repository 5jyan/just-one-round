- 코믹 전제: 자기 시간 감각을 과신하는 야근 너구리가 증기에 가려진 고장 난 시계 대신 감으로 파·계란·뚜껑 타이밍을 맞춘다.

- 예상 활성 플레이 시간: 보통 27~35초, 목표 30초
- 절대 상한: 활성 플레이 45초
- 제품 시간 예외: 이 게임은 2~5분을 채우기 위해 같은 행동을 반복하지 않고, 승인된 30초 마이크로게임 정체성을 유지한다.

## 20초 가이드 계약

> 처음 3초 뒤에는 컵라면 증기가 시계를 가려요.<br>
> 10초와 20초에 누른 뒤 표시되는 목표 오차를 참고해 다음 타이밍을 보정하세요.<br>
> 세 번의 오차를 모두 더해 0초에 가까울수록 높은 순위!<br>
> 게임 중 앱을 나가면 오늘의 기회가 사라져요.

- 목표: 게임 시작 후 누적 10초·20초·30초라고 느끼는 순간을 최대한 정확하게 찍는다.
- 조작: 화면 하단의 큰 `10초 · 파 넣기` → `20초 · 계란 넣기` → `30초 · 뚜껑 열기` 버튼을 목표마다 한 번씩 탭한다. 목표 시각은 게임 시작부터 누적된다.
- 점수: 세 탭의 목표 시점 대비 절대 오차를 더하며, 총 오차가 작을수록 좋다.
- 주요 실패 조건: 플레이 중 즉시 실패는 없다. 45초까지 세 번 누르지 않으면 시간 초과로 0점을 제출한다.
- 예상 읽기 시간: 약 14~18초

## 핵심 루프

- 초기 상태: 공통 카운트다운 동안 게임 시계와 입력을 잠근다.
- 보정 구간: 활성 플레이 0~3.0초에는 실제 시간을 `0.00`부터 표시하고 1·2·3초의 시각적 박자를 제공한다.
- 은폐 전환: 3.0~3.2초 동안 컵에서 올라온 증기가 시계를 덮고, 3.2초가 지난 뒤 입력 버튼을 활성화한다. 증기는 결과 전까지 비주기적으로 계속 흐른다.
- 재보정 피드백: 첫 번째와 두 번째 유효 입력 직후 목표보다 몇 초 빠르거나 늦었는지 2초간 보여준다. 실제 누른 시각은 공개하지 않는다.
- 첫 번째 행동: 체감 10초에 탭하면 첫 타임스탬프를 저장하고 파가 컵에 떨어지며 진행 표시가 `1/3`이 된다.
- 두 번째 행동: 체감 20초에 탭하면 두 번째 타임스탬프를 저장하고 계란이 떨어지며 진행 표시가 `2/3`이 된다.
- 세 번째 행동: 체감 30초에 탭하면 세 번째 타임스탬프와 점수를 확정하고 너구리가 뚜껑을 연다.
- 중간 피드백: 첫 두 입력의 부호 있는 오차만 2초간 보여준다. 실제 탭 시각과 부분 점수는 결과 전까지 공개하지 않는다.
- 성공 또는 진행: 각 유효 탭은 정확히 한 체크포인트만 진행시킨다.
- 실패: 정상 플레이 중 즉시 종료되는 실패는 없고 모든 빠름·늦음은 최종 오차가 된다.
- 시간 초과: 활성 플레이 45초에 세 번째 탭이 확정되지 않았으면 `timeUp`, 점수 0으로 종료한다.
- 완료: 세 번째 유효 탭 뒤 결과 타임라인을 보여주고 `clear` 결과를 정확히 한 번 방출한다.

## 입력 계약

- 제스처: 단일 포인터의 탭
- 판정 시점: 버튼 내부의 `pointer down` 시점
- 유효 영역: 하단 중앙의 고정된 대형 목표별 조리 행동 버튼
- 접근성 목표: 최소 48×48 논리 픽셀보다 충분히 크게 제공하고 엄지 도달 영역을 유지한다.
- 임계값과 데드존: 드래그 거리나 누름 시간은 점수에 영향을 주지 않는다. 버튼 바깥 입력은 무효다.
- 손 떼기와 재터치: 손을 뗄 때는 추가 판정하지 않으며, 유효 탭 후 250ms 입력 잠금이 끝나면 다음 탭을 받을 수 있다.
- 멀티터치: 가장 먼저 들어온 활성 포인터 하나만 인정하고 나머지는 무시한다.
- 카운트다운 입력: 모두 무시한다.
- 보정 구간 입력: 3.2초까지 버튼을 비활성화하며 점수나 체크포인트를 만들지 않는다.
- 유효 입력 피드백: 버튼 눌림, 짧은 비주기 음향·진동, 재료 낙하, 진행 표시 증가
- 무효 입력 피드백: 비활성 버튼의 낮은 대비를 유지하고 상태·점수·시계는 바꾸지 않는다.
- 입력 연타 정책: 한 유효 탭은 다음 체크포인트로 되돌릴 수 없이 진행하므로 연타는 이득이 없고, 250ms 잠금으로 우발적 이중 탭을 완화한다.

## 상태 머신

```text
loading
  → countdown
  → calibration_visible
  → clock_covering
  → waiting_for_10
  → waiting_for_20
  → waiting_for_30
  → result_reveal
  → finished_clear

calibration_visible | clock_covering | waiting_for_10 | waiting_for_20 | waiting_for_30
  → finished_timeout

countdown | calibration_visible | clock_covering | waiting_for_10 | waiting_for_20 | waiting_for_30 | result_reveal
  → interrupted
```

- `waiting_for_10`의 첫 유효 탭만 10초 기록으로 인정한다.
- `waiting_for_20`의 첫 유효 탭만 20초 기록으로 인정한다.
- `waiting_for_30`의 첫 유효 탭만 30초 기록으로 인정하고 점수를 잠근다.
- `result_reveal`에서는 입력과 점수 계산을 모두 잠그고 세 기록을 순서대로 공개한다.
- `finished_clear`는 점수와 실제 세 번째 탭까지의 활성 플레이 시간을 제출한다.
- `finished_timeout`은 점수 0과 45초 활성 시간을 제출한다.
- `interrupted`는 시도만 소진하고 점수를 제출하지 않는다.
- 모든 종료 경로는 보호된 단일 완료 함수를 거치며 결과를 최대 한 번만 방출한다.

- 변주 원천: 플레이어의 빠름·늦음과 누적 드리프트, 세 결과 기록, 결과 판정별 코믹 반응
- 수치 난이도 제어: 보정 시간, 목표 시점, 체크포인트 수, 판정 정밀도, 시간 초과, 결과 판정 구간
- 추가 수제 콘텐츠가 필요 없는 이유: 이 게임의 재미는 새 패턴 발견이 아니라 자신의 시간 감각과 일일 랭킹 비교에서 나온다. 게임 로테이션에 포함되므로 단독 장기 캠페인을 요구하지 않는다.
- 구현 복잡도: 낮음. 고정 화면, 단조 증가 시계, 세 타임스탬프, 순수 점수 함수와 작은 상태 머신으로 구성한다.
- 자동 테스트 전략:
  - 가짜 단조 시계를 주입해 입력 시점과 오차를 프레임 독립적으로 검증
  - 점수 정방향·역변환과 포맷터 왕복 검증
  - 각 상태에서 유효·무효 입력 검증
  - 시간 초과, 중단, 정상 완료의 결과 1회 방출 검증
  - 화면 비율별 버튼과 HUD 안전 영역 검증

## 무작위성과 한 번의 시도 공정성

- 주입 시드 또는 난수: 점수·입력·목표 시점에는 난수를 사용하지 않는다.
- 무작위 요소: 선택적으로 증기 입자 배치 같은 장식만 일일 `challengeSeed`로 결정할 수 있다.
- 합법적 생성 제약: 증기 이동은 목표 시점과 동기화하지 않고, 단조로운 진행도나 초 단위 주기를 만들지 않으며, 입력 영역을 가리지 않는다.
- 안전 시작: 활성 플레이 3.2초까지 점수에 영향을 주는 입력을 받지 않는다.
- 최소 반응·회복 기회: 첫 목표 전 6.8초가 남으며, 잘못된 탭도 즉시 판을 끝내지 않고 최종 오차로만 반영한다.
- 피할 수 없는 손실 방지: 장애물·충돌·무작위 실패가 없고 모든 정상 점수는 세 번의 플레이어 입력만으로 결정된다.
- 생성 실패 대체: 장식 시드 생성이 실패하면 정적 증기 또는 단순 비주기 루프를 사용하며 규칙은 그대로 유지한다.
- 프레임 공정성: 시각 애니메이션 누적 시간이 아니라 단조 증가 시계로 `pointer down` 시점을 기록한다.
- 감각 공정성: 3초 이후에는 첫 두 유효 입력의 목표 대비 오차만 같은 방식으로 제공한다. 자동 시계 힌트, 초 단위 음향, 규칙적 진동, 증가하는 게이지, 배경 시계는 제공하지 않는다.
- 대기 악용 방지: 45초에 강제 종료하며 기다릴수록 오차가 증가한다.
- 연타 악용 방지: 각 탭은 체크포인트를 하나 소비하고 되돌릴 수 없으며, 입력 잠금과 단일 포인터 정책을 적용한다.
- 화면 이탈 악용 방지: 홈 이동·백그라운드·잠금·전화·시스템 UI·앱 종료는 중단으로 처리해 점수를 제출하지 않는다.
- 외부 도구 한계: 다른 기기의 스톱워치는 순수 체감 시간 게임에서 완전히 차단할 수 없다. 버전 1은 이 잔여 위험을 받아들이며, 조리 시간 정지 같은 규칙 변경은 실제 악용 증거와 별도 사용자 승인 없이는 추가하지 않는다.
- 실패 피드백: 첫 두 입력 직후 부호 있는 오차를 보여주고, 조리 기록표에서는 1·2·3차의 부호 있는 오차를 각각 표시한다.

## 점수와 랭킹

### 오차 계산

- 목표 시점: `G = [10000, 20000, 30000]ms`
- 실제 유효 탭 시점: `T = [T1, T2, T3]`
- 판정 양자화: `q(t) = round(t / 10) × 10ms`
- 체크포인트 오차: `Ei = abs(q(Ti) - Gi)`
- 총 오차: `E = E1 + E2 + E3`
- 세 체크포인트는 동일한 가중치 1을 사용한다.

### 제출 계약

- 플레이어 표시 단위: 세 체크포인트 총 오차, 소수 둘째 자리 초
- 조리 기록표: 1차·2차·3차 목표 대비 오차만 표시한다.
- 공통 결과 화면: 세부 기록을 반복하지 않고 총 오차와 오늘의 순위·주변 랭킹만 표시한다.
- 플레이 중 HUD: 다음 목표 `10초`·`20초`·`30초`, 진행 `0/3`~`2/3`; 실제 시간과 실시간 점수는 숨긴다.
- 랭킹 방향: 총 오차가 작을수록 우수하나 공통 랭킹은 높은 정수를 우선한다.
- 점수 상수: `rankingCeilingMs = 3,600,000`
- 정상 제출 정수: `raw_score = rankingCeilingMs - E`
- 완벽한 정상 점수: `3,600,000`
- 시간 초과 점수: `0`
- 정상 점수 범위: 250ms 순차 입력 잠금과 45초 경계를 모두 반영한 정확한 범위 `3,525,750~3,600,000`
- 표시 역변환: 정상 점수는 `E = rankingCeilingMs - raw_score`로 복원하고 `E / 1000`을 소수 둘째 자리 초로 표시한다.
- 예시: `9.82초`, `20.31초`, `29.90초`는 `E = 590ms`, `raw_score = 3,599,410`, 표시 기록 `총 오차 0.59초`다.
- 정밀도: 각 시점 10ms, 총 오차 10ms 단위
- 동점: 세 오차의 합이 같은 기록은 동점이며 공통 결정적 순위 규칙을 따른다. 플레이테스트에서 동점률이 높으면 사용자에게 숨은 보조 점수를 넣지 않고 체크포인트 수나 표시 정밀도를 재검토한다.
- 좋지 않은 정상 시도: 세 번째 탭을 완료했다면 낮은 정상 점수를 제출한다.
- 시간 초과: 점수 0, 실제 활성 시간 45000ms, `timeUp`
- 중단: 시도만 소진하고 점수를 제출하지 않는다.
- 지속시간: 정상 완료는 활성 시작부터 세 번째 유효 탭까지, 시간 초과는 45000ms
- 보조 결과 필드: `starsCollected = 0`, `collisions = 0`
- 현재 서버 검증:
  - 게임 ID와 규칙 버전 일치
  - 점수 0 또는 정상 허용 범위
  - 정상 지속시간 3700~45000ms, 시간 초과 45000ms
  - 정상 점수는 `rankingCeilingMs` 이하
  - 총 오차가 세 번째 탭의 `abs(duration_ms - 30000)`보다 작을 수 없음

## 프레젠테이션 의존성

### 2D 비주얼 콘셉트

- 테마와 배경: 한밤중 사무실 휴게실에서 컵라면 하나를 지나치게 진지하게 조리하는 장면
- 카메라와 시점: 360×640 또는 360×720 기준의 고정 정면·약한 2.5D 시점
- 화면 구성: 상단 목표·진행 HUD, 중앙 시계와 너구리·컵라면, 하단 대형 입력 버튼
- 분위기: 조용하고 쓸쓸한 야근 밤에 혼자만 거창하게 집중하는 코미디
- 핵심 시각 개그: 결과가 빠르면 딱딱한 면 블록이 젓가락째 서고, 늦으면 불어난 면발이 컵 테두리 양쪽으로 축 처져 넘친다.
- 카툰 방향: 약간 못생기고 비뚤지만 실루엣과 행동은 명확한 crisp 2D cartoon
- 렌더링: 새 HD 아트는 anti-alias와 medium 필터로 부드럽게 확대하며, 논리 화면의 장면 구도는 고정한다.
- 대비 우선순위: 활성 목표·버튼·시계와 컵라면 > 너구리 행동 > 배경 소품
- 팔레트 분위기: 배경은 차가운 남색·청록, 컵과 면발은 크림·노랑·주황, 성공은 민트·금빛, 실패는 코랄·탁한 갈색
- 시간 단서 제한: 첫 두 입력의 오차 피드백 외에는 배경 시계, 초침, 주기적 형광등, 일정한 물방울처럼 실제 시간을 셀 수 있는 요소를 넣지 않는다.

### 플레이어 주체

- 역할: 시계 대신 자신의 감만 믿고 조리 단계를 실행하는 야근 너구리
- 실루엣과 비율: 둥근 등, 축 처진 어깨, 짧은 팔다리, 헐렁한 셔츠로 한눈에 피곤한 자세를 읽게 한다.
- 표정: 졸리지만 근거 없이 자신만만한 반쯤 감긴 눈
- 어색한 특징: 시간을 셀 때 몸 전체가 굳고 검지만 초조하게 까딱인다.
- 애정 포인트: 볼에 붙은 면발 한 가닥
- 필수 행동: 시계 응시, 증기에 놀람, 파 넣기, 계란 넣기, 뚜껑 열기, 완벽한 결과, 너무 빠른 결과, 너무 늦은 결과
- 시작 포즈: 디지털 시계에 얼굴을 지나치게 가까이 댄 자세
- 압박 포즈: 탭 진행에 따라 식은땀과 굳은 어깨가 늘어나되 실제 시간과 동기화하지 않는다.
- 성공 포즈: 눈이 조금 풀리고 두 손을 드는 어색한 소형 승리 자세다.
- 빠른 실패 포즈: 입을 가리고 어깨를 움츠린 채 딱딱한 면 블록을 후회스럽게 바라본다.
- 늦은 실패 포즈: 불어 넘친 컵 옆에서 어깨와 두 팔을 늘어뜨린 채 주저앉는다.

### 시각 역할

- 목표: 10초 파, 20초 계란, 30초 뚜껑 열기의 세 단계와 상단 진행 표시
- 위험 요소: 물리적 장애물은 없다. 실제 위험은 플레이어의 시간 드리프트다.
- 픽업: 점수 픽업은 없으며 파와 계란은 유효 입력을 확인하는 연출용 재료다.
- 안전 구간: 활성 플레이 0~3.2초의 시계 보정 및 입력 잠금
- 경고 언어: 시간 초과 직전에도 정확한 시간이나 규칙적인 점멸을 제공하지 않는다. 버튼은 고정된 상태를 유지한다.
- 탭 피드백: 버튼 눌림, 재료 낙하, 진행 점 하나 활성화
- 근접 성공 피드백: 결과 공개에서 목표선 가까이에 실제 기록 마커를 배치하고 금빛 테두리를 사용한다.
- 실패 피드백: 목표선 좌우의 빠름·느림 방향, 수치 오차, 가장 큰 오차 강조, 면발 상태 개그
- 배경 동작: 컵에서 시계까지 증기가 계속 비주기적으로 흐르며 조명·배경·대기 포즈에는 셀 수 있는 주기 신호를 두지 않는다.
- HUD 관계: 시계가 가려진 뒤에도 `다음 목표`와 `진행`은 유지한다. 실제 경과 시간은 숨기고 첫 두 입력의 오차만 2초간 보여준다.
- 가이드 비주얼:
  - 1페이지: 컵에서 올라온 증기가 시계를 덮고 첫 입력 오차가 표시되는 장면
  - 2페이지: 같은 버튼으로 10·20·30초를 순서대로 찍고 재료가 추가되는 장면
  - 3페이지: 세 결과 마커와 총 오차, 빠름·느림, 앱 이탈 경고
- 홈 미리보기: 압축한 비점수 데모에서 지속 증기, 두 체크포인트 오차, 세 조리 행동, 결과 개그를 반복한다. 압축 연출임을 명확히 한다.

  - 결과에는 성공, 빠름, 늦음을 구분하는 짧은 효과음을 사용한다.

## 기술 적합성

- 런타임 접근: Flame 고정 화면과 단조 증가 `Stopwatch` 또는 주입 가능한 동등 시계를 사용하고 Flutter HUD가 목표·진행·버튼을 표시한다.
- 재사용 프로젝트 구성: `MiniGameController`, `MiniGameHudState`, 공통 카운트다운, 게임 화면, 종료 전환, 시도 소진과 점수 제출 흐름
- 순수 규칙 모듈: `domain/ramen_timer_rules.dart`가 목표 시점, 입력 양자화, 개별·총 오차, 제출 점수 변환, 표시 포맷터, 결과 판정 구간과 서버 허용 범위를 담당한다.
- 중앙 조정 위치: `RamenTimerRules`에 모든 시간·점수·판정 상수를 모은다.
- 프레젠테이션: 전용 HUD 스타일, 홈 미리보기, 3페이지 가이드 비주얼을 사용한다.
- 레지스트리: `GameRegistry`, 지원 규칙 버전, `GamePresentationRegistry`, 홈·가이드 enum 또는 동등 정의에 등록한다.
- 백엔드: `20260920000100_ramen_timer_immediate_error_feedback_v4.sql`이 현재 런타임 v4의 45초 카탈로그, 점수 `0` 또는 정상 범위 `3,525,750~3,600,000`, 보조 필드 `0`, 정상 지속시간 `3700~45000ms`와 시간 초과 `45000ms`를 검증한다. `20260928000100_rollback_ramen_timer_to_v3.sql`은 Alpha 빌드 호환을 위해 새 시도를 v3으로 되돌린 이력을 보존하므로, 런타임 규칙 v4와 서버의 v3/v4 지원을 구분한다.
- 주요 구현 위험:
  - 애니메이션 델타로 시간을 재면 프레임 저하가 점수에 영향을 줄 수 있음
  - 결과 전 부분 오차나 주기적 배경 연출이 숨은 시계를 누설할 수 있음
  - 버튼 이중 입력과 여러 포인터가 체크포인트를 건너뛸 수 있음
  - 공통 결과 화면은 역변환된 총 오차를 표시해야 하며 내부 큰 정수를 노출하면 안 됨
  - 외부 스톱워치 악용은 클라이언트 규칙만으로 완전히 막을 수 없음
  - 30초 단판이 일부 사용자에게 너무 짧거나 반복적으로 느껴질 수 있음

## 인수 테스트

- 가이드에서 보이는 3초, 지속 증기, 첫 두 입력 오차, 10·20·30초 탭, 총 오차, 시간 초과, 이탈 규칙을 약 20초 안에 이해할 수 있다.
- 야근 너구리의 무모한 시간 감각과 세 조리 행동이 핵심 타이밍 규칙을 자연스럽게 설명한다.
- 한정된 에셋만으로 일관된 2D 픽셀아트 장면을 구성한다.
- 약간 못생기고 어색한 너구리의 정체성이 버튼·시계·컵라면 가독성을 해치지 않는다.
- 360 논리 픽셀 폭의 여러 휴대전화 비율에서 아트 픽셀 크기와 버튼 안전 영역이 일관된다.
- 카운트다운과 활성 플레이 0~3.2초에는 점수에 영향을 주는 입력이 없다.
- 정확히 3.0초까지 실제 시간이 보이고, 컵에서 올라온 증기가 3.0초부터 시계를 덮은 뒤 결과 전까지 계속 흐른다.
- 첫 두 유효 입력 직후 목표 대비 오차가 2초간 나타나고, 그 밖의 은폐 구간에는 실제 숫자가 보이지 않는다.
- 유효 입력의 `pointer down` 시점만 기록하고 손 떼기·드래그·버튼 밖 입력은 점수를 만들지 않는다.
- 250ms 입력 잠금과 단일 포인터 정책이 우발적·의도적 이중 탭을 막는다.
- 각 유효 탭은 체크포인트를 정확히 하나만 진행시킨다.
- 첫째·둘째 탭은 실제 기록이나 부분 점수 없이 목표 대비 부호 있는 오차만 공개한다.
- 세 번째 탭이 점수와 지속시간을 한 번만 잠그고 결과를 정확히 한 번 방출한다.
- 10.00·20.00·30.00초 입력은 총 오차 0과 최고 정상 점수를 만든다.
- 9.82·20.31·29.90초 입력은 총 오차 590ms와 제출 점수 3,599,410을 만든다.
- 빠름과 느림은 총 오차에 동일한 절대값으로 반영된다.
- 점수 정방향·역변환과 소수 둘째 자리 포맷이 왕복한다.
- 45초까지 세 번째 탭이 없으면 `timeUp`, 점수 0, 지속시간 45000ms를 정확히 한 번 제출한다.
- 앱 이탈·백그라운드·잠금·전화·시스템 UI·앱 종료는 가짜 점수를 제출하지 않고 시도만 소진한다.
- 프레임률을 바꿔도 같은 입력 타임스탬프가 같은 점수를 만든다.
- 장식 시드가 같으면 증기 흐름이 재현되며 어떤 시드도 입력 영역이나 오차 피드백의 가독성을 해치지 않는다.
- 은폐 뒤 사운드·햅틱·배경 애니메이션에는 입력 직후 오차 외의 초 단위 또는 목표 시점 단서가 없다.
- 모든 정상·시간 초과·중단 전이는 절대 45초 활성 플레이를 넘기지 않는다.
- 결과의 빠름·느림 방향, 수치, 가장 큰 오차와 면발 개그가 실수 원인을 명확히 보여준다.

## 미결정 사항

- 승인되지 않은 핵심 규칙은 없다.
- 실제 점수 분포에 따른 실력 구간 라벨, 정상 서버 점수 하한과 결과 연출 시간은 구현·플레이테스트로 검증할 가설이다.
- 외부 스톱워치 방지용 조리 시간 정지, 목표 시점 변경, 다세트 확장은 핵심 규칙 변경이므로 별도 승인 전에는 추가하지 않는다.
