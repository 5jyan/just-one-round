## 플레이어 약속

- 한 문장 약속: 점점 더 빨라지는 공 10개를 타이밍에 맞춰 치고, 가장 멀리 친 한 공으로 오늘의 순위를 겨룬다.
- 코믹 전제: 관중도 없는 구장에서 근거 없이 자신만만한 투수와 잔뜩 긴장한 타자가 단 10구만으로 승부한다.
- 핵심 실력: 투구 속도와 궤적 판독, 스윙 선입력 타이밍, 앞선 공에 흔들리지 않는 집중력
- 세션 모델: 고정 10구 최대 비거리 점수전
- 예상 지속시간: 50~70초
- 플레이어 대상 제한시간: 없음
- 절대 최대: 300초 기술 안전장치. 정상 플레이에서는 10구 자동 진행으로 훨씬 먼저 끝나며, 안전장치 도달 시 결과를 제출하지 않는다.

## 20초 가이드 계약

> 2초 준비가 끝나면 공이 오기 전부터 화면을 탭해 계속 스윙하세요.  
> 총 10구이며 뒤로 갈수록 빠르고 강하게 휘어집니다.  
> 열 번 중 가장 멀리 친 한 공이 오늘의 점수예요.  
> 2초 준비가 끝나면 공이 오기 전부터 0.3초마다 계속 휘두를 수 있어요!

- 목표: 10구 중 한 공이라도 최대한 정확히 쳐서 최고 비거리를 높인다.
- 조작: 2초 준비가 끝난 뒤부터 화면 어디든 탭한다. 투수의 와인드업과 공의 비행 중 0.3초마다 계속 스윙할 수 있다.
- 점수: 각 투구의 비거리 중 가장 큰 값 하나를 기록한다.
- 개별 실패: 헛스윙 또는 타이밍을 놓친 공은 0m지만 다음 투구는 계속된다.
- 전체 실패 조건: 없다. 10구 완료 전 중단하면 시도만 소진되고 점수는 제출하지 않는다.
- 예상 읽기 시간: 약 13초

## 핵심 루프

- 초기 상태: 3초 카운트다운 뒤 투수와 타자가 준비 자세를 취한다.
- 안전 시작: `playing` 진입 후 투수가 2초 동안 준비 동작을 하며 이 구간의 탭은 무시한다.
- 반복:
  1. 현재 투구 번호와 지금까지의 최대 비거리를 확인한다.
  2. 투수가 준비 동작 후 공을 던진다.
  3. 플레이어는 투수의 와인드업부터 공이 지나가기 전까지 0.3초 간격으로 계속 스윙할 수 있다.
  4. 실제 타격 시점과 이상적인 타격 시점의 차이로 비거리를 계산한다.
  5. 해당 공의 비거리와 새 최대 비거리를 보여준 뒤 다음 공으로 자동 진행한다.
- 정타: 강한 타격 효과와 함께 해당 투구 최대 비거리의 90~100%를 획득한다.
- 보통 타격: 타이밍 오차에 따라 최대 비거리의 35~89%를 획득한다.
- 헛스윙: 판정 범위 밖에서 스윙했거나 공이 지나갈 때까지 탭하지 않으면 0m다.
- 성공: 10구를 모두 처리하면 마지막 타격 연출 뒤 최대 비거리를 한 번 제출한다.
- 시간 초과: 플레이어 대상 시간 초과는 없다.
- 기술 안전장치: `playing` 진입 후 300초에 도달하면 비정상 정지로 간주해 결과 없이 중단한다.
- 종료: 10구 완료, 사용자 이탈·백그라운드 전환에 따른 중단, 기술 안전장치 중 하나로 반드시 끝난다.

## 입력 계약

- 제스처: 단일 탭
- 유효 터치 영역: 상단 나가기 버튼과 시스템 안전 영역을 제외한 전체 게임 영역
- 입력 개방: 투수가 공을 놓은 순간부터 공이 타격 지점을 완전히 통과할 때까지
- 투구 전 탭: 무시하며 짧은 입력 잠금 표시만 보여준다.
- 첫 유효 탭: 즉시 스윙을 시작한다. 타격 창보다 이른 헛스윙은 투구를 종료하지 않는다.
- 추가 탭: 2초 준비가 끝난 뒤 투수 와인드업부터 직전 인정 스윙 후 0.3초가 지나면 새 스윙으로 인정한다. 0.3초 이내 입력은 무시한다.
- 공을 보내는 경우: 입력 창이 닫히는 순간 자동으로 헛스윙 0m 처리한다.
- 멀티터치: 같은 프레임의 첫 번째 포인터만 인정하며 0.3초 쿨다운을 모든 포인터가 공유한다.
- 길게 누르기·드래그·손 떼기: 점수에 영향을 주지 않는다.
- 카운트다운·안전 시작 입력: 버퍼링하지 않고 폐기한다.
- 유효 입력 피드백: 타자가 즉시 스윙하고 타격 판정 결과를 표시한다.
- 무효 입력 피드백: 캐릭터 상태와 점수는 바뀌지 않는다.

## 상태 머신

```text
loading → countdown → safe_opening → pitch_prepare → pitch_flight
                                                    ├─ first tap → swing_resolution
                                                    └─ ball passed → miss_resolution

swing_resolution / miss_resolution → pitch_feedback
                                   ├─ pitch 1~9 → pitch_prepare
                                   └─ pitch 10 → result_reveal → finished_clear

loading / countdown / playing / result_reveal → interrupted
playing → 300s technical watchdog → interrupted
```

- `finished_clear`만 최대 비거리 결과를 제출한다.
- 10구가 모두 0m여도 정상 완료이므로 0점을 제출한다.
- `interrupted`와 기술 안전장치 종료는 시도만 소진하며 결과를 제출하지 않는다.
- 결과 콜백은 모든 경로에서 최대 한 번만 방출한다.

## 비거리 계산

- `i`: 현재 투구 번호 `1~10`
- `C_i`: 해당 투구의 최대 비거리 센티미터. `10,500 + 500 × (i - 1)`
- `W_i`: 해당 투구의 안타 판정 반폭 밀리초
- `e_i`: 방망이 타격 프레임과 공의 이상적인 접촉 시점 사이 절대 오차 밀리초
- `e_i > W_i`면 해당 투구 비거리는 `0cm`다.
- `e_i ≤ W_i`면 상대 오차 `r_i = e_i / W_i`를 사용해 거리 구간을 판정한다.
- `0.8 ≤ r_i ≤ 1.0`은 땅볼 `3,500~4,299cm`, `0.6 ≤ r_i < 0.8`은 1루타급 `4,300~5,499cm`, `0.4 ≤ r_i < 0.6`은 2루타급 `5,500~6,999cm`, `0.12 ≤ r_i < 0.4`은 장타 `7,000~9,999cm`로 구간 안에서 선형 보간한다.
- `0 ≤ r_i < 0.12`만 홈런이며 `10,000cm`부터 해당 투구 최대치 `C_i`까지 증가한다. 기존 20% 구간보다 40% 좁고, 내부 진행도에는 `2.0` 제곱 곡선을 적용해 초장타는 정타 중심에 매우 가까운 입력에서만 나온다.
- 홈런 이외의 기본 거리 `B_i`에는 투구 진행도 `p_i = (i - 1) / 9`와 접촉 품질을 사용한 `round(4,000 × p_i^1.8 × ((1-r_i)/0.88)^1.4)`cm 보너스를 더한다. 결과는 홈런 기준 바로 아래인 `9,999cm`로 제한한다.
- 따라서 같은 상대 오차에서 1구는 기본 거리 그대로지만 후반 구부터 보너스가 커지고, 10구는 접촉 품질에 따라 최대 40m를 추가로 받는다. 현재 공식으로 `r=0.5`를 계산하면 1구 약 62.5m, 5구 약 66.7m, 7구 약 89.1m(강타자 배율 포함), 10구 약 80.6m다.
- 최종 점수 `S = max(D_1, D_2, ... D_10)`이다.
- 이 공식에는 추가 난수를 넣지 않는다. 같은 투구를 같은 오차로 치면 항상 같은 비거리가 나온다.
- 7구도 먼저 기존 `D_7`을 계산한 뒤 `round(D_7 × 1.25)`를 적용한다. 판정 유형은 배율 적용 뒤 결정하므로 100m 미만 장타가 홈런으로 승격될 수 있다. 판정 밖의 0cm도 0 × 1.25 = 0cm다.
- 6구 종료 후 7구 직전에 1.6초 강타자 입장 연출을 한 번 보여준다. 붉은 대형 문구·광선·충격파·진동 동안 탭은 무시하고, 연출 종료 후 일반 7구 슬라이더의 와인드업을 처음부터 시작한다. 투수, 공, 판정 창, 궤적과 거리 계산은 바꾸지 않는다. 강타자는 등번호 없는 남색·붉은색 전용 유니폼과 더 넓은 어깨·몸통·하체를 가진 별도 시트를 사용하며 8구부터 원래 타자로 돌아온다.
- 이론상 최소 점수는 `0cm`, 최대 점수는 `16,875cm`, 즉 `168.75m`다. 1~6구와 8~10구의 기존 상한은 각각 `C_i`를 유지한다.

### 타구 유형과 궤적

| 비거리 | 표시 유형 | 시각 궤적 | 잔상 |
|---:|---|---|---:|
| 35.00~42.99m | 땅볼 | 낮게 튀며 내야를 통과 | 1 |
| 43.00~54.99m | 1루타급 | 낮은 포물선으로 외야 앞에 도달 | 2 |
| 55.00~69.99m | 2루타급 | 중간 높이와 깊이의 포물선 | 3 |
| 70.00~99.99m | 장타 | 담장 앞 또는 담장 높이 아래로 향하는 외야 타구 | 4 |
| 100.00~129.99m | 홈런 | 담장을 넘은 뒤 낙하하는 원거리 비행 | 7 |
| 130.00m 이상 | 초대형 홈런 | 담장과 관중석 위로 더 높고 깊게 뻗는 원거리 비행 | 7 |

- 타구 유형은 수비 결과가 아니라 비거리의 시각적 분류다. 땅볼도 성공 타격이며 기존 최고 기록보다 멀면 최대 비거리를 갱신한다.
- 100.00m부터 홈런으로 판정하며, 포물선이 낙하하는 마지막 구간에서도 공 중심이 담장 상단보다 위에 남아 구장 안으로 되돌아와 보이지 않게 한다.
- 100.00m는 담장을 확실히 넘고, 기본 상한 150m에 가까워질수록 담장 위 여유 높이와 전진 깊이가 증가한다. 7구 강타자가 150m를 넘겨도 이미 완전히 담장을 넘은 연출을 유지한다.
- 타구 방향은 시드와 투구 번호로 좌·좌중간·우중간·우의 네 코스에 분산한다. 투수가 있는 정중앙 코스는 생성하지 않는다. 빠른 타이밍은 계산된 코스를 왼쪽으로 한 단계, 늦은 타이밍은 오른쪽으로 한 단계 보정한다.
- 땅볼은 흙 영역을 따라 낮게 구르며 작게 튄다. 나머지 타구는 최고점 이후 전진 속도가 줄면서 아래로 낙하하고, 100m 이상 홈런은 모두 담장 위를 통과한다.
- 같은 시드·투구·타이밍 오차는 항상 같은 거리, 유형, 방향을 만든다.
- 1구의 기본 판정은 바깥쪽부터 땅볼·1루타급·2루타급 각각 20%, 장타 28%, 홈런 12%다. 후반 공은 비거리 보너스로 같은 상대 오차가 더 높은 타구 유형으로 올라갈 수 있다.
- 가장 정확한 홈런급 구간에서는 기본 최대 비거리 상한이 `105m → 150m`로 증가하고, 7구 강타자는 그 투구 결과만 1.25배로 확장한다. 따라서 판정 창은 좁아지지만 잘 맞힌 후반 공일수록 실제 비거리 보상이 커진다.

## 콘텐츠 확장성과 Codex 적합성

- 수작업 맵: 고정 경기 화면 1개
- 수작업 스테이지: 없음
- 재사용 패턴: 코드 기반 투구 정의 10개
- 필수 캐릭터 가족: 투수 1종, 타자 1종
- 필수 게임 오브젝트: 야구공, 방망이, 홈플레이트, 투수판
- 필수 효과 가족: 공 궤적, 타격 충격, 비거리 숫자, 헛스윙, 10구 마구 전조, 홈런 전용 배너·금색 폭발
- 변화 원천: 투구 속도, 속도 이징, 수평·수직 변화량, 변화 시작 시점, 시드 기반 변화 방향
- 수치 난이도 제어: 비행시간, 안타 판정 폭, 스윙 선행시간, 궤적 변화량, 변화 시작 시점, 최대 비거리
- 추가 콘텐츠가 필요 없는 이유: 고정된 10단계가 한 세션의 학습과 반전을 완성하며, 미세한 일일 시드 변주가 반복 날짜의 암기를 줄인다.
- 구현 복잡도: 중간. 물리 시뮬레이션 대신 순수 시간·곡선 기반으로 계산해 테스트 가능성을 유지한다.
- 자동 테스트 전략:
  - 투구 1~10 순서와 정확한 종료
  - 각 투구의 비행시간·판정 폭·최대 거리
  - 타격 오차와 거리 공식의 경계값
  - 최대 비거리가 10개 거리의 최댓값과 일치
  - 동일 시드의 방향·속도 변주 재현
  - 0.3초 재스윙 쿨다운과 이른 헛스윙 뒤 재시도
  - 10구 완료 결과 정확히 1회
  - 중단과 안전장치에서 결과 미제출

## 무작위성과 한 번의 시도 공정성

- 난수 원천: `MiniGameSeed.forAttempt`에서 전달한 `challengeSeed`
- 시드 범위: 한국 제품 날짜, 게임 ID, 규칙 버전을 포함한다. 일반 게임의 공통 정책에 따라 추가 시도에도 같은 챌린지를 사용한다.
- 무작위 요소:
  - 몸쪽·바깥쪽 및 변화구의 좌우 방향
  - 기준 비행시간의 ±1% 이내 미세 변주
  - 10구 마구 S자의 최초 방향
- 고정 요소:
  - 1~10구 투구 종류와 난이도 순서
  - 안타 판정 폭과 최대 비거리
  - 각 투구의 변화 축과 변화 시작 구간
- 합법 생성 조건:
  - 모든 공은 최종적으로 동일한 타격 가능 영역을 통과한다.
  - 이상적인 탭까지 약 580ms 이상을 보장한다.
  - 속도 변주는 기준값의 ±1%를 벗어나지 않으며 다음 구가 이전 구보다 항상 빠르다.
  - 화면 밖으로 나가거나 타격할 수 없는 궤적을 생성하지 않는다.
- 안전 시작: `playing` 진입 후 2초 동안 실패 가능한 공이나 유효 스윙이 없다.
- 피할 수 없는 실패 방지: 공의 위치·크기·궤적을 항상 표시하고 순간이동이나 숨김을 사용하지 않는다.
- 생성 폴백: 어떤 계산값이 합법 범위를 벗어나면 해당 투구의 표준 방향과 기준 비행시간을 사용한다.
- 추가 시도 공정성: 같은 날짜의 추가 시도도 첫 시도와 동일한 속도·방향 변주를 사용해 학습 결과를 공정하게 비교한다.
- 연타 악용 방지: 여러 번 스윙할 수 있지만 직전 인정 스윙 뒤 0.3초 이내 입력은 모두 무시한다.
- 대기 악용 방지: 공과 투구 순서는 자동 진행되며 입력하지 않은 공은 0m 처리한다.
- 화면 밖·수명주기 악용 방지: 앱 이탈, 잠금, 전화, 시스템 UI, 백그라운드 전환은 시도만 소진하고 결과를 제출하지 않는다.
- 판정 피드백: `정타`, `좋아!`, `빗맞음`, `너무 빨랐어`, `늦었어`, `헛스윙`을 타격 오차 방향에 따라 구분한다.

## 점수와 랭킹

- 플레이어 표시 단위: 열 번 중 최대 비거리 미터
- 투구별 표시: 해당 투구 거리 `N.NNm`
- HUD: 현재 투구 `N/10`, 최대 비거리 `MAX N.NNm`, 직전 투구 거리
- 제출 정수: 최대 비거리 센티미터 `0~16875` (규칙 버전 8; v1~v7 기존 검증 체인 유지)
- 정렬: 높은 정수가 더 높은 순위
- 표시 변환: `raw_score / 100`을 소수 둘째 자리 미터로 표시한다.
- 역변환: 표시용 미터를 사용하지 않고 내부 센티미터 정수를 직접 제출한다.
- 정밀도: 서버 센티미터, 화면 0.01m
- 동점: 센티미터까지 같으면 현재 공통 랭킹 규칙에 따라 먼저 제출한 기록이 앞선다. 플레이테스트에서 동점률이 높으면 숨은 점수 없이 정밀도만 재검토한다.
- 정상 완료: 10구 거리 중 최댓값을 제출하고 `GameEndType.clear`를 사용한다.
- 0점 완료: 10구를 모두 놓쳐도 정상 완료이며 0점을 제출한다.
- 시간 초과: 플레이어 대상 시간 초과 결과는 없다.
- 중단·기술 안전장치: 점수를 제출하지 않는다.
- 보조 결과 필드:
  - `starsCollected`: 비거리 1cm 이상인 안타 수 `0~10`
  - `collisions`: 0m인 헛스윙 수 `0~10`
  - 정상 완료에서는 두 값의 합이 항상 10이다.
  - `duration`: `playing` 시작부터 결과 확정까지 실제 경과시간
- 현재 서버 검증:
  - 규칙 버전 8 점수 `0~16875` (v1~v7 기존 검증 체인 유지)
  - 점수 `0~16875`
  - 안타 수와 헛스윙 수 각각 `0~10`, 합계 10
  - 실제 지속시간은 `25000~300000ms`다.

## 프레젠테이션 의존성

### 2D 비주얼 콘셉트

- 장소: 관중도 수비수도 없는 조용한 야간 야구장
- 등장인물: 투수 1명과 타자 1명만 사용한다. 포수·심판·수비수·관중·마스코트는 추가하지 않는다.
- 카메라: 360×640 세로 화면의 타자 뒤쪽 고정 시점. 투수는 화면 중앙 원거리, 타자는 좌측 하단 전경의 뒤쪽 3/4 모습으로 배치하며 공은 방망이 끝의 접촉점으로 커지며 접근한다.
- 구현 매체: 진짜 3D 없이 2D 스프라이트의 위치·크기·곡선만으로 원근감을 만든다.
- 분위기: 둘만 남아 지나치게 진지하게 승부하는 어색하고 웃긴 긴장감
- 핵심 시각 개그: 타자는 매 공마다 지나치게 긴장하지만 투수는 헛스윙이 나와도 아무 표정 없이 바로 다음 공을 준비한다.
- 픽셀 방향: 약 2×2 논리 픽셀로 보이는 굵은 픽셀 덩어리, 단순한 얼굴, 명확한 방망이와 글러브 실루엣
- 대비 우선순위: 공 > 타격 지점 > 방망이 궤적 > 타자·투수 > 배경 > HUD 장식
- 팔레트 분위기: 어두운 남청색 밤, 탁한 녹갈색 그라운드, 크림색 유니폼. 10구 마구의 보라색은 마지막 공 전용 강조색으로 남긴다.
- 배경 동작: 카메라는 고정하고 조명만 미세하게 깜빡인다. 게임 판독에 영향을 주는 장식 애니메이션은 사용하지 않는다.

### 타자

- 역할: 플레이어가 조작하는 주체
- 실루엣: 짧고 뭉툭한 몸, 큰 방망이, 작은 헬멧, 약간 안쪽으로 모인 무릎
- 표정: 입을 일자로 다문 채 눈만 크게 뜬 긴장한 표정
- 어색한 특징: 투구 전 방망이가 미세하게 떨리고 스윙 후 중심을 잘 잡지 못한다.
- 사랑스러운 단서: 헬멧 아래로 삐져나온 머리카락 한 가닥
- 필수 동작: 대기, 긴장, 스윙, 정타, 빗맞음, 헛스윙 회전, 결과 안도
- 오프닝: 두 번 심호흡하지만 방망이 떨림은 멈추지 않는다.
- 압박: 6구부터 무릎 떨림이 커지고 10구 전에 침을 한 번 삼킨다.
- 성공: 정타 뒤 자기도 놀라 눈이 더 커진다.
- 실패: 헛스윙 후 한 바퀴 돌아 주저앉되 즉시 다음 공 준비로 돌아온다.

### 투수

- 역할: 10단계 난이도를 몸동작과 공으로 전달하는 상대
- 실루엣: 마른 몸, 긴 팔, 몸에 비해 지나치게 큰 글러브
- 표정: 자신감이 넘치는 무표정
- 어색한 특징: 준비 동작은 과장되고, 릴리스 뒤 크게 숙여지는 팔로스루를 거쳐 무심하게 준비 자세로 돌아온다.
- 사랑스러운 단서: 한쪽만 자꾸 흘러내리는 양말
- 필수 동작: 대기, 긴 준비, 일반 투구, 변화구 투구, 마구 충전, 마구 투구, 타구 추적
- 오프닝: 2초 동안 몸을 푼 뒤 바로 첫 투구에 들어간다.
- 압박: 6구부터 준비 자세가 낮아지고 공 궤적 전조가 강해진다.
- 10구: 큰 글러브 안에서 보라색 픽셀이 새어 나온 뒤 도깨비 마구를 던진다.
- 성공·실패 반응: 타자가 잘 쳐도 못 쳐도 표정은 그대로지만 고개만 공을 따라간다.

### 시각 역할과 피드백

- 목표: 밝은 야구공과 방망이 끝의 실제 접촉 위치
- 위험: 별도 장애물은 없으며 공의 속도·궤적과 좁아지는 타이밍 창이 난이도다.
- 안전 영역: 최초 2초 준비 중에만 입력이 잠기며, 이후 와인드업부터 스윙할 수 있다.
- 투구 경고:
  - 직구는 짧은 흰색 잔상
  - 수평 변화구는 차가운 청록 잔상
  - 낙차 변화구는 주황색 먼지 픽셀
  - 10구 마구는 보라색 전조와 S자 잔상
- 정타: 55ms 접촉 정지, 흰색·노랑·주황 충격 폭발, 거리 단계에 맞는 화면 흔들림·햅틱과 큰 비거리 숫자
- 좋은 타격: 작은 충격 효과와 안정된 타구 궤적
- 빗맞음: 둔한 소리, 짧고 낮은 타구, 작은 거리 숫자
- 거리별 충격: 땅볼부터 홈런급까지 타격 이펙트 표시 배율을 `0.68× / 0.82× / 1.00× / 1.22× / 1.75×`, 지속시간을 `0.16 / 0.21 / 0.27 / 0.34 / 0.52초`로 높인다. 홈런급은 0.18초 동안 감쇠하는 이중 플래시를 사용한다.
- 홈런 축하: 100m 이상이면 `HOME RUN!` 금색 픽셀 배너가 1.35초 동안 팝업·유지·페이드하고, 배너 주변 12방향 금색 폭발 픽셀이 퍼진다.
- 거리별 진동: 같은 순서로 화면 흔들림 크기를 `0.8 / 2.0 / 3.5 / 5.5 / 10.0px`, 지속시간을 `0.08 / 0.12 / 0.17 / 0.24 / 0.42초`로 높이고 햅틱도 선택 클릭부터 시스템 진동까지 단계적으로 강화한다. 헛스윙에는 타격 햅틱을 주지 않는다.
- 너무 빠름: 방망이가 먼저 지나가고 공이 뒤늦게 통과한다.
- 늦음: 공이 기준선을 지난 직후 방망이가 나온다.
- 무입력: 타자는 자동으로 스윙하지 않고 대기 자세를 유지한다.
- 헛스윙 공 수명: 실패 판정 순간에도 공을 제거하지 않는다. 남은 투구 궤적을 이어 홈을 통과한 뒤 화면 아래로 커지며 빠져나가고 마지막 28%에서만 페이드한다.
- 기록 갱신: 해당 공이 기존 기록보다 멀면 거리 숫자가 `MAX`로 이동하며 갱신된다.
- 마지막 성공: 10구 결과 뒤 최대 비거리가 화면 중앙에 고정되고 최고 기록 여부를 표시한다.
- 가이드 시각: 느린 1구에서 공, 타격 기준선, 탭 순간, 최대 비거리 갱신을 순서대로 보여준다.
- 홈 미리보기: 중반 직구의 투구→접근→스윙→최대 비거리 갱신을 하나의 짧은 루프로 보여준다. 마구 꾸미기는 가이드에서 별도로 설명한다.

- 타자 배치는 V3보다 아래로 내려 스프라이트 컨테이너를 `(-21, 338, 240, 240)`에 둔다. 정타는 55ms 접촉 자세를 유지한 뒤 16프레임 팔로스루를 끝까지 재생하고 결과 회복 자세로 전환한다.

## 기술 적합성

- 런타임 접근: Flame 고정 화면에서 투구를 시간 매개 2D 곡선으로 이동시키고, 스윙 타격 프레임과 이상적인 접촉 시점의 차이를 순수 규칙으로 계산한다.
- 실제 투사체 물리: 사용하지 않는다. 화면 밖 타구는 사전 정의된 연출 곡선이며 비거리는 타이밍 공식으로 결정한다.
- 재사용 프로젝트 구성: `MiniGameController`, `MiniGameHudState`, 공통 게임 화면, 종료 전환, 시도·점수 제출 흐름
- 순수 규칙 모듈: `domain/ten_pitch_slugger_rules.dart`가 투구 정의, 시드 변주, 타격 오차 판정, 비거리 계산, 최대 점수, 결과 검증을 담당한다.
- 중앙 조정 위치: `TenPitchSluggerRules`에 시간·판정 폭·궤적·거리 상한이 모여 있다.
- 레지스트리 영향: `GameRegistry`와 프레젠테이션 레지스트리에 `ten_pitch_slugger`를 등록하고 최대 비거리 포맷터와 전용 HUD 스타일을 추가한다.
- 백엔드 영향: `20260921000100_ten_pitch_slugger_stronger_batter_v8.sql`이 게임·규칙 버전 8, 점수 `0~16875`, 안타·헛스윙 보조 필드 합계, 지속시간 `25000~300000ms`와 안타가 있을 때 점수 하한 `3500`을 검증한다. v1~v7 검증 체인은 migration 안에 유지된다.
- 주요 구현 위험:
  - 기기별 터치 지연과 스윙 애니메이션 프레임이 판정 체감을 어긋나게 할 수 있다.
  - 화면 원근 이동과 실제 이상적 접촉 시점이 시각적으로 정확히 일치해야 한다.
  - 8~10구가 어렵지만 읽을 수 있게 보여야 하며 무작위 속임수처럼 느껴지면 안 된다.
  - 최대 기록 갱신 누락이 최종 점수를 오염시킬 수 있다.

## 인수 테스트

- 가이드에서 조작, 10구, 최대 비거리, 개별 헛스윙을 약 20초 안에 이해할 수 있다.
- 등장인물은 투수와 타자 두 명뿐이며 다른 인물 스프라이트가 없다.
- 360 논리 픽셀 너비에서 공, 타격 기준선, 방망이, HUD가 서로 가리지 않는다.
- 전체 아트가 굵은 공통 픽셀 스케일과 ugly-cute 정체성을 유지한다.
- `playing` 진입 후 2초가 지나기 전에는 실패 가능한 공과 유효 스윙이 없다.
- 투구는 정확히 1구부터 10구까지 한 번씩 순서대로 진행한다.
- 각 투구에서 인정된 스윙 뒤 0.3초가 지나면 다음 스윙을 인정한다.
- 이른 헛스윙은 투구를 끝내지 않으며 공이 지나가기 전 다시 맞힐 수 있다.
- 아무 입력도 하지 않으면 타자는 자동으로 스윙하지 않는다.
- 투구 전, 추가 포인터, 길게 누르기, 드래그는 점수를 만들지 않는다.
- 입력하지 않은 공은 다음 투구 전에 정확히 0m로 확정한다.
- 너무 빠른 탭과 늦은 탭을 서로 다른 피드백으로 표시한다.
- 헛스윙 판정 뒤 공이 순간 삭제되지 않고 홈을 지나 화면 밖으로 자연스럽게 퇴장한다.
- 타격 오차 0ms에서 해당 투구 최대 비거리가 나온다.
- 판정 반폭 경계 안쪽은 최소 35m, 바깥쪽은 0m다.
- 투구별 비거리는 해당 투구 상한을 넘지 않는다.
- 최종 점수는 10개 투구 비거리의 최댓값과 정확히 같다.
- 최종 점수 범위는 규칙 버전 8에서 `0~16875cm`다.
- 점수 포맷터가 `16875`를 `168.75m`로 표시한다.
- 동일 시드와 시도 순번에서 방향·속도 변주가 재현된다.
- 모든 생성 궤적은 타격 가능 영역을 통과하고 약 580ms 이상의 이상적 탭 시간을 보장한다.
- 타구는 정중앙으로 나가지 않고 좌·좌중간·우중간·우 코스 중 하나를 사용한다.
- 땅볼은 흙 위의 낮은 바운드를 유지하고, 뜬공은 원거리에서 멈추지 않고 최고점 이후 낙하한다.
- 10구 완료는 결과를 정확히 한 번 제출하고 `clear`로 종료한다.
- 10구 전부 0m여도 0점을 정상 제출한다.
- 앱 이탈·백그라운드·잠금·전화·시스템 UI는 점수를 제출하지 않고 시도만 소진한다.
- 300초 기술 안전장치는 점수를 제출하지 않는다.
- 360×640, 360×720 및 지원되는 좁은 휴대폰 화면에서 타격 위치와 터치 영역이 일치한다.
