## 플레이어 약속

- 한 문장 약속: 고장 난 네온 오락기에서 흩어진 숫자를 1부터 50까지 최대한 빨리 찾아 누른다.
- 코믹 전제: 오래된 오락기가 숫자 버튼을 제멋대로 켜지만, 플레이어는 `NEXT`만 믿고 50까지 추적한다.
- 핵심 실력: 시각 탐색, 숫자 순서 유지, 손-눈 협응
- 세션 모델: 50을 누르면 끝나는 클리어 타임
- 가설 구간: 초보 70~150초, 중급 40~70초, 숙련 20~40초
- 절대 최대: 180초

## 20초 가이드 계약

> 5×5 보드에서 1부터 50까지 순서대로 탭하세요.  
> 위의 NEXT가 지금 누를 숫자예요. 3초간 못 찾으면 해당 타일이 은은하게 점멸합니다.
> 틀려도 계속할 수 있지만 시간은 흐릅니다. 50을 빨리 누를수록 높은 기록입니다!

- 조작: 숫자 타일 탭
- 점수: 50까지의 완료 시간
- 오답: 짧은 흔들림과 햅틱, 별도 시간 정지는 없음
- 실패: 180초 안에 완료하지 못하면 타임아웃
- 예상 읽기 시간: 약 15초

## 핵심 루프와 입력

- 시작: 3초 카운트다운 후 5×5 보드에 1~25를 섞어 표시한다.
- 반복: `NEXT` 확인 → 보드 탐색 → 해당 숫자 탭 → 다음 숫자 탐색
- 정답: 버튼을 끄고 다음 숫자로 진행한다.
- 힌트: 마지막 정답 후 3초간 진행하지 못하면, 현재 목표가 보이는 상태일 때만 타일 테두리를 은은하게 점멸한다.
- 오답: 해당 버튼을 0.16초 흔들고 진행 상태는 유지한다.
- 보드 밖·버튼 간격·이미 꺼진 버튼: 무시
- 리필: 활성 숫자가 15개보다 적고 26~50이 남아 있으면 꺼진 칸 하나에 다음 예약 숫자를 배치한다.
- 리필 지연: 0.5~2.0초 후 점등, 점등 효과 0.48초
- 성공: 50을 탭하면 0.52초 완료 연출 뒤 결과 제출
- 시간 초과: 180초에 진행을 멈추고 결과 제출
- 중단: 시도만 소진하고 결과 제출 없음

## 상태 머신

```text
loading → countdown → playing
                         ├─ tap 50 → clear_animation → finished_clear
                         ├─ 180s → finished_timeout
                         └─ interrupted
```

- 완료·타임아웃 결과는 각각 한 번만 방출한다.
- 완료 연출 중 중복 결과를 만들지 않는다.

| 초반 | 11~25 | 익숙한 고정 숫자 집합 | 빠른 시각 탐색 |
| 중반 | 26~35 | 꺼진 칸에 새 숫자 점등 | 빈칸 감시와 탐색 전환 |
| 후반 | 36~50 | 활성 버튼 약 15개 유지 | 지연 점등 추적과 속도 유지 |

### 조정 가능 값

| 변수 | 현재값 | 범위 | 이유 |
|---|---:|---:|---|
| 보드 | 5×5 | 고정 | 모바일 터치 크기와 탐색량 균형 |
| 시작 숫자 | 1~25 | 고정 | 규칙 즉시 인지 |
| 최종 숫자 | 50 | 고정 | 대중적인 명칭과 명확한 완료 |
| 활성 목표 | 15개 | 고정 | 후반 보드가 지나치게 비지 않음 |
| 리필 지연 | 0.5~2.0초 | 난수 | 새 숫자 주시 요구 |
| 타임아웃 | 180초 | 고정 | 한 판 최대 3분 |

- 시간이 흐른다고 자동으로 빨라지는 요소는 없다. 26 이후의 점등 지연과 화면 변화가 후반 난이도를 만든다.
- `10·20·30·40·50`을 정답으로 누른 직후 네온 팔레트와 맥동 속도가 다음 단계로 강해지며, 짧은 테두리 플래시로 전환을 알린다. `50`은 금색 클리어 분위기로 마무리한다. 입력·점수·리필 규칙은 변하지 않는다.
- 10단위 특수 버튼은 정답 시 0.72초간 압축·반동한 뒤 전기 폭발과 `N BREAK!`를 표시하고 캐비닛을 짧게 흔든다. 연출 중에도 다음 숫자 입력을 계속 받으며, 흔들린 표시 위치와 터치 판정 위치를 일치시킨다.
- `1·10·20·30·40·50`은 보드에 나타나는 처음부터 금색 계열 특수 버튼으로 구분한다.

## 콘텐츠 확장성과 Codex 적합성

- 수작업 맵·문제·스테이지: 없음
- 에셋 가족: 오락기 배경, 버튼 상태, 효과, 홈 히어로
- 변화: 시작 숫자 배열, 리필 위치, 리필 지연
- 수치 제어: 활성 버튼 수, 지연 범위, 보드 크기, 최종 숫자, 타임아웃
- 구현 복잡도: 낮음
- 추가 문제를 만들 필요가 없는 이유: 숫자 배열과 점등 위치가 매 판 다른 시각 탐색 순서를 만든다.
- 자동 테스트:
  - 1~25 셔플 완전성
  - 정답·오답·빈칸 탭
  - 26~50 순차 리필
  - 활성 버튼 수
  - 리필 지연 범위
  - 점수 왕복 변환
  - 클리어·타임아웃 결과 1회

## 무작위성과 한 번의 시도 공정성

- 난수 주입: 가능
- 무작위 요소: 1~25 배열, 리필 칸, 0.5~2초 리필 지연
- 합법성: 숫자는 중복 없이 순차 생성되고 현재 점등 중인 칸과 충돌하지 않는다.
- 안전 시작: 카운트다운 중 입력을 막으며 즉시 실패 조건은 없다.
- 피할 수 없는 실패: 없음. 모든 숫자는 점등 후 계속 보드에 남는다.
- 공정성 위험: 리필 지연 누적과 배열 난이도가 실제 클리어 타임에 영향을 준다.
- 권장 계약: 날짜·규칙 버전 기반 동일 시드를 사용하거나, 리필 지연을 점수 타이머에서 제외하지 않는다면 모든 플레이어에게 동일한 지연 순서를 제공한다.
- 연타 악용: 현재 NEXT와 정확히 같은 숫자만 진행시킨다.
- 대기 악용: 시간이 계속 흐르므로 이득이 없다.
- 실패 피드백: 오답 버튼 흔들림과 강한 햅틱

## 점수와 랭킹

- 플레이어 표시: 실제 완료 시간 `N.NN초`
- HUD: 경과 시간과 NEXT 숫자
- 서버 정렬용 제출 정수: `3,600,000 - 경과밀리초`
- 역변환: `3,600,000 - 제출점수`
- 순위: 제출 정수가 높을수록 빠른 기록
- 클리어: 최소 1ms로 제한한 실제 경과시간 제출
- 타임아웃: 180초, 충돌 1, 제출 점수 0, `timeUp`
- 0점은 어떤 정상 클리어보다 낮으며 결과·랭킹에서는 `0점`으로 표시한다.
- 중단: 제출 없음
- 정밀도: 화면은 0.01초, 서버는 밀리초 정수

## 2D 비주얼 콘셉트

- 장소: 어두운 오락실의 낡았지만 화려한 네온 캐비닛
- 카메라: 360×640 정면 고정
- 분위기: 남색·검정 화면 위 청록과 자홍 네온
- 캐릭터 대신 기계 자체가 주인공이다.
- ugly-cute 적용: 프레임이 약간 삐뚤고 버튼 빛이 균일하지 않으며 오래된 CRT가 과하게 진지한 `NEXT`를 표시한다.
- 픽셀 방향: 굵은 계단진 테두리, 제한된 네온 색, 선명한 숫자 실루엣
- 대비 우선순위: NEXT > 현재 찾을 숫자 타일 > 다른 활성 타일 > 점등 효과 > 캐비닛 장식
- 핵심 시각 개그: 오답 버튼만 억울한 듯 덜컹거리지만 기계는 아무 일 없다는 듯 다음 입력을 기다린다.
- 성공: 50 버튼과 전체 프레임이 짧게 점등
- 타임아웃: CRT가 붉게 깜빡이고 남은 NEXT를 표시
