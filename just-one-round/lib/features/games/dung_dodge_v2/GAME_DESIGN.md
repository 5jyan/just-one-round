### 첫 이동 즉사 회귀 수정

- 낙하 경로의 최근접점과 **캐릭터**의 세로 거리를 사용한다. 이전에는 똥의
  끝점과의 거리를 사용해 화면 위의 똥도 가로 위치만 가까우면 충돌했다.
- 드래그는 이벤트의 실제 가로 이동량을 누적해 다음 위치를 정한다.
- 즉시 1:1 이동·손을 뗀 위치 유지·화면 경계·이동 경로 충돌은 유지한다.
- 10개 시드의 초기 실제 왕복 드래그, 머리 위 안전한 장애물, 빠른 세로
  통과와 가로 이동 중 접촉, 종료 콜백 1회만 발생하는 경우를 검증한다.

## 플레이어 약속

- 한 문장 약속: 엉뚱한 선사시대 오리를 좌우로 움직여 하늘에서 쏟아지는 똥을 최대 5분간 피한다.
- 코믹 전제: 평화롭게 산책하던 오리 머리 위로 표정 있는 똥 운석이 쏟아지고, 오리는 뒤늦게 상황을 알아챈다.
- 핵심 실력: 낙하 위치 예측, 짧은 회피 이동, 다음 안전 공간 확보
- 세션 모델: 충돌 즉시 종료되는 생존전
- 목표 실패 구간: 초보 30~50초, 중급 50~90초, 숙련 90~150초
- 절대 최대: 300초

## 20초 가이드 계약

> 화면을 누른 채 좌우로 드래그하면 오리가 움직여요.  
> 위에서 떨어지는 똥의 빈틈으로 피하세요. 한 번 닿으면 즉시 끝납니다.  
> 시간이 갈수록 더 빠르고 자주 떨어져요. 최대 5분, 오래 버틸수록 높은 기록입니다!

- 점수: 실제 생존 시간
- 조작: 화면 어디서든 누르고 좌우로 드래그
- 실패: 오리와 똥이 한 번 충돌하면 즉시 종료
- 예상 읽기 시간: 약 13초

## 핵심 루프와 입력

- 시작: 3초 카운트다운 후 오리가 화면 아래 중앙에 선다.
- 반복: 낙하 위치 확인 → 가까운 안전 공간 선택 → 필요한 거리만 드래그 → 다음 낙하 묶음 확인
- 드래그 활성 거리: 6 논리 픽셀
- 이동: 손가락의 논리 가로 이동량을 캐릭터 중심에 1:1로 즉시 더한다. 별도 관성·추적 속도 제한은 없다.
- 가로 범위: 64px 오리 중심 기준 `x=32~328`
- 탭만 하기: 이동하지 않는다.
- 활성화: 처음 6 논리 픽셀은 탭 오입력을 막는 데드존이며, 임계값을 넘는 순간 누적된 첫 이동량 전체를 적용한다.
- 손 떼기·취소: 마지막 드래그 위치를 유지하고 걷기 상태만 초기화한다.
- 재터치: 새 위치로 순간이동하지 않고 새 드래그의 상대 이동만 적용한다.
- 멀티터치: 먼저 시작한 포인터만 드래그를 소유하며, 다른 포인터의 이동·종료·취소는 무시한다.
- 종료: 충돌 또는 300초 시간 초과
- 중단: 시도만 소진하고 결과를 제출하지 않는다.

## 상태 머신

```text
loading → countdown → playing
                         ├─ collision → finished_game_over
                         ├─ 300s → finished_time_up
                         └─ interrupted
```

- 정상 종료는 생존 밀리초를 정확히 한 번 제출한다.
- 충돌 시 KO 스프라이트로 바꾸고 낙하물을 제거한다.

## 난이도 계약

| 시간 | 생성 간격 | 기준 낙하 속도 | 목표 구간 |
|---:|---:|---:|---|
| 0초 | 0.62초 | 170 | 안전한 규칙 학습 |
| 20초 | 0.38초 | 297.5 | 중급 압박 |
| 80초 | 0.14초 | 680 | 숙련 압박 |
| 140초 | 0.12초 | 760 | 극한 |
| 200초 | 0.10초 | 840 | 극한 |
| 260초+ | 0.08초 | 920 | 절대 상한 |

- 기존 60·120·180·240·300초 기준을 각각 20·80·140·200·260초로 40초씩 앞당겨 적용한다.
- 0~20초를 포함해 표의 각 기준점 사이에서 생성 간격과 기준 낙하 속도를 선형 보간한다.
- 260초 이후에는 최대 난이도를 유지하며 게임은 300초에 종료한다.
- 개별 낙하 속도 배율: 기준 속도의 `0.88~1.18`
- 생성 x: 양쪽 24px 여백 안에서 2px 아트 격자에 스냅
- 최초 충돌 가능 시점은 활성 플레이 3초를 초과해야 한다. 현재 낙하 거리·속도로 이를 자동 검증한다.

- 수작업 맵·스테이지·웨이브: 없음

- 변화: 낙하 x, 개별 속도, 동시에 화면에 존재하는 똥 수
- 난이도 수치: 생성 간격과 낙하 속도 두 개
- 구현 복잡도: 낮음
- 지속 콘텐츠가 필요 없는 이유: 같은 낙하물도 시간 곡선과 위치 조합으로 계속 다른 회피 판단을 만든다.
- 자동 테스트:
  - 난이도 마일스톤과 260초 최대 난이도 상한
  - 시드별 낙하 순서 재현
  - 드래그 데드존과 상대 이동
  - 가로 경계
  - 지면·플레이어 충돌
  - 종료 결과 1회 방출

## 무작위성과 한 번의 시도 공정성

- 난수: 생성자 주입 가능
- 무작위 요소: 낙하 x와 `0.88~1.18` 속도 배율
- 안전 시작: 첫 물체가 생성되더라도 실제 충돌 가능 시점은 3초 이후여야 한다.
- 현재 구현의 검증 과제: 고난도에서 독립 난수가 동시에 모든 회피 공간을 막지 않는지 시드 퍼징이 필요하다.
- 권장 합법 생성 제약:
  - 플레이어 최대 이동 속도로 도달 가능한 안전 구간을 최소 하나 유지
  - 직전 낙하물과 지나치게 가까운 x 중복 제한
  - 최소 반응 시간 이하의 새 충돌 궤적 거부
- 폴백: 합법 후보가 없으면 해당 생성 틱을 건너뛴다.
- 대기 악용: 오리는 멈출 수 있지만 낙하 압력은 계속 증가하므로 점수 이득을 보장하지 않는다.
- 이동 공정성: 한 번의 입력으로 긴 거리를 이동해도 시작점과 끝점 사이의 수평 경로를 충돌 검사해 낙하물을 건너뛸 수 없다.
- 화면 밖·중단 악용: 중단 시 기록 제출 없음
- 실패 피드백: 충돌한 똥 제거, 오리 KO, 즉시 게임오버

## 점수와 랭킹

- HUD: 0.01초 단위 생존 시간
- 제출 정수: 생존 밀리초 `0~300000`
- 표시: `(ms / 1000).toStringAsFixed(2)초`
- 순위: 높은 밀리초 우선
- 충돌: 충돌 직전까지의 생존 시간 제출
- 300초 도달: 300000ms 제출, `timeUp`
- 중단: 제출 없음
- 동점: 같은 0.01초 표시라도 원시 밀리초가 다를 수 있으므로 서버 정렬 기준을 밀리초로 통일한다.

## 2D 비주얼 콘셉트

- 장소: 화산과 공룡 뼈가 보이는 밝은 선사시대 초원
- 카메라: 고정 측면 2D
- 분위기: 맑고 평화로운 배경과 불쾌하지만 우스운 낙하물의 대비
- 플레이어: 통통한 청록색 오리, 멍한 눈과 큰 노란 부리, 짧은 다리
- 위험물: 서로 다른 얼빠진 표정을 가진 갈색 똥
- ugly-cute 핵심: 오리는 귀엽지만 한 박자 늦고, 똥은 징그럽기보다 어리숙한 얼굴로 떨어진다.
- 픽셀 방향: 2×2 논리 픽셀 격자, 굵은 외곽선, 2~3단계 명암
- 대비 우선순위: 낙하 똥 > 오리 > 안전 지면 > 배경 장식
- 성공 비트: 가까스로 피하면 먼지와 뒤늦은 놀람
- 실패 비트: 오리가 납작한 KO 자세가 되고 똥은 짧게 튄다.
