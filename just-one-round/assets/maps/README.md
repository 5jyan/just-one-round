# 그래비티 스위치 맵 수정법

`gravity_switch_map.json`의 `patterns[].grid`를 그림처럼 직접 수정합니다.

- `ㅁ`: 벽
- `ㅇ`: 플레이어가 이동할 수 있는 빈칸
- 각 문자열은 가로 한 줄이며, 배열의 첫 줄이 맵의 가장 위입니다.
- 모든 줄의 글자 수는 같아야 합니다.
- 한 글자는 가로·세로 48px입니다.

```text
ㅁㅁㅁ
ㅁㅇㅁ
ㅇㅇㅇ
ㅁㅇㅁ
ㅁㅁㅁ
```

JSON에는 위 모양을 다음처럼 입력합니다.

```json
"grid": [
  "ㅁㅁㅁ",
  "ㅁㅇㅁ",
  "ㅇㅇㅇ",
  "ㅁㅇㅁ",
  "ㅁㅁㅁ"
]
```

현재 게임의 벽은 천장이나 바닥에 붙어 있어야 합니다. 따라서 중간에 떠 있는 `ㅁ`은 사용할 수 없으며, 한 세로줄 안에서 위쪽 벽과 아래쪽 벽 사이에는 반드시 `ㅇ` 통로가 남아야 합니다.

`unlockAfterSeconds`를 바꾸면 해당 패턴이 무작위로 등장하기 시작하는 시간을 조절할 수 있습니다.
