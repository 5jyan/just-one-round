# 중력 스위치 맵 수정법

실제 맵 그림은 `patterns` 폴더의 `.map` 파일에서 수정합니다. 따옴표와 쉼표가 없어서 위아래 줄이 붙은 하나의 그림처럼 보입니다.

```text
□□□□□□□
□□□□□□□
□□□□□□□
□□□■□□□
□□■■■□□
□■■■■■□
```

기호의 의미:

- `■`: 벽
- `□`: 이동 가능한 칸 표시
- `공백`: 아무 표시도 없는 완전히 빈칸

`□`와 공백은 모두 충돌하지 않습니다. 차이는 맵 파일에서 통로를 눈에 보이게 표시할지 완전히 비워 보일지뿐입니다.
천장·바닥에 붙은 `■`는 해당 표면을 늘리고, 통로 안의 `■`는 떠 있는 발판이 됩니다. 발판의 윗면과 아랫면에는 중력 방향에 맞춰 착지할 수 있고, 옆면에 부딪히면 종료됩니다. 붙어 있는 내부 `■`는 하나의 세로 벽 구간으로 읽고 기존 고철 모듈로 그립니다.

## 패턴 설정

`gravity_switch_map.json`에는 맵 그림 대신 패턴 설정만 둡니다.

```json
{
  "id": "floor_stairs",
  "description": "바닥 계단",
  "unlockAfterSeconds": 0,
  "mapFile": "patterns/floor_stairs.map"
}
```

- `unlockAfterSeconds`: 해당 패턴이 무작위로 등장하기 시작하는 시간
- `mapFile`: `assets/maps`를 기준으로 한 `.map` 파일 경로
- `testOnly`: `true`이면 일반 게임의 무작위 패턴에서 제외됩니다. 캡처 설정의 `patternIds`로는 지정할 수 있습니다.

## 맵 연결 규칙

맵은 별도의 커넥터 없이 바로 이어 붙습니다. 새 패턴의 첫 3열과 마지막 3열은
기본 패턴의 안전 단면에 맞춥니다.

```text
■■■
■■■
■■■
□□□
□□□
□□□
■■■
■■■
```

8줄 맵의 연결 구간은 위쪽 3칸과 아래쪽 2칸이 벽이고 중앙 3칸이 통로입니다.
이 3열 경계는 신규 패턴을 수정할 때도 유지해야 합니다.

맵은 1~12줄을 사용할 수 있습니다. 세로 한 칸은 48px이고, 12줄 전체가 640px 게임 화면 안에 들어갑니다. 12줄보다 짧은 맵은 부족한 줄을 위아래 벽으로 채워 중앙에 배치합니다. 기존 8줄 맵은 위아래에 벽 2줄씩 자동으로 채워져 이전과 같은 위치에 표시됩니다. 12줄 맵의 안전 연결 단면은 위쪽 벽 5줄, 통로 3줄, 아래쪽 벽 4줄입니다.

```text
■■■
■■■
■■■
■■■
■■■
□□□
□□□
□□□
■■■
■■■
■■■
■■■
```

## 공백을 안전하게 사용하기

편집기가 줄 끝 공백을 지우는 경우에는 모든 줄 양쪽에 `|`를 붙일 수 있습니다. `|`는 경계 표시일 뿐 실제 맵 칸에는 포함되지 않습니다.

```text
|■■■   |
|■□□   |
|□□    |
|      |
```

경계를 쓸 때는 모든 줄의 양쪽에 빠짐없이 붙여야 합니다.

## 주의사항

- 모든 줄은 칸 수가 같아야 합니다.
- 세로 줄 수는 패턴마다 달라도 되지만 최대 12줄입니다.
- 사용할 수 있는 문자는 `■`, `□`, 공백뿐입니다.
- 각 세로 열에는 하나 이상의 통로 칸이 있어야 합니다. 통로 안의 벽은 떠 있는 발판으로 사용할 수 있습니다.
