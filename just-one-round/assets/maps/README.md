# 그래비티 스위치 맵 수정법

실제 맵 그림은 `patterns` 폴더의 `.map` 파일에서 수정합니다. 따옴표와 쉼표가 없어서 위아래 줄이 붙은 하나의 그림처럼 보입니다.

```text
□□□□□□□
□□□□□□□
□□□□□□□
□□□■□□□
□□■■■□□
□■■■■■□
```

기호의 의미:

- `■`: 벽
- `□`: 이동 가능한 칸 표시
- `공백`: 아무 표시도 없는 완전히 빈칸

`□`와 공백은 모두 충돌하지 않습니다. 차이는 맵 파일에서 통로를 눈에 보이게 표시할지 완전히 비워 보일지뿐입니다.

## 패턴 설정

`gravity_switch_map.json`에는 맵 그림 대신 패턴 설정만 둡니다.

```json
{
  "id": "floor_stairs",
  "description": "바닥 계단",
  "unlockAfterSeconds": 0,
  "mapFile": "patterns/floor_stairs.map"
}
```

- `unlockAfterSeconds`: 해당 패턴이 무작위로 등장하기 시작하는 시간
- `mapFile`: `assets/maps`를 기준으로 한 `.map` 파일 경로

## 공백을 안전하게 사용하기

편집기가 줄 끝 공백을 지우는 경우에는 모든 줄 양쪽에 `|`를 붙일 수 있습니다. `|`는 경계 표시일 뿐 실제 맵 칸에는 포함되지 않습니다.

```text
|■■■   |
|■□□   |
|□□    |
|      |
```

경계를 쓸 때는 모든 줄의 양쪽에 빠짐없이 붙여야 합니다.

## 주의사항

- 모든 줄은 칸 수가 같아야 합니다.
- 모든 패턴은 세로 줄 수가 같아야 합니다.
- 사용할 수 있는 문자는 `■`, `□`, 공백뿐입니다.
- 벽은 천장 또는 바닥에 붙어 있어야 하며 중간에 떠 있는 벽은 현재 지원하지 않습니다.
