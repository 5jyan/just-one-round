# Friend-face cue mole drafts

A–D are new ordinary-mole concepts generated from the user-provided face reference. Only simplified facial relationships (brows, eyes, cheeks, nose, closed smile) are carried into the animal design; hair, clothing, background, hand, and photo pixels are excluded.

These are comparison-only drafts. Runtime files under `assets/images/mole_reaction/` remain unchanged. Each folder contains the raw magenta-backed generation, the exact prompt, notes, and a deterministic transparent cutout. See `face-mole-drafts-contact-sheet.png` for the side-by-side preview.

After a variant is selected, it can be normalized to the project's 48×48 source / 96×96 display contract and expanded into idle, hurt, thumbs-up, and golden recolor sheets.
