# Archived high-resolution mole roster

This directory preserves the earlier polished normal roster and attached-reference gold source for provenance and rollback. It is no longer the active visual direction.

The active runtime files still use the same 256px source-cell compatibility path under `assets/images/mole_reaction/high_res/`, but they are now replaced by the approved chunky pixel-art sheets documented in `../pixel_variant/manifest.json`. Both normal and gold sheets use nearest-neighbor sampling; the gold variant shares the normal silhouette and is a deterministic fur-palette transform.

The active game is a 2×2 board with one preparation event and one final golden event. The older 3×4, multi-event description in this archive is historical only.
